# 单句重新识别 需求

## 目标与范围

校对转写字幕时，对听错、漏字的几句**用本地转写模型重新识别原声**：可换更大的模型、指定语言、给出人名术语等提示，把识别结果作为修订建议逐条对比，确认后应用（可撤销）。

对应 `docs/TODO.md`「字幕工作台：听原声校对的后续 → 单句重新识别」。

来源：2026-10-11 用户：“你上面说的这些建议都挺好的，可以记录到一个TODO文档，然后再逐一处理”；随后“跑完后提交并推送，然后继续下一项”。

覆盖：

- 主进程：截取一条字幕的原声（16 kHz），交给已安装的本地转写模型识别，返回文字；不经转写任务队列，不生成新文档。
- 渲染端：从字幕菜单打开“重新识别原声”，选择模型、语言、提示词，逐条识别并显示与原文的差异，勾选后一次应用。

## 范围外

- 重新识别后的时间对齐（只替换文字，时间不变）与字词时间。
- 云端或付费语音识别。
- 翻译轨的重新翻译（应用后译文按现有规则标为“原文已变更”）。
- Agent 工具中的重新识别。

### R-RECOG-01 主进程识别一条字幕的原声

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「单句重新识别：把截取的片段交给本地转写模型（可换更大的模型、指定语言）」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

请求 `{ documentId, cueId, modelId, language, initialPrompt? }`：

1. 按文档当前内容取该字幕的时间段，两侧各留 200 毫秒（不早于 0）；时间段超过 30 秒时拒绝（转写服务单次上传上限约 32 秒）。
2. 用随应用的 FFmpeg 解码为 16 kHz 单声道 WAV，写入应用数据目录下的私有临时文件。
3. 交给转写运行时：与转写任务相同地解析模型（必须已安装）、校验服务运行时、按转写偏好的设备选择后端，向本地 whisper 服务申请推理租约，以“转写、不启用 VAD”识别该文件。
4. 返回识别文字（去掉首尾空白）与识别出的语言；删除临时文件，释放租约。

#### 验收标准

- AC-RECOG-01-1: 对一条字幕发起识别，转写服务收到的是 16 kHz 单声道 WAV（时长 = 字幕时长 + 0.4 秒）、指定的语言与提示词、`vadEnabled: false`，返回其文字；请求结束后临时文件已删除、租约已释放。
- AC-RECOG-01-2: 模型未安装时返回“需要配置”；文档没有可用原始媒体时返回对应的不可用原因；时间段超过 30 秒时返回“超出限制”；转写任务正在用其他模型或设备运行时返回“资源忙”；均不留下临时文件。
- AC-RECOG-01-3: 只接受当前窗口已打开的文档；取消请求时停止解码或推理并删除临时文件。
- AC-RECOG-01-4: 在本机已安装的 large-v3 系列模型上，对一段 Windows 语音合成的英文句子识别出与原句相近的文字（人工核对，作为真实环境证据）。

#### 边界与异常

- 同一窗口同一时间只进行一次识别，新的请求取消旧的。
- 识别期间占用模型（与转写任务一样阻止删除该模型）；转写服务进程在空闲后由现有策略回收。

### R-RECOG-02 “重新识别原声”对话框

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「结果作为 AI 修订建议预览，确认后应用」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 入口：字幕右键 / 行“⋯”菜单“重新识别原声…”（所选 1–20 条；文档没有可用原始媒体时禁用并说明）。
- 选项：转写模型（只列已安装的模型，默认取转写设置中的模型）、语言（自动或常用语言，默认取转写设置）、提示词（可选，人名、术语等，最多 200 字）。没有已安装模型时说明并提供“去安装模型”入口（切到“转写”页）。
- “开始识别”：逐条识别并显示进度（“正在识别 3 / 8”），可随时停止，已识别的结果保留。
- 结果：每条显示序号、试听按钮、原文与识别结果的差异；与原文不同的默认勾选，相同的显示“与原文一致”，未识别出语音的显示“未识别到语音”；失败的显示原因。
- “应用 N 条”：作为一次可撤销的修改写入原文（撤销标签“重新识别 N 条”）；对应译文按现有规则标为“原文已变更”。

#### 验收标准

- AC-RECOG-02-1: 选中 3 条打开对话框，默认模型与语言取自转写设置；开始识别后依次显示 3 条结果与差异，进度从 1/3 到 3/3。
- AC-RECOG-02-2: 取消勾选其中 1 条后“应用 2 条”，两条原文被替换、另一条不变；Ctrl+Z 一次恢复两条。
- AC-RECOG-02-3: 识别中点“停止”，后续条目不再识别，已完成的结果可应用；关闭对话框时停止识别与试听。
- AC-RECOG-02-4: 没有已安装模型时显示说明与“去安装模型”入口且不能开始；文档没有可用原始媒体时菜单项禁用。
- AC-RECOG-02-5: 1280×860 浅色与 786×660 深色下对话框不溢出，长句换行，差异与按钮对齐。

#### 边界与异常

- 翻译任务进行中不能应用（与其他编辑相同的提示），但可以识别与比对。
- 所选超过 20 条时只识别前 20 条并说明。
