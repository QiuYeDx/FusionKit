# studio 需求

需求行为只在这里定义；业务目标见 [brd.md](../../brd.md)，总体方案见 [architecture.md](../../architecture.md)。

## 目标与范围

字幕工作台对翻译资料的全部使用场景：翻译、试译、批量翻译、转写后自动翻译、一致性检查、AI 修订、记入资料，以及执行记录与报告。

- I1：改主进程与契约。这部分必须与数据层同步，否则工作台主进程无法运行。
- I2：改渲染层与交互。

## 范围外

- 翻译资料页（见 module-page）。
- Agent 工具（见 module-agent）。
- 经典字幕翻译器（不接入资料）。
- 旧版冻结资料、旧偏好的兼容（用户决定作废，见 [architecture §3](../../architecture.md#3-旧版数据直接作废不做兼容)）。

## 需求

### R-STUDIO-01 工作台主进程与契约接入 v2

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

按 [architecture §7.4–7.5](../../architecture.md#74-字幕工作台契约-srcsubtitle-studio) 改造：

- 翻译、批量翻译、试译、自动翻译、一致性检查、AI 修订的主进程路径，改用新的选择结构和 v2 冻结快照。
- 删除以下内容：主题、绑定、确认、方案展开、任务资源闸门、文档引用扫描、旧执行策略分支。

#### 验收标准

- AC-STUDIO-01-1: 用 v2 选择（2 个资料集）规划单文档资料翻译时，计划与冻结快照只包含这 2 个资料集的闭包；执行记录能被 `validateExecutionRecord` 校验通过，并且可以暂停后续跑。
- AC-STUDIO-01-2: 批量翻译和试译使用同一个选择规划，参与的条目与单文档翻译一致。请求中出现 `bindings`、`confirmations`、`documentTopicIds` 或 `recipeId` 时，作为非法输入拒绝。
- AC-STUDIO-01-3: 开启转写后自动翻译并选择资料集时，转写前冻结 v2 资料，转写完成后按冻结资料翻译。资料检查失败时生成准备报告，报告中的材料摘要列出资料集名，种子可用于重新检查。
- AC-STUDIO-01-4: 自动翻译资料偏好的结构为 `{enabled, sourceLanguage, collectionIds, disabledEntryIds, instructions?, context?}`，读写往返一致。
- AC-STUDIO-01-5: 一致性检查从库中读取「已选资料集中启用的术语」作为规范写法，停用的术语不参与。
- AC-STUDIO-01-6: AI 修订把已选资料编译后的条目发给模型，载荷中不包含 `condition`、`title`、`evidence`。
- AC-STUDIO-01-7: 删除一个正在被翻译任务使用的资料集后，该任务继续按冻结快照执行完成，不受影响。

#### 边界与异常

资料库读取失败时，翻译预检返回 `knowledge_check_failed` 和诊断，不发起模型请求。

### R-STUDIO-02 资料选择器、预设与最近使用

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

翻译对话框和自动翻译设置共用同一个选择器，包含：

- 当前翻译方向下的资料集多选。方向不一致的资料集置灰，并说明原因。
- 搜索。
- 预设：应用、存为预设、重命名、删除。
- 最近使用：最多 5 组。
- 「更多」：本次排除的条目、内容说明。

不再有主题、对象和方案锁定标记。

#### 验收标准

- AC-STUDIO-02-1: 勾选 2 个资料集后，摘要区显示 2 个资料集标签，试译和翻译都使用这 2 个资料集。
- AC-STUDIO-02-2: 点「存为预设」并输入名称后，预设写入资料库的 presets 组。下次打开选择器可以直接应用，应用后资料集、翻译要求、内容说明都被填入。
- AC-STUDIO-02-3: 应用预设后再增减资料集，不会修改预设本身。预设可以在选择器内重命名和删除，删除前需要确认。
- AC-STUDIO-02-4: 预设或最近使用中引用了已删除的资料集时，应用后该资料集不会被选中，并提示「有 N 个资料集已不存在」。不报错，也不阻止翻译。
- AC-STUDIO-02-5: 最近使用记录最近 5 组不同的资料集组合，按使用时间排序，保存在工作台偏好中，重启后仍在。
- AC-STUDIO-02-6: 资料库为空时，选择器显示「去翻译资料新建」入口，不出现空白下拉。

#### 边界与异常

资料库读取失败时，选择器显示「暂时无法读取资料」与「重新读取」，已选的资料集标签保留；预设保存失败时保留对话框输入并显示错误。

### R-STUDIO-03 试译与自动翻译设置简化

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P1 |

#### 说明

- 试译面板只显示参与的资料和问题，去掉逐句角色和条件确认。
- 转写面板的自动翻译资料设置使用同一个选择器，去掉主题。

#### 验收标准

- AC-STUDIO-03-1: 试译面板不再出现「话题 / 说话人 / 提及」选择和条件确认开关；问题列表按新的问题码显示文案。
- AC-STUDIO-03-2: 转写面板中设置自动翻译资料（勾选资料集或应用预设）后，设置写入偏好，转写完成后的自动翻译使用这些资料。
- AC-STUDIO-03-3: 自动翻译资料检查失败时，面板显示失败原因；「重新检查」把方向和资料集带入翻译对话框。

#### 边界与异常

偏好写入失败时（localStorage 不可用）面板仍可使用本次设置，下次打开回到默认值。

### R-STUDIO-04 记入资料确认即生效

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

涉及三个入口：「记住译法」（QuickTermDialog）、修订后记入、一致性检查保留写法（后两者都在 KnowledgeCaptureDialog）。改动如下：

- 去掉「保存后直接启用」开关和来源实体，保存即启用。
- 新建资料集时必须选择翻译方向，默认取当前文档的方向。

#### 验收标准

- AC-STUDIO-04-1: 在字幕右键菜单「记住译法」中填写原词和译法并保存后，资料库新增一条启用的术语，origin 为 `manual`。对话框中没有采纳开关。
- AC-STUDIO-04-2: 在 AI 修订后的记入对话框中保存 N 条后，这些条目全部启用，origin 为 `revision`。已存在的相同译法被跳过并提示。
- AC-STUDIO-04-3: 保存失败时，对话框保留输入并显示错误。重试不产生重复条目：用相同 id 重建时视为已保存。

#### 边界与异常

资料库在对话框打开期间被修改（generation 变化）时，提案按新快照重建后再保存；仍有冲突时提示刷新。

### R-STUDIO-05 执行记录与报告展示

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P1 |

#### 说明

执行记录详情、批量翻译与审阅中的资料展示，去掉方案、主题、条件，改为显示资料集和参与的条目。

#### 验收标准

- AC-STUDIO-05-1: 记录详情显示所用资料集和参与条目的摘要，不出现方案、主题、条件字段。
- AC-STUDIO-05-2: 问题列表中每个问题码都有对应文案，不显示原始键名。

#### 边界与异常

执行记录无法校验（格式不符或已损坏）时显示「记录不可用」，不显示部分资料内容。

## 约束

- 除资料选择外，工作台的翻译行为（批次、预算、重试、检查）不变。
- 执行记录上限（`assertKnowledgeExecutionCapacity` 64 KiB）不变。
