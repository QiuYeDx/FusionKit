# page 需求

需求行为只在这里定义；业务目标见 [brd.md](../../brd.md)。

## 目标与范围

重做翻译资料页 `/tools/translation-knowledge`：一层导航、资料集工作区（术语表 / 说明）、行内编辑、右侧抽屉、多选操作、删除撤销、导入导出、引导、Agent 页面上下文；I4 清理四语文案。

## 范围外

预设管理（只在工作台选择器中）；修订历史界面。

## 需求

### R-PAGE-01 布局与导航

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

左侧栏从上到下：全局搜索、资料集列表（名称、方向、条目数）、「新建资料集」、折叠的「已归档」分组，底部为导入、导出、编写 Skill、前往字幕工作台。主区显示当前资料集；没有资料集时显示空状态引导。全局搜索的结果跨资料集列出，点击后跳到对应资料集并高亮该条目。

#### 验收标准

- AC-PAGE-01-1: 页面中不再出现方案与风格、内容对象、全部资料、待确认 / 待审核、更多管理、维护与导入记录等入口。
- AC-PAGE-01-2: 首次打开时默认选中第一个未归档的资料集；从 Agent 卡片带 `knowledgeFocus` 打开时选中指定的资料集。
- AC-PAGE-01-3: 在全局搜索中输入「存档」，结果按资料集分组列出命中的术语和说明；点击结果后，主区切换到该资料集、相应标签，并滚动到该条目使其高亮可见。
- AC-PAGE-01-4: 库为空时，主区显示「新建第一个资料集」与「导入资料包」两个操作，以及一句说明资料集是什么。
- AC-PAGE-01-5: 窗口宽度小于 768px 时，侧栏收为顶部的资料集下拉，主区占满宽度，没有横向滚动。

#### 边界与异常

库读取失败时显示错误与诊断，不显示空状态；外部（Agent、工作台）保存后页面按 generation 更新，旧通知不覆盖新数据；`knowledgeFocus` 指向不存在的资料集时按默认规则选中。


### R-PAGE-02 术语表

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

列为：选择框、原词、译法、要求（必须 / 优先 / 保留原文）、启用开关、更多。表格末尾有常驻的新增行（回车保存，焦点回到原词）。双击或按 Enter 进入单元格编辑，失焦或回车保存，Esc 取消。「更多」打开右侧抽屉，编辑别名、备注、匹配方式、区分大小写，并查看来源。表格上方有资料集内搜索与「批量粘贴」。

#### 验收标准

- AC-PAGE-02-1: 在新增行输入原词和译法后回车，条目立即出现在表格中并启用，新增行清空，焦点回到原词输入框。
- AC-PAGE-02-2: 编辑一条术语的译法后按回车保存；保存失败（如 revision 冲突）时单元格恢复原值并显示错误，并提供刷新入口。
- AC-PAGE-02-3: 切换要求下拉或启用开关会立即保存；停用的行文字变淡，并带「已停用」标记。
- AC-PAGE-02-4: 抽屉中修改别名、备注、匹配方式后保存，表格对应行更新；抽屉关闭后焦点回到触发它的「更多」按钮。
- AC-PAGE-02-5: 批量粘贴两列表格（制表符或逗号分隔）时，先预览识别结果（新增 / 与已有相同 / 与已有冲突）；确认后只写入新增项，冲突项可选择「用粘贴内容覆盖」。
- AC-PAGE-02-6: 有 300 条术语时，表格滚动流畅，并分页显示，每页 100 条。

#### 边界与异常

原词或译法为空时不能保存并提示；与本资料集已有相同译法时禁止添加，原词相同而译法不同时提示但允许保存；「保留原文」时译法随原词；保存失败（含 revision 冲突）时回滚并提示，冲突后自动刷新。


### R-PAGE-03 说明

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

「说明」标签分「要求」与「背景」两个区块，每条显示正文（多行）、「重要」标记、启用开关、更多（编辑 / 删除）；每个区块底部有常驻的新增输入框（多行，Ctrl/⌘+Enter 保存）。

#### 验收标准

- AC-PAGE-03-1: 在「要求」区块新增一条，勾选「重要」后保存，条目出现在要求列表中，带「重要」标记并启用。
- AC-PAGE-03-2: 行内编辑正文，保存后列表更新；正文为空时不能保存，并给出提示。
- AC-PAGE-03-3: 停用的说明显示「已停用」标记且文字变淡，切换启用开关后立即生效并恢复正常样式。

#### 边界与异常

正文为空时不能保存并提示；编辑中按 Esc 取消，不保存。


### R-PAGE-04 资料集管理

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

一个资料集对话框同时用于新建和编辑：名称（必填）、翻译方向（必填，新建时默认取上次使用的方向）、说明（可选）。资料集头部的菜单提供：编辑、导出此资料集、归档 / 取消归档、删除。

#### 验收标准

- AC-PAGE-04-1: 新建资料集时只需填写名称和方向；保存后侧栏出现该资料集并自动选中，主区显示术语表的空状态与新增行。
- AC-PAGE-04-2: 编辑资料集的方向时，如果已有条目，显示提示「条目将随资料集改为新方向」，确认后保存。
- AC-PAGE-04-3: 归档后，资料集移入侧栏的「已归档」分组，且不再出现在工作台选择器中；取消归档后恢复原位。
- AC-PAGE-04-4: 删除资料集需要确认，确认框中显示条目数和受影响的预设数；删除后支持撤销（见 R-PAGE-05）。

#### 边界与异常

名称为空或语言代码无效时不能保存；已归档的资料集只读（不显示新增行与批量粘贴），取消归档后才能编辑。


### R-PAGE-05 多选操作与删除撤销

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

术语表和说明都支持多选（选择框、Shift 范围选择、全选当前页）。选中后出现操作条：启用、停用、移动到其他资料集、删除。任何删除完成后，底部显示「已删除 N 项 · 撤销」提示，持续 10 秒；撤销调用 `restoreRecords`。

#### 验收标准

- AC-PAGE-05-1: 选中 3 条后点击「停用」，3 条全部停用，选择清空，提示「已停用 3 条」。
- AC-PAGE-05-2: 选中 2 条术语并移动到另一资料集时，目标列表只列出同方向的资料集；移动后条目从当前列表消失，并出现在目标资料集中。
- AC-PAGE-05-3: 删除 2 条后点击「撤销」，2 条按原内容恢复，并回到列表中。
- AC-PAGE-05-4: 删除资料集后撤销，资料集、全部条目以及预设中的引用都被恢复。
- AC-PAGE-05-5: 撤销时库已被其他操作改变（例如同 id 已存在），提示「无法撤销」及原因，不进行部分恢复。

#### 边界与异常

只能移动到同方向、未归档的资料集，没有时提示；撤销遇到其他保存造成的 generation 变化时重读后重试一次；目标记录 id 已存在时不做部分恢复并提示原因。


### R-PAGE-06 导入与导出对话框

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

导入：选择或拖入文件 → 预览（按资料集列出状态与数量，每个资料集可选择新增 / 合并 / 另存为副本 / 跳过；冲突处理方式；是否导入预设）→ 导入后跳到第一个导入的资料集。导出：勾选资料集（默认当前资料集）、「包含停用条目」、「包含相关预设」→ 显示警告（如有）→ 保存。

#### 验收标准

- AC-PAGE-06-1: 拖入 v2 示例包后，预览列出各资料集的状态与条目数；导入完成后跳到第一个导入的资料集；拖入非 v2 文件时显示「不支持的资料包版本」，不进入预览。
- AC-PAGE-06-2: 导入与本地同 id 的资料集时，默认动作为「合并 + 保留本地」，并显示新增、不同、相同的数量。
- AC-PAGE-06-3: 导出时内容包含疑似凭据或本地路径的，对话框列出警告位置，用户仍可选择继续保存；取消保存时不写文件。

#### 边界与异常

拖入多个文件或非 `.fktk.json` 文件时提示并忽略；预览过期（库已变化）时提示重新导入；导出时取消保存对话框不写文件。


### R-PAGE-07 引导与 Agent 上下文

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P1 |

#### 说明

引导缩为 3 步：资料集、术语与说明、在工作台勾选。Agent 页面上下文改为当前资料集、可见条目、选中条目。

#### 验收标准

- AC-PAGE-07-1: 点击引导按钮后依次高亮侧栏资料集列表、术语表新增行、「前往字幕工作台」，共 3 步，可跳过。
- AC-PAGE-07-2: 在资料页对 Agent 说「把选中的这几条设为必须」时，Agent 上下文包含选中条目的 id 与 revision，并能据此生成卡片。

#### 边界与异常

库为空、页面加载中或有对话框打开时不自动开始引导；Agent 上下文只包含摘要、id 与 revision，不包含来源备注与网址。


### R-PAGE-08 文案清理

| 字段 | 值 |
| --- | --- |
| 来源 | BR-06 |
| 状态 | deferred |
| 批次 | I4 |
| 优先级 | P1 |

#### 说明

`src/locales/{zh,zh-Hant,en,ja}` 下的 knowledge、materials、studio、home、tools 只保留在用的键；四语键一致。

#### 验收标准

- AC-PAGE-08-1: 脚本扫描 `t("…")` / `t('…')` 的用法，与文案键对比，结果为没有未使用的 knowledge 键、没有缺失的键；四种语言的键集合一致。

#### 边界与异常

动态拼接的键用有限类型或清单列出，未知诊断码回退到诊断自带的信息。
