# 翻译资料 v2：业务范围与路线图

业务目标与范围的权威来源；具体 AC 在模块 requirements.md。

## 背景、目标与成功条件

### 现状问题（已对照代码核实，细节见 [总体设计 · 现状](architecture.md#1-现状与问题)）

| 用户看到的 | 实际 |
| --- | --- |
| 方案与风格 → 翻译方案 | 只有「读取哪些资料集 + 一段要求 + 一段内容说明」生效；继承偏好、积累译文、建议对象、建议保存位置四组字段未实现 |
| 方案与风格 → 翻译风格 | 只是一组规则条目的引用，规则必须属于已选资料集，而已选资料集的规则本来就全部参与；风格不增不减任何规则，只多一层校验报错 |
| 方案与风格 → 偏好模板 | 除管理页外没有任何代码读取 |
| 内容对象 + 适用范围 / 使用条件 | 整篇与批量翻译丢弃逐句说话人绑定和条件确认，只有试译（≤20 句）可绑定；实际只有「主题」能生效 |
| 表达习惯 / 参考译文 | 「仅保存」，不参与翻译；资料页三个标签都看不到它们 |
| 6 种状态 + 审核 | 手动写的内容也默认待审核；待审核 / 待确认 / 待确认导入 / 需重新审核并存 |
| 维护 | 归档、恢复、彻底清除历史、导入撤销、维护与导入记录，各有预览与确认流程 |

### 目标

把翻译资料从「可交换的知识库协议」收敛为用户一句话能说清的模型：

> **一个资料集 = 一个作品 / 主播 / 系列的词典和备忘；翻译时勾选要用哪几本。**

- 概念：资料集（带一个翻译方向）＋ 两类内容：**术语**（原词 → 译法）、**说明**（背景 / 要求）。工作台另有**预设**（常用的资料集组合与翻译要求）。
- 状态：条目只有「启用 / 停用」。保存即生效，没有审核。
- 维护：新建、编辑、停用、删除（可撤销）、资料集归档、导入、导出。
- 数据结构同步收敛（FK-TK/2），不留只在界面隐藏的死字段。

### 成功条件

1. 首次启动新版时，旧资料库原样移入待处理归档文件夹，应用以空库开始；新代码不含任何读取或转换旧格式的逻辑。
2. 用户新建资料集 → 加术语 → 在字幕工作台勾选 → 翻译生效，全程不需要理解对象、方案、风格、审核。
3. 代码中不再有 subjects / styles / recipes / preferenceTemplates / expression / memory / approvals / review 的任何痕迹（生产代码与测试均不含）。

## 原则（跨批次不变）

| 原则 | 含义 |
| --- | --- |
| 历史数据作废，代码保持干净 | 当前不是正式版，历史数据不做兼容：旧资料库只移入归档文件夹（不删除）以便日后由 AI Agent 按新规范重建；其余旧数据（冻结记录、偏好、旧资料包）按作废处理。新代码中没有任何旧格式的读取或转换。 |
| 确认即生效 | Agent 卡片、记入资料对话框、导入预览本身就是确认环节；确认后直接生效，不再有第二道审核。AI 推断 / 网页来源在卡片上明确标注。 |
| 单一事实来源 | 协议只在 `src/translation-knowledge/schemas.ts`。 |
| 不扩权 | Agent 仍不能删除资料（只能新建、修改、停用）；联网与发送范围不变。 |

## 范围外

- 云同步、多人协作、跨进程并发写入。
- 经典字幕翻译器接入资料（现状不接入，保持）。
- 自动学习（无确认的后台积累）。
- 旧版数据的迁移与兼容（见 [总体设计 §3](architecture.md#3-旧版数据直接作废不做兼容)）；按旧资料重建新资料由用户借助 AI Agent 完成，应用只在 Skill 文档中给出做法。
- 资料修订历史浏览 / 回滚界面（磁盘保留最近若干代用于故障恢复，不做界面）。

## 业务需求

### BR-01 收敛的数据模型

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明

用 FK-TK/2 取代 FK-TK/1：资料集（名称、说明、翻译方向、是否归档）、条目（术语 / 背景 / 要求，启用开关，可选来源）、预设（名称、翻译方向、资料集组合、翻译要求、内容说明）。删除对象、风格、偏好模板、方案、表达习惯、参考译文、来源实体、派生关系、审核状态与批准记录。存储只认当前格式：遇到其他版本的存储时整体移入归档文件夹后以空库开始；存储只保留最近若干代以便故障恢复。

#### 验收要点

v2 示例包导入后可在页面与工作台使用；在隔离目录放入任意非当前版本的存储，启动后文件原样出现在 `archive/<时间戳>/`，资料库为空且可正常写入。

### BR-02 旧记录、旧设置与旧文件兼容

| 字段 | 值 |
| --- | --- |
| 状态 | retired |
| 批次 | I1 |

#### 说明

2026-10-12 用户决定历史数据直接作废、不引入兼容逻辑，本需求废弃。旧资料库的去向见 BR-01（移入归档文件夹）。

#### 验收要点

无。

### BR-03 工作台按资料集与预设选用资料

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I2 |

#### 说明

翻译、试译、批量翻译、转写后自动翻译、一致性检查、AI 修订统一使用新选择结构：翻译方向 + 资料集 + 本次排除条目 + 翻译要求 / 内容说明。选择器提供「预设」（保存 / 应用 / 重命名 / 删除）和「最近使用」，去掉对象 / 角色 / 条件确认。

#### 验收要点

在工作台勾选资料集或应用预设后试译与正式翻译生效；保存当前选择为预设后可在下次直接应用；资料集被删除时预设与选择给出明确提示而不是报错崩溃。

### BR-04 Agent 与记入流程确认即生效

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I2 |

#### 说明

Agent 的检索、目录、准备变更工具与卡片改用新模型；记入资料（记住译法、修订后记入、一致性检查保留写法）不再有「保存后直接启用」开关，确认即生效；AI 推断 / 网页来源以来源标注呈现。

#### 验收要点

复现 agent-knowledge-loop 的「把泰姆菲尔德家的大小姐记到绝区零资料」场景：一轮内出现卡片，确认后条目启用并可在工作台选用；卡片与结果中不再出现对象 / 方案 / 待审核。

### BR-05 简单直观的翻译资料页

| 字段 | 值 |
| --- | --- |
| 状态 | deferred |
| 批次 | I3 |

#### 说明

页面只有一层导航（资料集列表 + 全局搜索），主区是当前资料集的「术语表」与「说明」两个标签；术语表行内增改、批量粘贴、多选停用 / 启用 / 移动 / 删除；高级字段放右侧抽屉；删除可撤销；导入导出各一个对话框；引导更新。

#### 验收要点

新用户在不看引导的情况下完成「建资料集 → 加 3 条术语 → 加 1 条要求 → 停用 1 条 → 删除并撤销」；页面不再出现方案、风格、模板、对象、待审核、维护记录入口。

### BR-06 外围一致

| 字段 | 值 |
| --- | --- |
| 状态 | deferred |
