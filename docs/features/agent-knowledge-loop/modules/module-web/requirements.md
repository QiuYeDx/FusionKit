# web 需求

需求行为只在这里定义；L 的业务目标来源于 brd.md。不要在 tasks/record 另写一套期望。

## 目标与范围

为 Agent 提供免密钥的联网查证：在主进程按用户开启的来源检索和读取公开网页，结果附来源，供 Agent 核对作品中的人名、地名、术语译法并写入带来源的资料提案。

2026-10-10 用户确认（Q-01）：不接需要密钥的通用搜索；首选维基百科，二次元相关优先萌娘百科、百度百科，可选 B 站游戏 Wiki、主流搜索引擎或游戏官网。实测可用性见 design.md。

## 范围外

需要密钥或登录的服务；绕过验证码、反爬挑战或站点访问限制；下载文件、执行页面脚本；向任何站点发送资料库或字幕全文。

## 需求

### R-WEB-01 联网检索与读取

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P0 |

#### 说明

主进程服务提供两个能力：按来源检索（返回标题、链接、简短摘要、来源）与读取页面（返回标题、链接、正文纯文本 ≤8000 字、访问时间）。来源：维基百科（中/日/英）、萌娘百科（经镜像 moegirl.uk）、百度百科（词条摘要卡片）、B 站游戏 Wiki（按 Wiki 代号）、必应搜索（可带 `site:` 限定到游戏官网等站点）。已知 Wiki 页面的读取使用其接口获取纯文本，其他公开页面取主要正文。

#### 验收标准

- AC-WEB-01-1: 在检索维基百科「绝区零」时，返回包含该词条的结果（标题、维基百科链接、去除标记的摘要），语言随参数选择 zh（简体）/zh-Hant（繁体）/ja/en；中文维基与萌娘百科的摘要与正文转换为所选字形。
- AC-WEB-01-2: 在检索萌娘百科、B 站游戏 Wiki（代号 zzz）时，返回对应站点的词条结果与链接；百度百科按词条名返回摘要卡片（描述、简介与部分信息栏）。
- AC-WEB-01-3: 在必应检索「绝区零 site:zenless.hoyoverse.com」时，返回解析出的网页结果（标题、链接、摘要），不含广告与站内导航链接。
- AC-WEB-01-4: 在读取维基百科或萌娘百科页面链接时，返回该词条的纯文本正文（截断到 8000 字）与访问时间；读取一般网页时返回去除脚本、样式与导航后的正文文本。
- AC-WEB-01-5: 在来源返回错误、超时或结构异常时，返回稳定错误码（`web_lookup_failed` / `web_lookup_timeout` / `web_lookup_blocked`），不抛出未处理异常。

#### 边界与异常

每次检索最多 8 条结果；检索词 ≤200 字；B 站 Wiki 代号仅允许小写字母、数字、下划线、短横线。请求使用应用网络代理设置，标明 FusionKit 用户代理。页面内容由脚本绘制、HTML 中没有正文时，以页面自带的描述（description / og:description）作为正文。

### R-WEB-02 安全与隐私边界

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P0 |

#### 说明

读取页面只允许公网 http/https 地址；拒绝本机、内网、链路本地等地址（含重定向后与域名解析后的地址）；限制重定向次数、响应大小、超时与内容类型；不带 Cookie 与凭据。只发送检索词与页面链接，不发送资料库或字幕内容。渲染进程未开启联网时不发起任何请求。

#### 验收标准

- AC-WEB-02-1: 在读取 `http://127.0.0.1`、`http://localhost`、`http://192.168.1.1`、`file:///`、`ftp://` 或解析到内网地址的域名时，返回 `web_lookup_blocked`，不发出请求。
- AC-WEB-02-2: 在公网地址重定向到内网地址时，停止跟随并返回 `web_lookup_blocked`；重定向超过 3 次返回 `web_lookup_failed`。
- AC-WEB-02-3: 在响应超过 2 MiB 或内容类型不是网页/文本/JSON 时，停止读取并返回 `web_lookup_failed`。
- AC-WEB-02-4: 在设置未开启联网时，Agent 的联网工具返回 `web_lookup_disabled`，主进程不收到请求。

#### 边界与异常

检索来源的接口地址为固定白名单，不接受渲染进程提供的任意主机。直连时，连接本身也只使用公网解析结果（防止检查后解析结果改变）。198.18.0.0/15（基准测试保留段）不视为内网：代理客户端的 fake-IP 模式用它应答所有公网域名并转发到真实站点，没有局域网使用该段；2026-10-10 实测本机即为此模式，拒绝它会使维基百科等来源全部不可用。

### R-WEB-03 联网查询设置

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P1 |

#### 说明

设置页新增「Agent」分组：「允许 Agent 联网查询资料」开关（默认关闭，说明会向所选站点发送检索词）；各来源开关与说明（维基百科、萌娘百科（镜像）、百度百科默认开启，B 站游戏 Wiki 与必应搜索默认开启/关闭见设计）；B 站游戏 Wiki 代号列表。设置持久化，四语言。

#### 验收标准

- AC-WEB-03-1: 在首次打开设置的「Agent」分组时，联网开关为关闭；开启后重启应用仍为开启。
- AC-WEB-03-2: 在关闭某一来源时，Agent 检索该来源返回 `web_source_disabled`，其他来源照常。
- AC-WEB-03-3: 在填写 B 站 Wiki 代号「zzz」后，检索 B 站游戏 Wiki 未指定代号时使用它；代号格式不合法时不能保存并提示。

#### 边界与异常

最多 10 个 B 站 Wiki 代号。

## 约束

不新增依赖（使用现有 axios 与主进程代理配置）。界面文案四语言并通过 `pnpm run i18n:check`。不绕过任何验证码或访问限制。
