# studio 需求

需求行为只在这里定义；L 的业务目标来源于 brd.md。不要在 tasks/record 另写一套期望。

## 目标与范围

让字幕工作台的 AI 修订与翻译资料互通：修订时参考该文档已选用的资料；修订确立了可复用的译法时，在用户应用修订后克制地询问是否记入资料。

## 范围外

修订只改原文（听写纠错）时不提示记入资料（没有译文对应关系）；不在用户未应用修订时提示；不改变修订预览的应用与撤销规则。

## 需求

### R-STUDIO-01 修订参考已选资料

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P1 |

#### 说明

修订对话框读取该文档当前的翻译资料选择（翻译对话框中选过的方案/资料集与源语言）。有可用选择且修订涉及译文时，修订请求携带该选择；主进程按资料解析规则（已采纳、语言对、范围、字面命中）为每个请求块挑选命中的术语、要求和背景，随修订请求发送，并要求模型在修订译文时遵循。对话框显示所用资料。

#### 验收标准

- AC-STUDIO-01-1: 在文档已选用含「テイムフィールド家のお嬢様 → 泰姆菲尔德家的大小姐」已采纳术语的资料集、修订译文时，发往模型的请求包含该术语且只关联到命中原文的条目；未命中的条目不附带该术语。
- AC-STUDIO-01-2: 在文档没有资料选择或只修订原文时，修订请求与现状相同（不读取资料库）。
- AC-STUDIO-01-3: 在修订对话框中，有资料选择时显示「参考资料：<方案名或资料集名>」，没有时不显示该行。

#### 边界与异常

资料解析产生的问题（需确认的条件、冲突）不阻止修订：只使用可直接解析的条目。资料库读取失败时按无资料修订，不报错中断。

### R-STUDIO-02 识别可沉淀的译法

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

修订涉及译文时，模型可在修订结果中附带「可复用的译法约定」（专有名词、称谓、反复出现的术语、用户说明中规定的写法），每个请求最多 5 条。主进程只保留原文字面出现在本块原文、译文出现在修订后（或沿用的）译文中的条目，跨块去重，整次修订最多 10 条，并记录关联的字幕。修订预览在有此类条目时提示「应用后可记入翻译资料」。

#### 验收标准

- AC-STUDIO-02-1: 在修订把多处「时间菲尔德家的大小姐」改为「泰姆菲尔德家的大小姐」且模型返回该约定时，修订结果含一条原文「テイムフィールド家のお嬢様」、译文「泰姆菲尔德家的大小姐」的提示，关联被修订的字幕。
- AC-STUDIO-02-2: 在模型返回的约定原文不出现在任何条目原文、或译文不出现在修订后译文中时，该约定被丢弃；重复约定只保留一条。
- AC-STUDIO-02-3: 在只修订原文时，请求不要求、结果不包含此类提示。

#### 边界与异常

约定文本须可保存（无 `<` `>`、控制字符），每段不超过 200 字；模型未返回或返回格式不合法时视为没有提示，不影响修订本身。

### R-STUDIO-03 应用修订后询问记入资料

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

用户应用修订后，若被应用的修订关联了可沉淀的译法，且这些译法并非资料库中已存在的同译法条目，工作台显示一条提示「AI 修订中有 N 条译法可以记入翻译资料」，提供「记入翻译资料」与关闭。点击打开批量记入对话框（R-KNOWLEDGE-04），预填这些译法、文档语言对和该文档所选的资料集。

#### 验收标准

- AC-STUDIO-03-1: 在应用了带提示的修订后，工作台出现该提示；点击「记入翻译资料」打开预填的批量记入对话框。
- AC-STUDIO-03-2: 在提示的译法已全部以相同译文存在于资料库，或用户取消勾选了所有关联修订后应用时，不显示提示。
- AC-STUDIO-03-3: 在关闭提示、切换文档或撤销该次修订后，提示消失且该次修订不再提示。

#### 边界与异常

提示不打断编辑，不自动打开对话框；同一时刻最多一条该提示，新的修订替换旧提示。

### R-STUDIO-04 术语一致性检查

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

用户可在字幕预览工具栏对当前文档、或在文档列表对所选文档（最多 20 个、合计最多 5000 条字幕）发起「一致性检查」，可填写重点（如“人名和地名”）。检查使用 AI 翻译模型配置：模型逐块列出反复出现的名称/术语及其各种译法、疑似同一名称的不同原文写法；应用在全部字幕上按字面回数出处，得出「同一原文多种译法」「同一名称多种原文写法」两类问题组；文档选用了翻译资料时，已启用术语的规定译法作为推荐写法，并标出未按资料翻译的位置。结果按组列出写法、出处数量与推荐写法，可展开查看每处字幕。检查不修改任何内容。

#### 验收标准

- AC-STUDIO-04-1: 在文档译文中「テイムフィールド家のお嬢様」被译成「泰姆菲尔德家的大小姐」3 处、「时间菲尔德家的大小姐」1 处时，检查结果有一组，列出两种写法及出处数，推荐出现最多的写法，展开可见每处字幕的序号与文本。
- AC-STUDIO-04-2: 在文档选用的资料中有已启用术语「ホロウ → 空洞」、而部分字幕译为「虚空」时，结果有一组，推荐写法为「空洞」并标明来自翻译资料。
- AC-STUDIO-04-3: 在对两个文档检查时，同一组的出处来自两个文档并标明文档名；超过 20 个文档或 5000 条字幕时不发起请求并说明原因。
- AC-STUDIO-04-4: 在模型列出的名称在字幕中只有一种写法、或原文/译法不出现在字幕中时，不形成问题组；模型返回格式错误时显示错误，文档不变。
- AC-STUDIO-04-5: 在模型把同一名称的写法分成几项报告（如「センパイ（又写作 先輩）」与「先輩（又写作 せんぱい）」）时，凡共用写法的合为一组；组内只列字幕中实际出现的写法及各自次数，以出现最多的写法为组名；同一写法不出现在两个组里。（2026-10-10 用户测试反馈）

#### 边界与异常

检查可取消；进行中或文档有翻译任务时仍可检查（只读）。文档在检查后被修改，应用时按下一需求处理。

### R-STUDIO-05 确认统一与撤销

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

用户为每组选择标准写法（候选写法之一或自行输入），勾选要统一的组；「统一」对每个涉及的文档执行一次字面替换编辑（不再调用模型）：译文中的其他写法替换为标准写法；原文写法的统一方向由用户在该组的写法中单选（默认出现最多的写法），其余写法全部改为所选写法：只有原文写法不一的组，勾选该组即统一原文；同时有译法差异的组，另需勾选「同时统一原文写法」。当前文档的统一可用工作台撤销；结果中提供「撤销本次统一」恢复所有文档。勾选「记入翻译资料」的组在统一后的回执中提供「记入翻译资料」，点击打开批量记入对话框，预填「原文 → 标准写法」（不自动弹出，避免叠加窗口）。

#### 验收标准

- AC-STUDIO-05-1: 在选择「泰姆菲尔德家的大小姐」为标准并统一后，所有出处的译文包含标准写法、不再包含被替换写法，其余文字不变。
- AC-STUDIO-05-2: 在统一后点击「撤销本次统一」，所有涉及文档的译文恢复原样；当前文档也可用 Ctrl+Z 撤销。
- AC-STUDIO-05-3: 在检查后某文档被修改（版本变化）时统一，该文档被跳过并说明，其余文档照常统一。
- AC-STUDIO-05-4: 在勾选某组「记入翻译资料」并统一后，回执显示「记入翻译资料」，点击后打开批量记入对话框，预填该组原文与标准写法。
- AC-STUDIO-05-5: 在文档未翻译、只有原文写法不一的组时，勾选该组后「统一」按钮可用并显示将修改的条数；同一组只能选一个统一方向，切换方向后条数随之变化；统一后原文按所选写法改写；这类组不提供「记入翻译资料」。（2026-10-10 用户测试反馈：此前这类组无论如何勾选都显示「统一 0 组（修改 0 条）」）

#### 边界与异常

单个文档单次最多修改 1000 条（沿用编辑上限）；超过时该文档不统一并说明。翻译任务进行中的文档不可统一（只读检查仍可用）。

## 约束

修订使用 AI 翻译模型配置（与现状一致）；资料只读，写入经批量记入对话框由用户确认。文案四语言并通过 `pnpm run i18n:check`。不新增依赖。契约以 `src/subtitle-studio/cue-revision-contract.ts` 为准。
