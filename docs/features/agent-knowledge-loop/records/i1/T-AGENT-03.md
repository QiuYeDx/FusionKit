渲染审查（设计基准见 module-agent 设计），初版后发现并修复：

2. 展开后另起一个带内部滚动条的方块 → 嵌套滚动、视觉断裂 → 其余行接续在同一底色列表内、随对话滚动 → 复验 `05`：一个连续列表。
3. 完成态「已保存 1 项」只计条目，漏掉对象与资料集 → 用实际计数 → 复验 `02`：「已保存：新建 1 个对象，新建 1 个资料集，新增 1 条；已启用 1 条。」
4. 仅修改时摘要写「存入」不贴切 → 无新增时用「「X」中：修改 1 条」 → 复验 `07`。
5. 英文「1 new collection(s)」生硬（项目未使用复数键）→ 改为「new collections: 1」并以「·」连接 → 复验 `08`。
