## 用户测试反馈修复（2026-10-10）

用户在 8 个文档、1756 条字幕上检查得到 10 组「原文写法不一」，但无论怎么勾选都显示「统一 0 组（修改 0 条）」，且「センパイ（还写作 先輩）」与「先輩（还写作 せんぱい）」给出相反的修改方向。原因与修正：

- 变更条数与编辑计划都要求先有译文标准写法，未翻译文档的原文写法组标准写法为空，于是计 0 条、被跳过。现在译文统一与原文统一分开计算与执行；原文统一方向在组内单选（默认出现最多的写法），只有原文差异的组勾选即生效；没有译文的组不显示「记入翻译资料」。
- 替换时若新写法包含旧写法（バトさん → シロバトさん），已是新写法的位置不再被重复替换。
- 出处列表每行只列一次，同时标出该行的原文写法与译法。截图：screenshots/05-source-spellings-dark.png（已审阅）。
