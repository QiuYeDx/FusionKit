# 外部 Agent 接入：工具面 需求

需求行为只在这里定义；业务目标见 ../../brd.md。不要在 tasks/record 另写一套期望。

## 目标与范围

渲染进程中的外部工具宿主，以及外部 Agent 可用的精选工具。工具建立在字幕工作台、翻译资料等现有 IPC 之上，与界面共享数据与访问控制；不包裹内置 FusionKit Agent 的工具执行器（见 spec.json A-01）。

## 范围外

内置 Agent 的经典页面队列工具、网页查询；使用 FusionKit 自身任务模型的翻译流水线（字幕 AI 翻译、长文本翻译，2026-10-14 用户确认不开放）。名称翻译在 I1–I3 范围外，I4 以“外部 Agent 自己给出译名”的方式开放（R-TOOLS-12）。

## 需求

### R-TOOLS-01 外部工具宿主

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

应用启动后渲染进程安装工具宿主并向主进程声明就绪。宿主收到调用后按共享目录再次校验参数、分派到工具实现、把结果或稳定错误码回传；每次调用记入外部连接活动（工具名、状态、时间），供界面展示。

#### 验收标准

- AC-TOOLS-01-1: 在应用启动完成后，主进程收到就绪声明；在此之后的调用被分派到对应工具实现并回传结果。
- AC-TOOLS-01-2: 在工具实现抛出异常时，回传 `{ ok: false, error: "tool_failed" }` 及截断到 600 字符且已脱敏（不含任何已配置 API Key）的原因，宿主继续服务后续调用。
- AC-TOOLS-01-3: 在调用被取消时，工具收到中止信号，回传 `cancelled`。
- AC-TOOLS-01-4: 在调用完成后，外部连接活动中出现该调用记录（客户端、工具、成功/失败），每个连接最多保留最近 50 条。

#### 边界与异常

宿主只服务目录中存在的工具；目录外的名字回传 `unknown_tool`。参数二次校验失败回传 `invalid_arguments`。

### R-TOOLS-02 首批读取工具

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

`get_fusionkit_status`：应用版本、界面语言、当前页面、信任档位、Agent/任务模型是否已配置（只给是否与模型显示名，绝不给 Key 或地址）、字幕工作台文档总数、进行中的工作台翻译/转写任务数。`list_studio_documents`：按关键字、格式、状态分页列出工作台文档的 documentId、revision、名称、格式、句数、翻译状态、进行中的任务。

#### 验收标准

- AC-TOOLS-02-1: 在已配置模型的应用中调用 `get_fusionkit_status`，结果包含版本、界面语言、当前路由、信任档位、modelConfigured 布尔值与模型显示名、工作台文档数；序列化结果中不出现任何 API Key 或接口地址。
- AC-TOOLS-02-2: 在工作台已有导入文档时调用 `list_studio_documents`，得到与工作台界面一致的文档及 documentId/revision；按关键字过滤只返回匹配文档；分页给出 total 与 nextOffset。
- AC-TOOLS-02-3: 在工作台为空时调用 `list_studio_documents`，得到 total=0 的空列表而不是错误。

#### 边界与异常

列表每页最多 50 条；名称截断到 255 字符。

### R-TOOLS-03 信任档位与应用内确认

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

工具分三类：读取；写入（改动 FusionKit 内数据或启动任务，可撤销或可取消）；破坏性（覆盖已有文件）。翻译资料变更与破坏性一样「总是确认」。只读档拒绝写入与破坏性；确认档写入需确认；自动档写入直接执行；总是确认的操作在任何档位都需确认。确认以应用内全局对话框出现（任意页面），写入类可勾选「本次连接内允许此类操作」。工具最多等待 45 秒，未决时返回 `confirmation_pending` 与确认 ID，外部 Agent 用 `get_confirmation_result` 继续等待；用户稍后允许时操作照常执行并保存结果。

#### 验收标准

- AC-TOOLS-03-1: 在只读档下调用任一写入或破坏性工具，主进程直接返回 `read_only`，不转发、不弹确认；读取工具照常可用。
- AC-TOOLS-03-2: 在确认档下调用写入工具，FusionKit 弹出对话框，标明客户端名称、操作与对象（文档名、文件名或路径）；用户允许后工具返回成功结果，拒绝后返回 `declined_by_user` 且数据不变。
- AC-TOOLS-03-3: 在确认档下允许时勾选「本次连接内允许此类操作」，同一连接的同类写入不再询问；另一连接或连接断开重连后重新询问。
- AC-TOOLS-03-4: 在自动档下调用写入工具不弹确认直接执行；调用破坏性工具（覆盖同名文件）或翻译资料变更仍弹确认，且对话框不提供本次连接放行选项。
- AC-TOOLS-03-5: 在用户 45 秒内未决定时工具返回 `confirmation_pending` 与 confirmationId；之后用户允许，`get_confirmation_result` 返回该操作的结果；用户拒绝或 10 分钟未决定，返回 `declined_by_user` 或 `confirmation_expired`；连接关闭时其未决确认作废。
- AC-TOOLS-03-6: 在多个确认同时等待时，对话框按到达顺序逐个显示并标出剩余数量；默认焦点在「拒绝」；FusionKit 窗口未聚焦时任务栏闪烁提示（不抢焦点）。

#### 边界与异常

确认对话框内容由 FusionKit 根据参数生成，不显示外部 Agent 自由填写的说明文字。拒绝、过期不留下部分写入。

### R-TOOLS-04 工作台文档读取

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

`read_studio_document`：按句分页（每页最多 100 句）返回文档摘要、译文轨道列表（ID、语言、名称、来源、是否为外部 Agent 所建且可写）、各句 ID/序号/起止时间/原文；指定 trackId 时附带该轨道各句译文、来源、是否已审校、是否已过期。未在本窗口列出过的文档也能读取（工具自行补齐访问）。

#### 验收标准

- AC-TOOLS-04-1: 在工作台有一份 2 句的字幕时调用 `read_studio_document`，得到 2 句的 cueId、序号、startMs/endMs 与原文，以及 revision 与 nextOffset=null。
- AC-TOOLS-04-2: 在指定外部 Agent 已写入的轨道时，返回各句译文及 origin=ai、reviewed=false；原文被改动后的译文标为 stale=true。
- AC-TOOLS-04-3: 在应用重启后未打开工作台页面、外部 Agent 直接按 documentId 读取时，读取成功；documentId 不存在时返回 `document_not_found`。

#### 边界与异常

`limit` 1–100；`offset` 超出句数返回空句列表。

### R-TOOLS-05 按路径导入字幕

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

`import_studio_subtitles`（写入类）：导入外部 Agent 给出的字幕文件或文件夹路径（最多 20 个路径；文件夹取其中字幕文件，子文件夹仅 recursive=true），返回每项结果与新文档的 documentId/revision。

#### 验收标准

- AC-TOOLS-05-1: 在确认档允许后导入一个含 2 个 SRT 的文件夹，返回 importedCount=2 及两份文档摘要，工作台列表随即出现这两份文档。
- AC-TOOLS-05-2: 在路径中没有字幕文件时返回 `no_subtitles_found`；单个文件解析失败只记在该项结果中。

#### 边界与异常

路径不做「用户亲手输入」校验（外部 Agent 以用户身份运行，见 A-02）；导入受工作台已有数量与大小上限约束。

### R-TOOLS-06 新建译文轨道与批量写入译文

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

`create_studio_translation_track`：在文档上新建空译文轨道，标记为由外部 Agent（客户端名）所建，返回 trackId 与新 revision。`write_studio_translations`：一次最多 200 句，按 cueId 写入外部 Agent 的译文，记为 AI 来源、未审校；整批校验，任一句不合法则整批不写；一次写入在工作台中是一步可撤销的编辑；只允许写入外部 Agent 所建的轨道。两者同属「编辑字幕译文」类，共享本次连接放行。

#### 验收标准

- AC-TOOLS-06-1: 在确认档允许后新建轨道并写入 2 句译文，工作台打开该文档可见新轨道与 2 句译文，标为 AI 译文、未审校；工作台的撤销可一步撤回这次写入。
- AC-TOOLS-06-2: 在译文含 `<` 或 `>`、为空或超长时，整批返回 `invalid_translation_text` 并列出问题句 cueId，文档不变。
- AC-TOOLS-06-3: 在 revision 过期时返回 `revision_conflict` 与当前 revision；向非外部 Agent 所建轨道写入返回 `track_not_writable`。
- AC-TOOLS-06-4: 在工作台的执行记录入口中，外部 Agent 所建轨道不显示「旧翻译没有执行记录」，而是不提供执行记录入口。

#### 边界与异常

轨道数受工作台每文档 100 条上限约束；轨道名默认为客户端名称，可传入名称覆盖。

### R-TOOLS-07 导出

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

`export_studio_document`：按 source / target / bilingual 与格式（默认沿用工作台规则）导出到源文件所在文件夹，或由用户在系统保存对话框中选择位置；冲突策略 indexed（加序号，写入类）或 overwrite（覆盖，破坏性）。需要确认的有损项默认接受并在结果中列出；阻断项返回错误。

#### 验收标准

- AC-TOOLS-07-1: 在确认档允许后以 bilingual 导出外部 Agent 所建轨道到源文件夹，源文件夹出现双语 SRT，内容含原文与译文，结果给出文件名。
- AC-TOOLS-07-2: 在自动档以 overwrite 导出时仍弹确认并标明会覆盖同名文件；拒绝则文件不变。
- AC-TOOLS-07-3: 在导出计划有阻断问题（如缺少译文且选择阻断）时返回 `export_blocked` 与问题列表，不写文件。

#### 边界与异常

源文件夹不可用（如源文件已移走）时返回 `source_directory_unavailable`，提示改用 choose-location。

### R-TOOLS-08 本地转写

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P1 |

#### 说明

`start_studio_transcription`（写入类）：用已安装的本地模型把给定音视频路径转写进工作台（不启用自动翻译与自动导出，由外部 Agent 后续处理），返回任务列表；进度用 `get_studio_tasks`。

#### 验收标准

- AC-TOOLS-08-1: 在本地转写运行时或模型不可用时调用，返回明确错误码（如 `transcription_not_ready`），不留下草稿。
- AC-TOOLS-08-2: 在工作台已有未提交的转写草稿时返回 `transcription_drafts_pending`，不改动用户草稿。
- AC-TOOLS-08-3: 在条件满足并获允许时，转写任务入队，返回 taskId 列表；本批不启用自动翻译，用户原有的工作台自动翻译设置在入队后恢复。

#### 边界与异常

每次最多 100 个媒体文件；路径不做「用户亲手输入」校验（A-02）。

### R-TOOLS-11 转换字幕格式与提取语言

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P0 |

#### 说明

- `convert_subtitle_files`：按路径（文件或文件夹，可选包含子文件夹）转换字幕格式。参数：路径（1–50 个）、目标格式（SRT / VTT / LRC / ASS / SSA / SBV）、输出位置（原文件旁，或指定文件夹）、重名处理（编号 / 覆盖）、LRC 转为其他格式时最后一条的默认时长。源格式按扩展名判断；与目标格式相同的文件跳过并说明。
- `extract_subtitle_language`：按路径从双语字幕中提取一种语言（中、日、英、韩、法、德、西、俄、葡），输出保持原格式；参数中的路径、输出位置、重名处理同上。
- 两者与经典页面使用同一转换 / 提取实现，按 UTF-8 读取；一次最多处理 200 个文件。属于写入（确认组“转换与提取文件”）；重名处理为“覆盖”时在任何档位都确认。确认框由 FusionKit 根据参数生成：文件数、前若干个文件名（含完整路径）、目标格式或保留的语言、输出位置与重名处理。
- 结果逐个文件列出：源文件、输出文件（成功时）或失败原因；不返回文件内容。

#### 验收标准

- AC-TOOLS-11-1: 在外部 Agent 给出一个含 3 个 ASS 文件的文件夹并要求转为 SRT、输出在原文件旁时，“修改前询问”档位弹出确认（3 个文件、SRT、原文件旁、编号）；确认后 3 个 SRT 写在原文件旁，结果列出 3 个输出路径。
- AC-TOOLS-11-2: 在输出处已有同名文件且重名处理为“编号”时生成“名称 (1).srt”；为“覆盖”时即使在“自动执行”档位也弹出确认，确认后替换。
- AC-TOOLS-11-3: 在外部 Agent 要求从双语 SRT 提取中文时，输出只含中文行的 SRT；不是字幕的文件、无法解析的文件在结果中逐个说明原因，其余文件照常处理。
- AC-TOOLS-11-4: 在“只读”档位两个工具都返回 `read_only`；路径不存在时返回 `path_not_found`；超过 200 个文件时返回 `too_many_files` 且不写入。

#### 边界与异常

- 源格式与目标格式相同的文件不写出、在结果中标为跳过，也不列入确认框；没有需要转换的文件时直接返回结果，不请求确认。
- 写入失败（权限、磁盘）在该文件的结果中说明，不影响其他文件；已写出的文件不回滚（与经典页面相同）。

### R-TOOLS-12 按外部 Agent 给出的名称重命名文件与文件夹

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P0 |

#### 说明

- `inspect_name_paths`（读取）：按路径（1–50 个）列出要改名的条目：路径、类型（文件 / 文件夹）、当前名称、身份标识；可选列出文件夹内的子项（最多 2000 条）。受保护的系统路径与不存在的路径被拒绝并说明。
- `rename_paths`（写入，任何档位都确认）：外部 Agent 给出条目（路径、身份标识、新名称，最多 500 条）；FusionKit 先核对（非法字符、与已有文件重名、目标重复、条目已变化），有问题时不弹确认、直接返回逐条问题；没有问题时弹出确认，列出“旧名 → 新名”；确认后按“由深到浅”执行，失败自动回滚，返回改名数与撤销编号。新名称只能是名称，不能含路径分隔符（不能移动位置）。
- `undo_name_changes`（写入，任何档位都确认）：按撤销编号撤销一次重命名（与名称翻译页的撤销相同）。
- 不调用任何模型：译名由外部 Agent 自己生成。

#### 验收标准

- AC-TOOLS-12-1: 在外部 Agent 检查一个含 2 个文件、1 个子文件夹（内含 1 个文件）的文件夹并给出 4 个新名称时，FusionKit 弹出确认列出 4 行“旧名 → 新名”；确认后 4 项都改名（子项先于文件夹），结果含撤销编号。
- AC-TOOLS-12-2: 在新名称含 `/`、`\`、`:` 等非法字符、与同目录已有文件重名或两条目标相同时，返回逐条问题且不弹确认、不改名；条目在检查后被移动或替换（身份标识不符）时返回该条被拒绝。
- AC-TOOLS-12-3: 在用 `undo_name_changes` 撤销后，4 项恢复原名；“自动执行”档位下 `rename_paths` 与 `undo_name_changes` 仍弹出确认，用户拒绝时返回 `declined_by_user` 且不改名。
- AC-TOOLS-12-4: 在“只读”档位 `rename_paths`、`undo_name_changes` 返回 `read_only`，`inspect_name_paths` 正常返回。

#### 边界与异常

- 名称翻译页正在执行重命名或撤销时返回 `busy`，不排队。
- 改名过程中失败时按现有执行器回滚；回滚不完整时结果说明，并可在名称翻译页的恢复入口处理。

### R-TOOLS-13 经典工具任务与页面

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P1 |

#### 说明

- `get_classic_tasks`（读取）：列出用户在经典工具页（字幕 AI 翻译、格式转换、语言提取）中的任务：工具、文件名、状态、进度、输出路径（完成时）、失败原因；每个工具最多 50 条。不包含字幕或文件内容。
- `open_fusionkit_page` 增加经典工具页面：字幕 AI 翻译、格式转换、语言提取、文件名翻译、本地字幕转写、长文本翻译。

#### 验收标准

- AC-TOOLS-13-1: 在用户已在格式转换页加入 2 个任务（1 个完成、1 个等待）时，`get_classic_tasks` 返回这 2 条及各自状态，完成的含输出路径。
- AC-TOOLS-13-2: 在外部 Agent 要求打开“文件名翻译”页面时，FusionKit 切换到该页面。

#### 边界与异常

没有任务时返回空列表；页面名不在列表中时返回 `invalid_arguments`。

## 约束

- 工具名、说明、输入 schema 只在 `src/agent/external/catalog.ts` 定义一次，主进程与渲染进程共用；该模块只依赖 zod 与纯契约模块。
- 结果有界：列表分页、文本截断；不返回本机绝对路径以外的敏感信息，不返回 API Key 与接口地址。
- 工具说明使用英文（与内置 Agent 工具一致），面向外部模型。
