# 外部 Agent 接入：活动记录 需求

需求行为只在这里定义；业务目标见 ../../brd.md（BR-05）。不要在 tasks/record 另写一套期望。

## 目标与范围

让用户随时知道外部 Agent 对 FusionKit 做了什么：每次调用留下可读的记录（跨重启保留），在独立的「外部 Agent 活动」页面按连接查看与筛选，并从记录直接打开相关文档、撤销重命名或在文件夹中显示输出；未经询问就执行的改动由标题栏指示和不抢焦点的提示告知。

## 范围外

- 不记录、不显示工具参数原文、字幕正文、译文、翻译资料以外的文件内容、令牌与 API Key。
- 不在活动页面重新执行或回放外部 Agent 的调用；字幕工作台的改动在工作台里撤销（记录提供打开文档的入口）。
- 不导出记录文件，不上传到任何服务。
- 内置 FusionKit Agent 的操作不进入本记录（它有自己的会话与消息历史）。

## 需求

### R-ACTIVITY-01 记录每次外部调用并保存在本机

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I5 |
| 优先级 | P0 |

#### 说明

FusionKit 为外部 Agent 的每次工具调用写一条记录，包括主进程直接拒绝、窗口不可用、超时与取消的调用。记录内容：

- 连接：会话 id、客户端名称与版本；连接开始与结束时间单独记录。
- 调用：工具、读取 / 写入 / 破坏性、开始时间与耗时。
- 放行方式：不需要确认（读取）、你在确认框中允许、本次连接已放行、自动档未询问、你拒绝、确认已过期、只读档拒绝。
- 结果：成功、失败（错误代码与不超过 300 字的原因）、已拒绝、等待你确认、已取消。等待确认的调用在你稍后决定或确认过期后更新为最终结果。
- 摘要：FusionKit 按调用写出的可读内容（对象名称、路径、数量、目标格式等，与确认框同源），以及执行后的结果数字（如写入条数、转换成功 / 跳过数）。
- 后续操作所需的引用：相关字幕文档、重命名的撤销记录、输出文件路径。

记录保存在本机（用户数据目录），保留最近 30 天；改动类记录（写入与破坏性工具，含失败与拒绝）最多 2000 条，读取类记录另外最多保留最近 1000 条；超出时删除最旧的。可一键清空。

#### 验收标准

- AC-ACTIVITY-01-1: 在外部 Agent 先后调用读取工具与写入工具后，记录按时间顺序出现这两次调用，含客户端、工具、放行方式、结果与耗时；写入记录的摘要写出对象名称与数量。
- AC-ACTIVITY-01-2: 在只读档下外部 Agent 调用写入工具，记录出现该调用，放行方式为只读档拒绝；在确认框中拒绝，记录为“你拒绝”；勾选“本次连接内允许”后再次写入，第二条记录的放行方式为“本次连接已放行”；自动档下的写入为“自动档未询问”。
- AC-ACTIVITY-01-3: 在调用返回“等待确认”后，你稍后在确认框中允许并执行成功，同一条记录更新为成功并带执行结果；确认过期则更新为已过期。
- AC-ACTIVITY-01-4: 在重启 FusionKit 后，此前的记录与已结束的连接仍可查看；早于 30 天的记录、超出上限的最旧记录被删除；清空后记录与已结束的连接全部消失，当前连接保留。
- AC-ACTIVITY-01-5: 在写入译文、拆分 / 插入字幕的记录与保存的记录文件中，找不到字幕正文与译文文字、令牌与工具参数原文；记录文件中单条记录不超过 8 KB。

#### 边界与异常

- 记录文件损坏的行被跳过，其余记录照常读取；文件无法写入时调用照常执行，不因记录失败而失败。
- 摘要中的条目最多保留 20 项，其余记为“另有 N 项”。
- 不在主进程信任渲染端提供的会话、客户端与工具：这些由主进程自己的调用信息决定；渲染端只补充摘要、放行方式与引用，且经长度与结构校验。

### R-ACTIVITY-02 「外部 Agent 活动」页面

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I5 |
| 优先级 | P0 |

#### 说明

独立页面（`/external-agent`）。左侧是连接列表：「全部连接」与每个连接（当前连接在前，显示客户端名、连接状态与时长或结束时间、改动数与问题数）；底部是保留说明与「清空记录」。右侧是所选连接的概况（客户端与版本、连接时间、当前信任档位；当前连接可断开）和按日期分组的时间线。时间线可筛选：改动（默认）/ 全部（含读取）/ 有问题（失败、拒绝、只读档拒绝、过期）。每条记录一行显示时间、可读的一句话、放行方式与结果；展开后显示条目、结果数字、错误说明与耗时，并提供可用的后续操作：

- 打开文档：转到字幕工作台并打开该文档（文档已删除时提示）。
- 撤销这次重命名：经你在 FusionKit 中确认后撤销（已撤销或无法撤销时说明原因）。
- 在文件夹中显示：转换、提取写出的文件（导出的结果只返回文件名，记录中显示文件名）。

新调用实时出现在时间线中；等待你确认的调用显示为“等待你确认”。接入未开启且没有记录时，页面说明并提供前往设置的入口。

#### 验收标准

- AC-ACTIVITY-02-1: 在一个连接调用若干读取与写入工具后打开活动页面，左侧出现该连接（当前连接、时长、改动数），右侧默认只显示改动；切到“全部”后出现读取记录；切到“有问题”只显示失败与拒绝。
- AC-ACTIVITY-02-2: 在页面打开时外部 Agent 再写入一次，新记录不刷新页面即出现在时间线顶部。
- AC-ACTIVITY-02-3: 在展开一条写入译文的记录并点「打开文档」后，进入字幕工作台并预览该文档；在展开一条重命名记录并点「撤销这次重命名」、在确认后，文件恢复原名，记录显示已撤销；转换记录的「在文件夹中显示」打开输出所在文件夹。
- AC-ACTIVITY-02-4: 在点「清空记录」并确认后，时间线与已结束的连接消失，当前连接保留且之后的调用继续记录。
- AC-ACTIVITY-02-5: 在 1280×860 与 900×700、浅色与深色、中文与英文下，含长文件路径、长客户端名、多日记录与失败记录时，页面不溢出、不重叠，时间线在自己的区域内滚动；键盘可在连接列表、筛选与记录展开之间操作，焦点可见。

#### 边界与异常

- 时间线分批加载（每次 100 条），滚动到底继续加载。
- 读取类记录的摘要可以只是工具的可读名称加对象名（如文档名）。
- 撤销重命名只对“重命名”记录且有撤销引用时提供；不对字幕工作台的改动提供撤销（在工作台撤销）。

### R-ACTIVITY-03 标题栏指示与未询问改动的提示

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I5 |
| 优先级 | P0 |

#### 说明

标题栏中原来的连接圆点改为一个可点击的小指示（位于应用名左侧，不会被 Windows 悬停时出现的窗口按钮遮挡）：有连接时显示圆点与客户端名（多个连接时显示连接数）；正在执行调用时圆点有动态；有等待你确认的请求时显示提醒色；有“未查看的未询问改动”时显示数字。点击进入活动页面（定位到相应连接）；进入活动页面即视为已查看。没有连接也没有未查看改动时不显示。

改动在未询问的情况下成功执行（本次连接已放行或自动档）时，FusionKit 显示一条不抢焦点的轻提示，例如“claude-code 写入了 12 条译文 · 查看”；同一连接 5 秒内的多次改动合并为一条（“claude-code 做了 3 项改动”）。用户正在活动页面查看该连接时不提示。设置 → 外部 Agent 中可关闭这类提示（默认开启）。

#### 验收标准

- AC-ACTIVITY-03-1: 在外部客户端连接后，标题栏出现带客户端名的指示；断开后指示消失（没有未查看改动时）；点击指示进入活动页面并选中该连接。
- AC-ACTIVITY-03-2: 在本次连接已放行写入译文后，外部 Agent 连续写入 3 次，只出现一条合并提示，指示显示未查看数 3；点提示中的「查看」或指示进入活动页面后数字消失。
- AC-ACTIVITY-03-3: 在确认框中允许的改动不弹提示、不计入未查看数；关闭“未询问改动的提示”后不再弹提示，指示的数字照常。
- AC-ACTIVITY-03-4: 在提示与指示出现时，FusionKit 窗口不获取焦点、不改变当前页面。

#### 边界与异常

- 未查看数只统计未询问就成功执行的改动，最多显示 99+。
- 指示的悬停说明写出连接数与未查看改动数。

### R-ACTIVITY-04 设置页的入口与开关

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I5 |
| 优先级 | P1 |

#### 说明

设置 → 外部 Agent 的“当前连接”区域增加「查看活动记录」入口（每个连接也可直接进入其活动），并增加“未询问就执行的改动显示提示”开关（与接入设置一起保存在本机）。

#### 验收标准

- AC-ACTIVITY-04-1: 在设置页点「查看活动记录」进入活动页面；点某连接的活动入口时选中该连接。
- AC-ACTIVITY-04-2: 在关闭提示开关并重启 FusionKit 后，开关仍为关闭。

#### 边界与异常

无。
