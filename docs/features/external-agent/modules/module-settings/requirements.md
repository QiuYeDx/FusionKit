# 外部 Agent 接入：设置与接入体验 需求

需求行为只在这里定义；业务目标见 ../../brd.md。不要在 tasks/record 另写一套期望。

## 目标与范围

让用户开启、配置、接入、观察和管理外部 Agent：设置页、连接指示与活动、各客户端配置片段、随附 Skill 与说明文档。

## 范围外

主进程端点与鉴权（module-bridge）；工具行为与确认浮层本身（module-tools）。

## 需求

### R-SETTINGS-01 设置页「外部 Agent」

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

设置页新增「外部 Agent」分区（`/setting?tab=external`）：开关与运行状态（含地址与端口冲突错误）、信任档位（三选一并说明）、端口、令牌（默认遮挡，可显示、复制、重置并二次确认）。

#### 验收标准

- AC-SETTINGS-01-1: 在设置页切到「外部 Agent」并打开开关，状态显示运行中与 `http://127.0.0.1:<端口>/mcp`；关闭后显示已关闭。
- AC-SETTINGS-01-2: 在端口被占用时，状态显示端口被占用的说明；改为空闲端口后恢复运行。
- AC-SETTINGS-01-3: 在切换信任档位后，设置立即保存，之后外部调用按新档位执行。
- AC-SETTINGS-01-4: 在令牌默认遮挡的状态下点「显示」可见完整令牌，「复制」写入剪贴板；「重置令牌」经确认后令牌改变，旧连接断开。
- AC-SETTINGS-01-5: 在 1280×860 与 900×700、浅色与深色、中文与英文下，分区内容不溢出、不重叠，长地址与路径在代码块内横向滚动而不撑宽页面。

#### 边界与异常

非法端口（非 1024–65535 整数）就地提示并不保存。

### R-SETTINGS-02 连接指示与最近操作

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P1 |

#### 说明

设置分区列出当前连接（客户端名与版本、连接时长、最近一次操作及成败），可逐个断开；有连接时标题栏应用名旁出现小圆点（悬停说明连接数）。

#### 验收标准

- AC-SETTINGS-02-1: 在外部客户端连接并调用工具后，设置分区出现该客户端及其最近操作；标题栏出现连接圆点。
- AC-SETTINGS-02-2: 在点击某连接的「断开」后，该连接从列表消失，客户端下一次请求得到会话不存在；无连接时圆点消失并显示空状态。

#### 边界与异常

最近操作只显示工具名与成败，不显示参数内容。

### R-SETTINGS-03 客户端配置片段

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

按客户端（Claude Code、Codex、Cursor、通用 JSON）与方式（HTTP；stdio 桥，可在 FusionKit 未运行时自动启动）生成可直接复制的配置，内容随当前端口、令牌与本机安装路径生成；每个片段附一句放置位置说明。

#### 验收标准

- AC-SETTINGS-03-1: 在接入开启时，各客户端 HTTP 片段包含当前地址与 `Bearer <令牌>`，stdio 片段包含 FusionKit 可执行文件、桥脚本与端点文件的真实路径和 `ELECTRON_RUN_AS_NODE=1`；点「复制」写入剪贴板。
- AC-SETTINGS-03-2: 在生成的 Codex 片段为合法 TOML、JSON 片段为合法 JSON（含 Windows 反斜杠路径）。
- AC-SETTINGS-03-3: 在接入关闭或尚无令牌时，片段区提示先开启接入，不显示含空令牌的配置。

#### 边界与异常

开发模式下 stdio 片段附加应用路径参数，安装版不附加。

### R-SETTINGS-04 随附 Skill 与说明文档

| 字段 | 值 |
| --- | --- |
| 来源 | BR-03 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P1 |

#### 说明

仓库 `.agents/skills/fusionkit-app/SKILL.md` 提供一份很薄的 Skill（何时使用、工作流、领域概念、确认与错误处理，不重复工具说明）；设置分区可一键安装到 Claude Code（`~/.claude/skills/fusionkit-app/`）或 Codex（`~/.codex/skills/fusionkit-app/`）。README（中英）与 `docs/features/external-agent/README.md` 说明接入方法。

#### 验收标准

- AC-SETTINGS-04-1: 在点击「安装到 Claude Code」后，目标目录出现与仓库内容一致的 SKILL.md，界面显示已安装与路径；再次安装覆盖为当前版本。
- AC-SETTINGS-04-2: 在 SKILL.md 中，frontmatter 含 name 与 description，正文说明 FusionKit 须运行且开启接入、翻译工作流与确认处理。
- AC-SETTINGS-04-3: 在 README（中英）中，有外部 Agent 接入小节，说明开启、复制配置、信任档位与安全边界。

#### 边界与异常

安装只写这两个固定目录，失败时提示原因且不留半个文件（临时文件后替换）。
