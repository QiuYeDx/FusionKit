## 实际结果

用户反馈双语 LRC/SRT 被作为独立正文行导入，要求识别原文与旧译文、清除旧译文后重翻译，并将后续导出只更新设计。已登记 R-WORKSPACE-08/T-WORKSPACE-07，在 T04 前实施；T05 增加 original/source 区分及 imported 轨输出验收。授权依据保存在 spec.json，不代表用户已验收当前结果。

旧行为是保真解析后逐 cue 显示，无双语解释；新行为是在保真文档上提供本地候选确认，确认后形成单条原文及 imported/unreviewed 译文。至少三组且 80% 候选具有稳定语言顺序和结构才自动打开预览，其余由手动入口打开。支持前/后侧原文、20 条分页、只看需确认、逐条保持原样、可选空格分界；单行拆分默认关闭，所有单行候选均需复核。最多 1000 项自定义覆盖，超限不破坏有效预览。

双方原节点及 UTF-16 字符范围保留在 importedPair；不排序、不去重、不估算时间，原文件字节完全保留。不同节点且均为单行的精确同时间二元组可以配对；同节点重复 LRC 标签保留，已双行的同时间 SRT 块分别拆分。偏离主要语言顺序、字种不明、相同内容等进入复核筛选。导入译文在 UI 明示“未复核”。

清除选中轨和关联终态任务在一个事务内完成，原文/其他轨/原始证据不变。任意轨 queued/running，或选中轨 interrupted/needs_configuration 时禁止清轨。审查发现公开 removeTask 清理历史任务同样会推进 revision、破坏另一运行任务，已补同文档 queued/running 保护。新翻译只读取分离后的 source，不夹带旧译文。
