# 文档库密度与即时切换

本轮问题：左栏统计/搜索/筛选/底栏占高过多；当前文档高亮等待正文读取，且触发全局禁用闪烁；翻译批次独占第三行。

实施与验收：

- 压缩左栏辅助区域，保留清晰的可操作热区、统计及实际 token 详情；筛选摘要并入选择栏。
- 点击立即改变当前行，正文使用独立加载反馈和淡入淡出；列表、导入和批量操作不因预览读取禁用。
- 沿用串行读取协调器，以导航代次阻止旧响应覆盖最后选择；失败可重试，加载时禁止误操作旧文档。
- 翻译状态及批次进度合并在元数据行，长名称继续中间省略。
- 真实 Electron 验证快速连续点击、延迟/失败响应、背景刷新、深浅主题与窄窗口；记录列表可视高度和截图。

状态：实现及技术验证完成，等待用户验收；未提交推送。

## 实现

- 任务计数同排，实际 token 总量常驻；输入/输出、统计范围及缺失数据说明通过悬停/键盘聚焦查看，“查看全部”仍显示完整详情。
- 搜索输入框 28px，搜索工具区 40px，筛选信息与全选同排，底栏 37px。保留文件名可读性与复选框热区。运行中的批次以旋转状态图标、状态、`2 / 3` 同排呈现；辅助技术保留完整批次标签。
- 导航请求和已加载页面分离：立即更新请求目标，继续使用单读取协调器，跳过已过期的排队请求，提交前核对导航代次、文档版本和删除记录。读取失败保留目标并可重试；与导入/删除等操作交接时使旧导航失效。
- 预览单独显示 160ms opacity 过渡的加载层；旧内容暂时 inert，防止误操作旧文档。退出动画保留加载内容，支持 prefers-reduced-motion。列表、导入及批量操作不借用预览忙碌状态。
- 根据 FK-PIT-0147 保留后台刷新和操作的隔离，新增 FK-PIT-0152 记录即时导航及旧响应处理规则；同步项目密度约定。
