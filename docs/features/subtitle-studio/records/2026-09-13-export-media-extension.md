# 导出时移除媒体扩展名

用户要求：字幕工作台导出与格式转换工具一致，支持移除媒体扩展名，默认开启，完成后提交推送。

实现：共用媒体扩展名识别规则。先去掉原始字幕格式扩展名，再按开关移除紧邻的单个媒体扩展名（忽略大小写），最后添加可选文件名后缀与输出格式；其他点号和名称片段保留。选项同时参与单份/批量导出计划与文件名预览，关闭可保留媒体扩展名。下载原始文件功能不改变源文件名。

验证：99 项命名、转换器及导出服务回归通过；三端构建、TypeScript、2,257 个 i18n 引用键、435 文件边界和 preload 检查通过。实际 Electron 单份预览开关及批量开/关两种真实文件写出通过，截图已复核，证据：`test-results/studio-smart-export/run-yCafQV/`。源文件内容保持不变。
