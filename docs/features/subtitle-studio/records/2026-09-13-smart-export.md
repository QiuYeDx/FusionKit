# 根据译文内容选择导出方式

用户要求：单份或批量文档均无译文时，只允许并默认仅原文；混合文档仅译文导出时可用原文补齐，双语导出缺译行只保留一遍原文。完成后提交推送。

实现范围：导出配置根据实际译文状态选择默认值和可用模式，空译文轨不作为已有译文；保留默认原文回退，以及用户显式选择的阻止/跳过策略。复核共享导出生成器在 SRT、LRC、VTT、ASS 中的缺译、空译文和过期译文行为，避免重复原文和空输出。

验证完成：

- 73 项导出生成器、导出服务、翻译到导出及批量服务回归通过。新增覆盖四格式的缺译、空白、过期译文与双语顺序，实际输出原文仅一次，源文档不被修改。
- 实际 Electron 用原生文件授权和真实 repository 验证单份/批量纯原文模式限制、混合模式三个选项、仅译文和双语的两批实际 SRT 文件。产物和已复核截图：`test-results/studio-smart-export/run-KURIt4/`。
- 三端构建、TypeScript、i18n 四语言与 2,257 个引用键、preload 和代码边界检查通过。
- 更新旧导出体验用例中的纯原文默认值断言；新界面回归单独覆盖本轮变化。首次新用例仅因把“部分译文”写成“有译文”而失败，修正断言后通过。

底层生成器原已支持默认原文回退和双语缺译行不重复，本轮通过四格式回归与实际混合产物确认，并完善表单和空译文内容判定。
