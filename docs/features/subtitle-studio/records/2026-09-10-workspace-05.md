## 实际结果

沿用本轮继续 I1 的真实授权，T04 验证完成后推进 T05。新增独立导出字幕入口和本地 planner：source 始终投影当前 cue.source，target/bilingual 使用显式译轨，original 下载仍保留原始文件字节。支持 SRT/LRC、两种双语顺序、四编码、BOM/换行；不消费模型配置或发出网络请求。

缺失/过期译文默认阻断，用户可选跳过或回退原文，输出名称及摘要标明 partial。缺少译轨不能伪装成译文导出。真实翻译会跳过的空白 cue 不被误判缺译文。LRC 缺结束时间需显式接受严格更晚起点和可调末组时长估算，不回写源时间。LRC 使用毫秒起点、应用后的实际 offset 时间；已知结束时间、样式、多行或未计时内容的降级明确确认，歧义结构和不可编码字符阻断。

planExport 在 main 保存 owner 绑定的 15 分钟冻结字节计划，一 owner 至多一项，全局最多 8 项/128MiB。保存只接受冻结修订、计划及精确确认类别，不接受 renderer 路径。原生保存对话框期间的新译文提交不影响输出；删除或撤权拒绝。自有同目录临时文件 write/sync/逐字节回读后发布；默认建议名采用 hard-link 无覆盖索引，明确的原生改名/覆盖沿用原生保存授权，失败不先删除旧目标。成功消费计划、失败/取消可重试，计划不持久化。

UI 采用 qiuye-ui-quality 和项目 UI 约定，复用 ScrollableDialog/ToolField/Select、12px 留白、紧凑按钮。缺失和时长策略属于显式选择，避免再重复确认；其他格式变化确认绑定当前计划。选项改变需重查，后台 revision 更新保留已检查内容并提示冻结快照。
