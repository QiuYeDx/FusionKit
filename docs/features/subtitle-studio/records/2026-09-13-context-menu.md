# 字幕文档右键操作

用户授权在现有文档库增加右键操作。本轮先明确规则，再实现与验证；不提交推送。

| 范围 | 规则 | 状态 |
| --- | --- | --- |
| 操作对象 | 右键已选文档使用全部已选项（含跨页项）；右键未选项只处理该项，保留原多选与当前预览 | 已实现 |
| 菜单 | 指针位置打开，碰撞时自动避让视口；顶部显示处理数量；翻译、导出、原文件下载、继续/取消翻译、删除 | 已实现 |
| 执行 | 复用页面级现有控制器与确认流程，冻结文档 ID 范围；重新检查当前版本，不借用全局读取状态 | 已实现 |
| 可访问性 | Shift+F10 / 菜单键打开，方向键选择、Escape 关闭，回到来源行；删除仍二次确认 | 已实现 |
| 生命周期 | 搜索/分页或切换视图不沿用过期菜单；弹窗在宽窄布局切换时保留；未完成跨页全选时不开放含糊范围 | 已实现 |

沿用共享 DropdownMenu 的定位、主题与键盘语义，不新增依赖。菜单不是另一套批量执行器，不改变复选框选择和预览。

验证计划：真实 Electron 导入合成文件，覆盖多选/未选/跨页、取消与实际导出/删除、键盘与焦点、深浅主题、边缘避让、窄窗口；检查类型、多语言、边界及构建。

## 实现与审阅

`StudioLibraryContextMenu` 复用共享 DropdownMenu，保持鼠标定位与键盘导航；`StudioLibrary` 只确定本次作用范围，不触发预览读取或修改复选框。当前右键行显示临时边框，未选项的复选框仍保持未选。

页面级 `StudioTranslation` / `StudioExport` 接受一次性打开请求，共用已有表单、参数和结果状态。管理确认保存独立的文档范围，关闭动画保留确认内容。根据 FK-PIT-0127/0149，控制器继续放在稳定页面层，选择和右键菜单均不经过全局读取操作。

菜单文案不重复“批量”，数量由顶部统一说明；无可继续/取消任务时相应项禁用。关闭菜单或弹窗返回来源行，点击菜单外部则保留用户新点击位置的焦点；原行被删除或布局替换后使用文档库入口作为后备焦点。
