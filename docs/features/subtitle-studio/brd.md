# 字幕工作台业务范围与路线图

## 来源与目标

2026-09-08 用户提出统一字幕语义结构，用于节省翻译冗余、灵活导出、转写复用和未来校正。随后明确要求：新起独立工具；现有工具作为可继续稳定使用的 v1；未来删除 v1 时新版不受影响；转写实现可以参考或复制现有工具，避免质量退步；本轮将设计落实为文档并给出下一步。

“v1”是旧工具身份，不等同于应用版本或文件 schemaVersion。当前 package.json 为 0.3.0，本方案不承诺发布版本号或日期。新版是独立字幕工作台，第一批可单独交付；未完成能力不提供可点击的空操作。

## 范围边界

- v1 范围为现有字幕 AI 翻译工具和本地字幕转写工具。其路由、历史任务、偏好、恢复文件、Agent 入口和运行能力保持原状；不为归档而移动源码或强制改名。
- 当前字幕转换、提取、远程 Audio API 工具不自动归档，也不属于本次替代承诺。
- 应用级导航、主进程注册、preload 接线及构建组合允许增加新版贡献；不得改变 v1 协议、算法、默认值和数据。
- 可复用不归 v1 所有的通用 UI、模型客户端等，但必须审计传递依赖，不能仅凭 shared/common 目录名认定安全。
- 不自动迁移 v1 历史任务/断点、不接管其 Store、不强制切换默认入口。旧内容通过用户选择文件导入，形成新版独立副本。
- 不承诺格式间全部无损、不承诺模型绝对正确或固定 token 节省比例。
- 首批不做协作编辑、完整时间线编辑器、云同步、通用插件系统或新 ASR 引擎。

## 业务需求

### BR-01 独立工具与旧版本共存

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明

新版拥有独立身份、状态、执行与数据边界；v1 正常使用。新版代码、类型、资源和测试不运行依赖待删除的 v1 专属实现。应用组合层可以同时注册二者，移除旧贡献后新版仍可启动。

#### 验收要点

依赖检查及隔离副本中的 v1 实际移除演练证明边界；共存构建回归旧路径。每个可运行增量都复核，完整原生资源移除与打包演练在 I2 补齐。

### BR-02 持久文档与一次翻译多次导出

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明

SRT/LRC 解析为稳定身份的字幕文档，原文与译文轨分离保存。模型处理文本及必要 ID，时间轴留在本地。重启后继续使用已保存结果，选择原文、纯译文或双语并切换支持的导出格式。

#### 验收要点

实际翻译后保留文档；重启再导出不调用 AI、不依赖源文件仍存在；恢复保留已提交译文；降级和未完成项可见；源文件不被隐式覆盖。

### BR-03 继承现有本地转写能力并保持独立

| 字段 | 值 |
| --- | --- |
| 状态 | deferred |
| 批次 | I2 |

#### 说明

冻结并复制完整生产能力闭包，继承有效默认值、原生版本、低音量处理、停顿分块、时间与去重策略。直接输出统一文档，不经 v1 文件或 token 中转。

#### 验收要点

相同原始响应回放保持确定性结果；相同资源与配置做限定真实音频对照；已接受改善不因移植消失，已知缺陷如实保留。资源、运行时、打包和进程不依赖 v1，两套工具的清理互不删除资产。

### BR-04 扩展格式与可解释的保真导出

| 字段 | 值 |
| --- | --- |
| 状态 | deferred |
| 批次 | I3 |

#### 说明

优先扩展 ASS，再按需求增加 WebVTT 等。区分正文、样式、内联控制、绘图、注释和附件，明确解析、保留、翻译、导出的支持等级。

#### 验收要点

普通 ASS 对话可翻译，非文本结构按策略保留；不宣称卡拉 OK 自动重对齐。跨格式损失可预览，不能静默丢失再报告成功。

### BR-05 字幕校正与版本管理

| 字段 | 值 |
| --- | --- |
| 状态 | deferred |
| 批次 | I4 |

#### 说明

支持原文/译文校正、时间编辑、复核状态和多个译文版本；按需求增加拆分合并及撤销。稳定 ID、修订身份和时间来源在 I1 建立，完整编辑历史不提前实现。

#### 验收要点

修改原文只使相关译文过期，排版变化不触发翻译；旧请求不覆盖新文本；源字词时间不冒充译文字词时间；拆分合并可追溯。

### BR-06 双语文件的原译文分离

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明

2026-09-09 用户要求智能识别已存在的双语 SRT/LRC，将原文与导入译文分开，并支持清除质量不佳的译文后重新翻译。通过本地结构与字种证据推荐、预览确认原文方向，不把同时间字幕或多行正文一律自动合并。歧义可保持原样或选择拆分位置。原始文件内容独立保留。

#### 验收要点

用户提供的同时间双行 LRC 与同块双正文行 SRT 可转为统一原文 cue 与 imported 译文轨；单行混排明确需复核。清轨不删原文/原文件，新翻译只读取整理后的原文。原文件下载与原文轨导出区分；source/target/bilingual 导出仍在 T05 实现，不提前展开完整编辑器。

## 批次顺序

| 批次 | 可交付结果 | 进入条件 |
| --- | --- | --- |
| I1 | 独立文档、SRT/LRC 导入、翻译、持久化、预览与多次导出 | 获得实施指令 |
| I2 | 媒体转写→文档→翻译→导出 | I1 文档契约可用；复制时冻结有效生产基线 |
| I3 | ASS 及格式能力声明 | I1 格式边界可用，不强依赖 ASR 算法改进 |
| I4 | 编辑、修订及版本对比 | I1 并发控制可用，临近实施再细化 |

I2/I3 可以按用户优先级交换；默认先保护转写连续性。本轮不开启并行 Agent，不提前创建后续模块任务。
