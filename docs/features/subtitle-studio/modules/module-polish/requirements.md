#### 验收标准

- AC-POLISH-01-1: 转写队列使用紧凑28px图标ghost操作，文件名和元数据间距收紧，按钮hover区别于行hover，长名称和键盘操作保留。
- AC-POLISH-01-2: 翻译计划展开详情的灰色行与边框四周留白一致；排查共享清单消费者，不引入重复padding。
- AC-POLISH-01-3: 结果主要按钮的文本与尾部图标作为整体光学居中，保持36px热区及窄窗换行。
- AC-POLISH-01-4: 工具列表进入/退出字幕工作台时，退场页面不因路由新值提前改变顶部留白，标题栏空间稳定；其他工具路由布局正常。
- AC-POLISH-01-5: 队列与文档预览提供打开所在文件夹；主进程按已授权任务/文档ID解析私有来源，验证身份和存活；缺失/替换/跨owner拒绝，renderer不接收任意路径权。
- AC-POLISH-01-6: 删除队列会话说明及footer区域，释放列表空间。
- AC-POLISH-01-7: 翻译概览显示结构化状态数量与列表全范围（分页前）实际API token输入/输出/总数，未知用量和不可用文档明确标记，不伪装0；最近一批仅有完整有效范围且进行中时显示进度。
- AC-POLISH-01-8: 清理成功项与清理所有终态项的语义清楚；提示明确包含成功/失败/取消，运行和排队任务不被清除，字幕文档保留。
