# I1 独立字幕文档与翻译导出需求

## 目标与范围

来源：BR-01、BR-02。新增字幕工作台，完成 SRT/LRC 导入→文档保存→翻译→只读预览→重启后多种导出。具体结构和技术取舍见 design.md 及根 architecture.md；本文件是 I1 行为和验收标准的唯一来源。

## 范围外

I1 不接原生转写、不实现 ASS、编辑/拆分合并、多用户协作、Agent 新工具调用或 v1 检查点迁移。文档允许多个译文轨；I1 可创建不同语言/模型的新轨，不提供复杂版本对比 UI。已有 Agent 的 v1 工具照常工作。

## 需求

### R-WORKSPACE-01 独立入口与依赖

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

新增工具身份、路由、IPC 和偏好。共用应用壳与经过审计的基础设施，不依赖 v1 的实现、类型、状态或资源。

#### 验收标准

- AC-WORKSPACE-01-1: 在共存构建中，新入口可使用；旧翻译和转写入口、偏好、历史任务及恢复/重试路径未被替换或迁移，相关回归与实际操作有证据。
- AC-WORKSPACE-01-2: 新版传递依赖检查通过；在隔离副本真正移除 v1 专属实现与注册贡献、重新构建后，I1 导入、翻译、重启再导出链路仍运行，且不回读旧目录。

#### 边界与异常

共存需要修改应用组合文件，但不能移动或替换 v1 专属实现。公共模块发现旧依赖时先复制必要纯能力到新版，不能用允许名单豁免旧工具。

### R-WORKSPACE-02 导入与统一结构

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

通过原生选择或授权拖放导入 SRT/LRC，形成新版持久文档。保留原始格式信息与诊断，按 capability 判断可翻译性。

#### 验收标准

- AC-WORKSPACE-02-1: SRT 多行、非连续编号、重叠时间、BOM/CRLF；LRC 元数据、多标签、同时间不同文本、空行和 offset 均有确定解析结果与原节点映射；重排不改变 cue ID，同时间条目不合并。
- AC-WORKSPACE-02-2: 编码不明/失败、倒序时间、过大输入、未知复杂标记或增强型 LRC 都有明确诊断；不静默替换字符、丢正文、去时间标签后假装支持，失败导入不留下可用状态的半份文档。

#### 边界与异常

原文件存在重复编号或重叠时间不等于非法。未知格式不承诺可翻译；用户取消选择/解码修复时不得留下成功文档或修改源文件。

### R-WORKSPACE-03 文档持久化与安全生命周期

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01, BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

文档是任务结束后可继续使用的资产。任务、文档、用户导出文件生命周期分开，数据不借用旧 Store 和恢复文件。

#### 验收标准

- AC-WORKSPACE-03-1: 文档和已提交译文在重启后可读，源文件移走也能预览/导出；模拟提交各阶段失败或索引损坏时可恢复上一完整提交，不能丢失原文或暴露半提交译文。
- AC-WORKSPACE-03-2: 清理完成任务保留文档；显式删除文档取消其任务，迟到响应不能复活或改写内容；已导出文件和 v1 数据不被清理，磁盘快照不含密钥或临时能力 token。

#### 边界与异常

仓库不可写、当前提交损坏和没有任何有效 generation 时明确报告恢复失败；不能自动退回旧 Store 或编造空文档覆盖。删除失败保留墓碑与可重试清理记录。

### R-WORKSPACE-04 纯文本翻译与可靠对应

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

模型只处理正文、必要短 ID/保护标记和有界文本上下文。源编号、时间、元数据与双语排版由本地掌握。

#### 验收标准

- AC-WORKSPACE-04-1: 捕获实际请求证明本次内容和上下文没有程序加入的字幕编号/时间轴/文件元数据/双语原文副本；模型返回乱序 ID 仍正确对应，源时间与原文不变。预估和执行共用预算计划，未知 usage 不显示为零。
- AC-WORKSPACE-04-2: 漏项、重复/未知 ID、截断 JSON、无效标记和超预算单元被明确拒绝；失败批次不提交或错位，只重试该批次；普通译文换行不被当作新 cue，超长文本不被截断。

#### 边界与异常

正文中恰好出现日期、编号或时间字样属于用户文本，不能为了满足请求检查删除。请求检查针对程序额外添加的文件结构。

### R-WORKSPACE-05 恢复、取消与修订保护

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

批次提交与检查点一致，暂停/失败后可继续。复用应用模型能力但不依赖旧翻译运行时，禁止嵌套无限重试。

#### 验收标准

- AC-WORKSPACE-05-1: 已提交一批后模拟错误/关闭，重启继续不重发该批；取消阻止后续派发和迟到写入；失效配置提示修复，不能静默更换模型。供应商结果未知的重试如实记录。
- AC-WORKSPACE-05-2: 源修订、轨道修订、任务 generation 过期时拒绝旧结果；同一文档重复启动不能创建两个活动翻译任务，不同文档不会交叉写入；限流退避可取消且只有一个重试拥有者。

#### 边界与异常

I1 不提供源文本编辑 UI，但通过服务级并发测试守住修订合同。供应商执行状态未知时不能保证恢复不重复计费；无可用配置时保存文档并等待修复，不自动请求其他模型。

### R-WORKSPACE-06 与翻译解耦的导出

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

从固定文档修订投影导出 source/target/bilingual，支持 SRT/LRC、双语顺序及编码/换行选择。原文保留导出与跨格式转换有不同保真能力。

#### 验收标准

- AC-WORKSPACE-06-1: 同一已翻译文档重启后切换纯译文/双语和 SRT/LRC 均可导出，AI 调用计数不增长，翻译状态不失效；SRT 双语共用一块时间轴，LRC 双语由本地生成同标签两行。
- AC-WORKSPACE-06-2: 缺结束时间、时间精度/样式损失、缺失/过期译文均在导出前明确；用户可选择定义好的估算或不完整导出策略，未选择时不能静默导出为完整结果。估算不回写为源测量值。
- AC-WORKSPACE-06-3: 默认同名文件使用索引命名，主动覆盖按原生保存授权执行；失败/取消不覆盖源文件或发布半份结果；导出过程中出现新译文提交时文件仍来自单一已选文档修订。

#### 边界与异常

用户取消损失策略或输出选择时保留文档。无严格更晚的 LRC 起点使用显式末条策略，不按下一数组项直接制造零时长；任何估算仍受有效时间范围约束。

### R-WORKSPACE-07 结构化预览与 IPC 边界

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01, BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

列表和只读详情围绕文档展示，翻译与导出设置分开；敏感文件权限和所有写入由主进程掌握。

#### 验收标准

- AC-WORKSPACE-07-1: 实际 Electron 中可按序号/时间/原文/译文/状态阅读，缺失、处理中、失败和模型未人工复核可区分；长文本、窗口收窄、空文档和分页无内容截失；键盘可操作，四语言无原始 key。
- AC-WORKSPACE-07-2: 越 owner 的文档访问、伪造路径/能力、非法方法和过期 revision 被拒绝；字幕及模型 HTML/脚本只作为数据展示，不执行或自动联网；关闭工作台不破坏 v1 状态。

#### 边界与异常

临时租约过期仅影响相关外部读写，已持久文档仍可查看。页面卸载撤销订阅与自有临时权限，不默认等价于删除文档；任务生命周期由主进程明确管理。

## 约束

所有验证在隔离用户目录和受控输出位置执行；不删除真实 v1 或更改用户保存偏好。真实模型验收只使用明确配置且允许发送的短样本；mock、实际 API、UI 与打包证据分开标注。缺环境保持待验证，不能用构建通过代替实际能力。
