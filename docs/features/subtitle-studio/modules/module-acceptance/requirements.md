# I3 人工验收完善与格式扩展

来源为2026-09-12用户逐项列出的六项人工验收问题及连续实施授权，原话归纳见[问题记录](../../records/2026-09-12-manual-acceptance-findings.md)。保留I1/I2既有数据、权限、原生质量与共享资源契约；此次不开展打包演练、发布或I4编辑器。任务验证与用户整体验收分开记录。

### R-ACCEPTANCE-01 字幕文件拖入

| 字段 | 值 |
| --- | --- |
| 来源 | BR-07 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

拖入和选择文件都进入同一批量导入流程，保留逐项结果和真实来源。

#### 验收标准

- AC-ACCEPTANCE-01-1: 文件拖入有高亮反馈；支持多文件及SRT/LRC/VTT/ASS；非文件拖入、目录、无有效原生File、超量与不支持格式有明确结果，失败文件不影响其他有效文件；忙碌及组件退出不会重复导入或更新过期页面。
- AC-ACCEPTANCE-01-2: preload只从原生File获取路径，固定内部IPC不接受公共invoke绕过；main核验当前窗口/帧/能力，导入与来源记录使用同一受控路径，Windows临时代理不能冒充真实来源。Picker仍可用。

#### 边界与异常

拖入不是任意路径授权；主进程仅处理当前能力和真实File来源，单文件错误隔离，超量整体拒绝。

### R-ACCEPTANCE-02 转写队列批量维护

| 字段 | 值 |
| --- | --- |
| 来源 | BR-07 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

队列头提供清理已完成和已结束记录，用户无需逐条删除。

#### 验收标准

- AC-ACCEPTANCE-02-1: 清理完成/全部终态按触发时任务快照执行，运行中、排队中及清理未结束的记录受到保护；重复触发、部分失败和并发结束有准确反馈；已生成字幕文档仍可打开。
- AC-ACCEPTANCE-02-2: 批量取消清楚标明数量并经用户确认，仅请求取消，等待实际终态和清理完成后才允许移除；空队列与不可用动作正确禁用，窄屏及键盘可操作。

#### 边界与异常

取消不等于已经完成清理，删除队列记录不删字幕文档；并发状态由主进程判定。

### R-ACCEPTANCE-03 翻译任务总览

| 字段 | 值 |
| --- | --- |
| 来源 | BR-07 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

提供独立于当前文档、筛选和分页的全局翻译任务摘要，以及本轮提交任务的真实进度。

#### 验收标准

- AC-ACCEPTANCE-03-1: 主进程从完整文档库汇总排队、运行、完成、失败、取消、中断及待配置数量，明细可定位文档；摘要不包含API key、正文或恢复凭据，不因文档分页漏任务。
- AC-ACCEPTANCE-03-2: 本轮进度使用真实已确认批次数与本轮任务集合，不被历史完成记录稀释；SPA切换、事件和轮询并发不回退新状态；提交完成后可见入队数量，运行/等待/异常与空态明确，宽窄视口均可读。

#### 边界与异常

全局摘要和本轮百分比分开；无本轮集合时不凭历史结果推算进度，坏文档计数可见。

### R-ACCEPTANCE-04 VTT 与 ASS 完整工作流

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

接通导入、可译正文、文档重开、原始文件、同格式及跨格式导出。复杂格式能力明确分级，不宣称任意语法无损转换。

#### 验收标准

- AC-ACCEPTANCE-04-1: WebVTT支持头、时间戳、cue ID、settings、多行正文及基本文本标签；ASS v4+按Events Format解析普通Dialogue、时间与转义正文；导入后重开及普通正文翻译可用，既有SRT/LRC/媒体和双语流程不误走新格式分支。
- AC-ACCEPTANCE-04-2: 原始文件按原字节导出；同格式源轨/译轨/双语通过受支持正文范围补丁保留VTT NOTE/STYLE/REGION及ASS样式、事件前缀、Comment、未知section和附件。绘图、卡拉OK、无法稳定重建的内联控制明确诊断/阻止不安全套译文，不把控制串发模型或静默抹掉。
- AC-ACCEPTANCE-04-3: 四种字幕目标格式支持源/译/双语及媒体文档导出，规范生成可重新解析；跨格式元数据、样式、绘图、时间精度等实际损失在计划中明确并确认。格式筛选、导入提示、导出选择及错误说明一致，严格模式/未完成译文约束保持。

#### 边界与异常

不支持任意ASS渲染器语义及卡拉OK重对齐；复杂结构原样保留并明确译文导出限制，不能静默降级。

### R-ACCEPTANCE-05 输出到来源目录

| 字段 | 值 |
| --- | --- |
| 来源 | BR-07 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

导入文档绑定其原字幕来源，转写文档绑定用户选入的音视频来源，位置在主进程私有持久保存。

#### 验收标准

- AC-ACCEPTANCE-05-1: 单份、批量和原始导出可选择来源目录或另选位置；重启仍可解析来源，多份来自不同目录时逐份输出；转写使用真实音视频输入路径，不从显示名或transcript digest猜路径。
- AC-ACCEPTANCE-05-2: 旧文档无记录及目录不可用明确提示，允许原生选择重新指定并标明是用户重新绑定；不静默回退到下载目录。路径不出现在公共文档/任务摘要，不接受renderer任意路径；目录和文档身份在实际发布时复核，计划过期或来源改变不能沿用旧授权。
- AC-ACCEPTANCE-05-3: 来源目录输出不覆盖输入或其他已有文件，重名安全递增；批量部分失败保留逐项结果。文档仍可在源文件移除后预览、翻译、另存，来源失败不损坏文档。

#### 边界与异常

来源不可用不影响持久文档；只在原生选择后重新绑定，输出同名递增保护；不宣称Node路径API完全无TOCTOU。

### R-ACCEPTANCE-06 默认无额外文件名后缀

| 字段 | 值 |
| --- | --- |
| 来源 | BR-07 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明

默认输出名称为原名称和目标扩展名；用户可选择内容模式、目标语言或自定义后缀。

#### 验收标准

- AC-ACCEPTANCE-06-1: 源轨/纯译/双语/部分译文默认均无.source/.target/.bilingual/.partial；可显式选择预设或自定义后缀，计划预览与实际单份/批量文件名一致，必要的重名序号独立保留。
- AC-ACCEPTANCE-06-2: 后缀限制为合法单一文件名片段，拒绝路径分隔、控制字符及不合法结尾，兼容旧缺省请求；部分译文和损失继续由界面/计划明确显示，不能依赖文件名标记。

#### 边界与异常

无后缀不表示允许覆盖；缺省兼容旧请求，非法自定义拒绝，重名序号及部分译文提示保留。
