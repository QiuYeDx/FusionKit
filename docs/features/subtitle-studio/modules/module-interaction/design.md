# I6 交互与密度设计

## 现状与约束

基线3855c2c加I5完整未提交工作树。用户十项新反馈涉及信息层级和局部状态；不提交、不打包，不改变原生File、自动翻译、plan/revision/来源保护。

## 方案与取舍

导出采用设置→检查总览→执行结果三个明确步骤，在同一dialog外壳切换完整内容和标题，焦点移至新步骤标题，不在旧表单末尾悄悄插入状态。回设置保留配置并撤销旧计划，需重新检查；总览显示就绪/受阻数、输出配置和去重变化类型，逐文件详情默认折叠。确认按钮明确表示接受所示变化并执行，继续传递真实acceptedLosses。原生保存取消留在review，失败可恢复。

复制菜单列出原文、译文、双语和带时间的对应选项，打开菜单不复制。未知结束时间不生成假SRT结尾；缺译文时相关选项不可用，过期译文标明。纯文本保留实际所选轨，不暗含时间；选项选择才写剪贴板，成功失败反馈真实。

当前页全选/清除同步更新选择，不经页面busy。跨页匹配查询使用独立局部pending和请求序号/查询/挂载/删除保护，快速清除或改变选择撤销旧请求；保留100上限。后台进度继续静默读取。

## 前端设计基准

沿用FusionKit的ToolPanel/ToolDetailLayout、ScrollableDialog、DropdownMenu、StudioDocumentRow/StudioScrollFade与主题token。队列为名称/动作、紧凑元数据、细进度，自动翻译短标签同排且有完整tooltip；灰槽浅深hover可见，不缩按钮热区。header使用工作台局部紧凑共同尺度，不全局改其他工具。

已选文档上移编码前，编号与名称首行对齐。设置/检查/结果具有不同标题、内容和主按钮；清单默认折叠。共享结果组件复用于导出、原始下载、翻译及根操作结果。删除前必要的作用范围确认与实时任务监控不机械隐藏。

文档左栏由紧凑任务概览面板和占剩余高度的库面板组成；窄窗在文档mobile-controls内提供图标和必要活动/异常数量的一键入口，避免新增占据正文高度的整行。两视图共享标题空间和内容起点，转写保持原可滚动配置。

## 代码落点

root owns docs/四locale、复制组件/纯格式函数、翻译结果接入。admission_design只转写队列；windows_baseline导出分步、共享结果与行样式；ipc_design根index、布局、概览与选择。复制和共享结果通过props交给index owner接入，不交叉写文件。UI由root统一串行调度，正在验收时不得重建dist。

## 验证与风险

纯复制字节/选择竞态针对性测试；最终Electron验证剪贴板、检查不写文件/确认写入来源、结果折叠、可查看失败、hover/行高、标题几何、全选MutationObserver无全页busy/禁用/正文读取。1280×860浅色和786×540深色，长名、focus/失败/快速操作，人工审阅修复复验。两套生产与测试TS、四语、边界、构建/preload、spec/diff；不重跑ASR设备或打包。合成文件/隔离profile/受控HTTP，结束确认独占进程退出。
