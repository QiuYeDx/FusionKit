# structure 需求

需求行为只在这里定义；L 的业务目标来源于 brd.md。

## 目标与范围

字幕预览中合并相邻字幕、编辑与平移时间；作为一次编辑可撤销；转写文档可用；导出正确。删除沿用现有能力。

## 范围外

拆分、插入、调整顺序；按音频对时；跨页合并。

## 需求

### R-STRUCTURE-01 合并相邻字幕

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

选中当前页中 2–50 条连续字幕后，可从工具栏「合并」、右键/更多菜单「合并为一条」或 Ctrl+M 合并。合并结果保留第一条的位置与身份：开始时间为第一条的开始，结束时间为最后一条的结束（最后一条结束未知则仍未知）；原文按顺序拼接并去重（相邻两段规范化后相同、一段包含另一段且较短者不少于较长者一半、或一段是另一段的开头（至少 2 字，识别器重新起句）时只保留较完整的一段；中日韩文字直接相连，其他文字以空格相连）；译文同样处理——所有被合并字幕都有当前译文时合并后的译文为当前译文，否则合并已有译文并标为“原文已变更”。

#### 验收标准

- AC-STRUCTURE-01-1: 在选中截图中的第 19–22 条（双语识别后为第 10、11 条：「先輩みたいに朝から眠そうにしてる方、」/「像前辈这样一大早就犯困的，」与「先輩みたいに朝から眠そうにしてる方」/「像前辈这样一大早就犯困的」）并合并时，结果为一条：开始 00:00:26.780，原文「先輩みたいに朝から眠そうにしてる方、」，译文「像前辈这样一大早就犯困的，」，结束时间与原第二条相同（LRC 为未知）；字幕数减一。
- AC-STRUCTURE-01-2: 在合并内容不同的「こんにちは。」与「元気？」时，原文为「こんにちは。元気？」；合并「Hello」与「world」时为「Hello world」。
- AC-STRUCTURE-01-3: 在选中不连续的字幕、或只选中 1 条时，「合并」不可用并说明原因；合并后的文字超过单条上限时拒绝并说明。
- AC-STRUCTURE-01-4: 在合并后撤销（工具栏或 Ctrl+Z），恢复原来的各条字幕、时间、原文、译文与审阅标记；重做再次合并。

#### 边界与异常

翻译任务进行中不可合并（沿用编辑锁）；合并会停止依赖这些字幕的已暂停任务（沿用删除规则）。合并后的译文来源记为人工编辑。

### R-STRUCTURE-02 调整时间

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

双击时间列、按 T 或菜单「编辑时间」进入行内时间编辑（开始、结束两个输入框，格式 `HH:MM:SS.mmm`，也接受 `MM:SS.mmm` 与秒数）；LRC 等结束时间可留空（未知）。菜单「平移时间…」对所选字幕整体加减毫秒数。校验：结束不早于开始；开始不越过原本未越过的相邻字幕开始时间（不制造新的先后颠倒；LRC 等原本就可能乱序的文档不因此被拒绝）；转写文档结束不超过媒体时长且必须有结束时间。

#### 验收标准

- AC-STRUCTURE-02-1: 在把第 1 条结束时间改为 00:00:05.000 并保存后，时间列显示新时间，导出 SRT 使用该时间；撤销恢复原值。
- AC-STRUCTURE-02-2: 在输入结束早于开始、开始早于上一条开始、或无法解析的时间时，不保存并在输入框下方说明原因。
- AC-STRUCTURE-02-3: 在选中 3 条并平移 +500 ms 时，三条的开始与结束各加 500 ms；会破坏顺序时整体拒绝并说明。

#### 边界与异常

单次最多调整 1000 条（沿用编辑上限）；时间不能为负。

### R-STRUCTURE-03 结构编辑的数据一致性与导出

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P0 |

#### 说明

合并与改时间在转写文档与文本文档中都可用；被改过时间的文档导出时，VTT/ASS/SSA 同格式导出改为重新生成（原文件中的样式、位置等以现有“已省略”提示说明），不再因时间不符而阻断；撤销历史标签为「合并 N 条字幕」「调整 N 条字幕的时间」。

#### 验收标准

- AC-STRUCTURE-03-1: 在转写文档中合并两条或改时间后，文档可保存、重新打开后保持，导出 SRT 时间正确。
- AC-STRUCTURE-03-2: 在 VTT 文档中改了一条时间后导出 VTT，导出成功且该条使用新时间，提示中包含格式信息被省略的说明（若有）。
- AC-STRUCTURE-03-3: 在双语 LRC（已识别）中合并后导出双语 LRC，合并处只输出一次原文与一次译文，时间为第一条的开始。

#### 边界与异常

未改时间的文档导出行为不变。

## 约束

不新增依赖；文案四语言；结构编辑沿用 `CUE_EDIT_LIMIT` 与 `LIMITS.cueBytes`。
