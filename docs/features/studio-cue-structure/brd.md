# 字幕结构编辑与双语导入：业务范围与路线图

业务目标与范围的权威来源；具体 AC 在模块 requirements.md。

## 背景、目标与成功条件

### 用户反馈（2026-10-10）

- 截图：「01某邮局的工作 - ある郵便局のお仕事.lrc」第 19–22 条，00:00:26.780 与 00:00:27.500 两个时间点各有一句「先輩みたいに朝から眠そうにしてる方」与「像前辈这样一大早就犯困的」，是转写时把同一句识别了两次。用户希望：这种相邻重复能由 AI 修订或 Agent 修复——合并为一条，内容去重，开始时间取前一条、结束时间取后一条；并指出工作台目前不能改时间、不能合并，AI 修订与 Agent 也没有打通这些能力。
- 补充：导入这类双语 LRC 时应智能识别，把两种语言分别作为原文和译文，而不是全部平铺为原文。

### 现状盘点（读代码与实测）

- **编辑能力**：`cue-edit-contract.ts` 的操作只有 source / target / clear / review / entries / revise / delete / restore。删除（含撤销）已存在于工具栏、菜单与 Del 键；**没有合并、拆分、插入、改时间**。`timingRevision` 字段存在但从未递增。
- **转写文档**（schemaVersion 2）：`validateDocument` 要求每条字幕的时间与其转写片段完全一致、`timingRevision === 1`，因此任何改时间或合并都会被拒绝。
- **导出**：VTT/ASS/SSA 同格式导出按原文件逐节点打补丁，时间与原文件不符的字幕被视为 `invalid_time` 而阻断；SRT/SBV/LRC 与跨格式导出按 `cue.timing` 重新生成。
- **AI 修订**：提示词写明“每条保持为一条、时间固定”，结果只有文字字段；空文字被拒绝，因此模型无法删除或合并。Agent 的 `studio_prepare_revision` 也只能改文字。
- **双语识别**：识别逻辑已存在（`bilingual.ts`，「双语整理」对话框）。对用户的文件实测：151 个时间戳全部配对（日 → 中，2 对建议核对），`recommended = true`。但：
  - 只在页面上**单个文件**导入后自动弹出（`index.tsx:363`）；多文件导入、Agent 按路径导入都不会提示；
  - 文档有**任何编辑**（AI 修订、删除）后，「双语整理」按钮永久消失（`hasStudioEdits`）——用户截图中已无此按钮；
  - 拆分后无法恢复原样（移除译文只删除译文轨道，被拆走的那一行不会回来）。

### 目标

1. 双语字幕在导入时就被识别为原文 + 译文，无论从哪里导入；识别错了可以一键恢复原样。
2. 用户可以合并相邻字幕、调整时间，和现有删除一样一次撤销；导出结果正确。
3. AI 修订与 Agent 能发现并提出结构修复（合并重复片段、删除无用片段），在预览中由用户确认后一次应用。

### 成功条件

- 导入用户的双语 LRC 后直接得到 151 条带中文译文的日文字幕。
- 用户截图中的重复可在 3 步内修好（选中 → 合并 / 或在 AI 修订预览中勾选合并 → 应用），并可撤销。
- 结构修复不需要模型编造时间：合并的时间由应用按规则计算。

## 范围外

- 拆分一条字幕、插入新字幕、调整字幕顺序（列入后续，见「后续批次」）。
- 基于音频/波形的对时、按音频重新识别；模型给出的时间。
- 已编辑文档的事后双语识别（仍可在未编辑时使用「双语整理」）。
- 跨页合并（字幕预览按 100 条分页，一次合并限于当前页）。

## 跨批次原则

- **一次操作一次撤销**：合并、改时间、AI/Agent 的结构修复都作为一次编辑进入工作台撤销历史。
- **确认后才改**：AI 修订与 Agent 只在预览中提出，用户勾选并应用后才写入（与现有 AI 修订一致）。
- **时间由应用计算**：合并时开始取第一条、结束取最后一条（LRC 无结束时间则保持未知）；模型不提供时间。
- **保留原文件**：文本字幕的原始内容仍保存在文档中（来源文件不被改写）；结构变化后导出改为重新生成。

## 业务需求

### BR-01 双语字幕导入即识别

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明

从任何入口导入的文本字幕，若明显是双语（现有识别判定为推荐），导入后即为原文 + 导入译文；用户可一键恢复为原样导入。

#### 验收要点

用户的双语 LRC 导入后为 151 条日文原文 + 中文译文；多文件与 Agent 导入同样生效；不明显的文件仍按原样导入；可撤销识别。

### BR-02 合并相邻字幕与调整时间

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I2 |

#### 说明

在字幕预览中合并选中的相邻字幕（时间取首尾、文字去重）、编辑单条字幕的开始/结束时间、整体平移所选字幕的时间；均可撤销；转写文档同样可用；导出正确。

#### 验收要点

截图中的重复可合并为一条（00:00:26.780 开始，译文同步合并）；时间可编辑且有顺序校验；撤销恢复原样；导出 SRT/LRC/VTT 正确。

### BR-03 AI 修订与 Agent 的结构修复

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I3 |

#### 说明

应用自身可检测相邻重复；AI 修订可提出合并与删除；Agent 可按用户的话准备合并、删除、改时间，或请 AI 修订找出重复。全部在修订预览中确认后一次应用。

#### 验收要点

截图中的重复被检测为一处合并建议；AI 修订的合并/删除建议显示在预览中并可单独取消；Agent 准备的结构修改不调用模型即可预览；应用后一次撤销。
