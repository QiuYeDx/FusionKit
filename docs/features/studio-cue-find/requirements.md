# 列表内查找替换 需求

## 目标与范围

人工校对时需要在整篇字幕中找一个词（人名、误写、术语），逐个查看并改正。目前只有 Agent 能按文字查找字幕，字幕预览没有搜索框。本次在字幕预览中加入**查找与替换**：Ctrl+F 打开查找栏，在整篇（所有页）的原文、译文中查找，逐条跳转并高亮，可逐条替换或全部替换，替换可撤销。

#### 说明

- 按字面查找（可选区分大小写），范围为原文、译文（当前译文轨）或两者；结果为按文档顺序的匹配字幕及每条中的匹配处数，覆盖全部页。
- 只读：不修改文档；文档修订号不符时按现有规则返回冲突。

#### 验收标准

- AC-FIND-01-1: 250 条的文档中，“法尔童”出现在第 3、120、240 条（第 120 条出现两次）时，查找返回这三条与共 4 处；区分大小写时 “Paris” 不匹配 “paris”，不区分时匹配。
- AC-FIND-01-2: 范围为“译文”时只在当前译文轨的译文中查找；没有译文的字幕不匹配。

#### 边界与异常

- 查找词 1–200 个字符；匹配字幕超过 10000 条时只返回前 10000 条并说明。

### R-FIND-02 替换

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「列表内查找替换」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 编辑操作“替换”：在指定字幕（或全部匹配字幕）的原文和 / 或当前译文轨译文中，把查找词的每一处替换为替换词（可为空）。原文替换与编辑原文相同（对应译文标为原文已变更）；译文替换与编辑译文相同（成为人工译文）。
- 格式：匹配处在同一格式片段内时保留格式；跨越格式片段时按整行替换（与行内编辑相同，局部格式会移除）。
- 替换后为空、或替换词含 `<` `>` 等不能保存的字符时拒绝，文档不变。一次最多替换 1000 条字幕。
- 撤销恢复替换前的原文与译文（一次撤销）。

#### 验收标准

- AC-FIND-02-1: “全部替换”把 3 条中的 4 处“法尔童”替换为“法厄同”，含不在当前页的字幕；撤销后全部恢复。
- AC-FIND-02-2: “替换”只替换当前一条中的所有匹配处，并跳到下一条匹配。
- AC-FIND-02-3: 替换后为空或替换词含 `<` 时拒绝且文档不变；斜体整行的字幕替换后仍为斜体。

#### 边界与异常

- 翻译进行中拒绝（与其他编辑相同）。

### R-FIND-03 查找栏

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「列表内查找替换（Ctrl+F）」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 在字幕列表中按 Ctrl+F（或点列表上方的查找按钮）打开查找栏，焦点进入查找框；已选中的单条字幕中选中的文字作为初始查找词（如有）。
- 查找栏：查找框、匹配计数（“第 3 / 17 条 · 共 21 处”，无匹配时“无匹配”）、上一条 / 下一条（Shift+Enter / Enter）、范围（原文 / 译文 / 全部，有译文轨时）、区分大小写开关、展开替换（替换框、“替换”“全部替换”）、关闭（Esc）。
- 跳转：转到匹配字幕所在页，选中并滚动到该行；当前页中所有匹配处高亮，当前条更醒目。
- 文档改变（编辑、撤销、替换）后自动重新查找；关闭查找栏后清除高亮并回到列表。

#### 验收标准

- AC-FIND-03-1: Ctrl+F 输入“法尔童”，显示“第 1 / 3 条 · 共 4 处”，第 3 条被选中并高亮；Enter 跳到第 120 条（翻到第 2 页），Shift+Enter 回到第 3 条。
- AC-FIND-03-2: 展开替换输入“法厄同”点“全部替换”，计数变为“无匹配”，撤销后又找到 3 条。
- AC-FIND-03-3: Esc 关闭查找栏，高亮消失，焦点回到列表。
- AC-FIND-03-4: 1280×860 浅色与 786×660 深色下查找栏不溢出，按钮可用。

#### 边界与异常

- 翻译进行中替换按钮禁用并说明；查找仍可用。
