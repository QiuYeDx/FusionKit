# 拆分与插入字幕 需求

## 目标与范围

校对时常遇到一条字幕说了两句话（转写把两句合成一条、或一句太长读不完），或者漏了一句（转写漏听、导入的字幕缺行）。本次在字幕预览中支持**把一条字幕拆成两条**（在文字中点选拆分位置，转写文档按字词时间定出拆分时刻）和**在某条前后插入一条新字幕**，两者都可试听、可撤销。

对应 `docs/TODO.md`「字幕工作台：编辑与校对 → 拆分字幕、插入字幕」；`docs/features/studio-cue-structure/brd.md` 将其列为后续批次。

来源：2026-10-11 用户：“你上面说的这些建议都挺好的，可以记录到一个TODO文档，然后再逐一处理”；随后“跑完后提交并推送，然后继续下一项”。

## I2：Agent 拆分与插入字幕（2026-10-14）

人工可以拆分、插入字幕后，Agent 仍只能合并、删除、改时间：用户说“把第 5 条从‘不过’那里拆开”“第 12 条后面漏了一句‘谢谢’”时，Agent 无法完成。I2 让**内置 FusionKit Agent**（准备后由用户在预览中应用，与合并、删除、改时间一致）和**外部 Agent**（MCP，按信任档位确认后执行）都能拆分与插入字幕，操作与撤销沿用 I1 的 `split` / `insert`。

来源：2026-10-14 用户在 v0.5.0 回顾后选定“补齐 Agent 的工作台编辑能力：拆分和插入字幕目前没有对应的 Agent 工具”，要求先写文档再开发（`docs/TODO.md`「v0.5.0 后续」）。

I2 范围外：

- 外部 Agent 拆分时一并拆分用户自己的译文轨，或把译文写入不是它创建的译文轨（与 `write_studio_translations` 相同，只能写它自己的轨道）。
- 一次调用拆分或插入多条（外部 Agent 每次一条；内置 Agent 一次准备的编辑中可含多条，见 R-SPLIT-04）。
- 外部 Agent 合并、删除、改时间、改原文（仍不开放）。

## 范围外

- 调整字幕顺序（拖动排序）。
- Agent 工具中的拆分与插入（I1 范围外；I2 加入，见 R-SPLIT-04、R-SPLIT-05）。
- 拆分时自动重新翻译两半（译文可一并拆分，或留在第一条并标为原文已变更）。

### R-SPLIT-01 拆分一条字幕

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「拆分可利用转写的字词时间定出拆开后的时间」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 编辑操作“拆分”：一条字幕在给定时刻拆为两条——原字幕保留前半文字、结束于拆分时刻；新字幕紧随其后，文字为后半、从拆分时刻开始到原结束。两半文字都不能为空；拆分时刻必须在开始与结束之间（结束未知时只需晚于开始）。
- 译文：可同时给出两半的译文（作为人工译文写入）；不给出时，原译文留在第一条（因原文已改变而标为“原文已变更”），第二条没有译文。
- 建议拆分时刻：按文字中的拆分位置估算。转写文档中这条字幕未改过文字与时间、且转写带有字词时间时，取拆分位置处字词的时间边界；否则按拆分位置前的字数占比在开始与结束之间估算（结束未知时用下一条的开始或开始后 5 秒）。
- 撤销恢复拆分前的文字、时间与译文并移除新字幕；重做得到同样的两条（新字幕的 id 不变）。

#### 验收标准

- AC-SPLIT-01-1: SRT 文档中 1.000–4.000 的“甲。乙。”在“乙”前、2.500 拆分后，变为“甲。”1.000–2.500 与“乙。”2.500–4.000 两条，导出两条；撤销后恢复为一条，重做后两条（第二条 id 与第一次相同）。
- AC-SPLIT-01-2: VTT（保留格式）文档拆分后导出成功，两条都在；拆分后的文档按新时间重新生成（与改时间相同）。
- AC-SPLIT-01-3: 转写文档中带字词时间的字幕，在第二个字词前拆分时建议时刻为该字词的开始时间；改过文字的字幕按字数估算。拆分后文档校验通过（同一转写片段可对应两条字幕），撤销、导出正常。
- AC-SPLIT-01-4: 拆分时刻不在开始与结束之间、或一半为空时拒绝且文档不变；同时给出两半译文时两条都有人工译文，不给出时第一条译文标为原文已变更、第二条无译文。

#### 边界与异常

- 翻译进行中拒绝（与其他编辑相同）。
- 双语导入后成对的字幕可以拆分；新字幕不再与原文件中的译文行成对。

### R-SPLIT-02 插入一条字幕

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「插入字幕」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 编辑操作“插入”：在某条字幕之前或之后插入一条新字幕，给定开始、结束与文字（可选译文，作为人工译文）。
- 约束：新字幕的开始不早于前一条的开始、不晚于后一条的开始（与改时间的顺序规则一致）；结束不早于开始；结束未知只在允许的格式中可以；转写文档的结束须在媒体时长内。
- 撤销移除新字幕；重做插回同一条。

#### 验收标准

- AC-SPLIT-02-1: 在第 2 条之后插入 6.000–7.500“补上的一句”后，它成为第 3 条，导出包含它；撤销后消失，重做后回到第 3 条。
- AC-SPLIT-02-2: 开始早于前一条的开始或晚于后一条的开始、结束早于开始、文字为空时拒绝且文档不变；转写文档中可以插入（结束在媒体内）。

#### 边界与异常

- 翻译进行中拒绝。

### R-SPLIT-03 拆分与插入的界面

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「拆分字幕、插入字幕」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 入口：右键 / 行“⋯”菜单“拆分字幕…”（只选中一条时）、“在上方插入字幕…”“在下方插入字幕…”。
- 拆分对话框：显示原文，点击或用方向键在文字中放置拆分位置（默认在最靠近中间的标点或空格后）；下方预览两条（文字与时间），拆分时刻按建议自动填入、可修改，并注明“按字词时间”或“按字数估算”；每一条可试听；有译文时可选择“同时拆分译文”并在译文中放置拆分位置。
- 插入对话框：开始、结束（默认取前后两条之间的空隙，最长 2 秒）、文字（必填）、译文（有译文轨时可填）；可试听所填时间段。
- 应用后撤销标签“拆分字幕”“插入字幕”；新字幕成为选中行。

#### 验收标准

- AC-SPLIT-03-1: 右键一条字幕“拆分字幕…”，在文字中点击拆分位置，预览两条与建议时刻，应用后列表出现两条且第二条被选中；Ctrl+Z 恢复。
- AC-SPLIT-03-2: “在下方插入字幕…”默认时间在两条之间，填写文字后应用，新字幕出现在其后并被选中；时间不合规时说明原因且不能应用。
- AC-SPLIT-03-3: 1280×860 浅色与 786×660 深色下两个对话框不溢出，长句换行，按钮对齐。

#### 边界与异常

- 选中多条时“拆分字幕…”禁用；翻译进行中两个入口都禁用并说明。

### R-SPLIT-04 内置 Agent 拆分与插入

| 字段 | 值 |
| --- | --- |
| 来源 | 2026-10-14 用户：“补齐 Agent 的工作台编辑能力：拆分和插入字幕” |
| 状态 | active |
| 批次 | I2 |

#### 说明

- 内置 Agent 准备结构编辑的工具（现可合并、删除、改时间）增加两种编辑：
  - **拆分**：指定字幕序号与拆分位置——第二条开头的文字（须在该条原文中恰好出现一次，可用位置序号区分多次出现），可选拆分时刻（不给时按 I1 的建议时刻：字词时间或按字数估算）、可选两半译文（当前显示的译文轨）。
  - **插入**：指定字幕序号、之前 / 之后、文字，可选译文、开始与结束（不给时取与插入对话框相同的默认时间）。
- 与合并、删除、改时间一样只准备、不直接写入：在 AI 修订预览中列出每一项（拆分显示两半文字、拆分时刻与依据；插入显示位置、时间与文字），可试听，用户应用后写入，一次撤销恢复全部。
- 同一次准备中可混合各种编辑；同一条字幕不能同时被拆分与合并 / 删除 / 改时间，同一条字幕的同一侧只能插入一条。
- 应用后 Agent 收到结果（拆分、插入的条数），与现有的合并 / 删除 / 改时间计数一起报告。

#### 验收标准

- AC-SPLIT-04-1: 让 Agent “把第 5 条从‘乙’前拆开”，预览出现一项拆分：两半“甲。”“乙。”、拆分时刻与依据；应用后第 5、6 条为两半，Ctrl+Z 一次恢复为一条。
- AC-SPLIT-04-2: 让 Agent “在第 2 条后插入‘补上的一句’”且不给时间，预览中的时间为插入对话框的默认时间（两条之间的空隙，最长 2 秒）；应用后成为第 3 条。
- AC-SPLIT-04-3: 拆分文字不存在、出现多次且未给位置序号、或拆分后一半为空时返回 `invalid_split`；插入时间不合规时返回 `invalid_time`；同一条被拆分又被删除时返回 `overlapping_edits`；以上情况都不打开预览，文档不变。
- AC-SPLIT-04-4: 一次准备中含 1 项改时间、1 项拆分、1 项插入，预览列出 3 项，应用后一次撤销全部恢复；应用后 Agent 收到含拆分与插入条数的结果。

#### 边界与异常

- 翻译进行中、或已有修订预览打开时，与现有结构编辑相同地拒绝（`edit_blocked` / `revision_already_open`）。
- 准备与应用之间文档被修改时，与现有结构编辑相同地提示文档已变化、不写入。

### R-SPLIT-05 外部 Agent 拆分与插入

| 字段 | 值 |
| --- | --- |
| 来源 | 2026-10-14 用户：“补齐 Agent 的工作台编辑能力：拆分和插入字幕” |
| 状态 | active |
| 批次 | I2 |

#### 说明

- 外部 Agent（MCP）新增两个工具：
  - `split_studio_cue`：文档、修订号、字幕 id、拆分位置（第二条开头的文字，可选出现序号）、可选拆分时刻（毫秒；不给时按建议时刻）、可选两半译文（只能写它自己创建的译文轨）。
  - `insert_studio_cue`：文档、修订号、锚点字幕 id、之前 / 之后、开始与结束（毫秒，结束可为空——仅在格式允许时）、文字、可选译文（只能写它自己的译文轨）。
- 两者改变的是所有译文轨共用的字幕结构与原文，属于新的确认类别“修改字幕结构”：“只读”档位拒绝；“修改前询问”档位每次在 FusionKit 中确认（确认框由 FusionKit 根据参数生成：文档名、字幕序号、两半文字与拆分时刻 / 插入位置、时间与文字），可在本次连接内放行这一类别；“自动执行”档位直接执行。放行“写入译文”不包括本类别，反之亦然。
- 每次调用是工作台中的一次可撤销编辑（撤销标签“拆分字幕”“插入字幕”）。返回新修订号、新字幕 id，拆分还返回实际拆分时刻与依据。
- 外部 Agent 的说明文字与随附 Skill 介绍这两个工具：何时用（一条说了两句、漏了一句）、拆分后其他译文轨的该条译文会标为原文已变更。

#### 验收标准

- AC-SPLIT-05-1: “修改前询问”档位下调用 `split_studio_cue`（拆分位置“乙。”），FusionKit 弹出确认，内容为文档名、第 N 条与两半文字、拆分时刻；确认后文档变为两条，结果含新修订号、新字幕 id、拆分时刻与依据；Ctrl+Z 恢复。
- AC-SPLIT-05-2: `insert_studio_cue` 在锚点之后插入 6000–7500 毫秒“补上的一句”，确认后出现在锚点之后，结果含新字幕 id；放行本类别后再次插入不再询问。
- AC-SPLIT-05-3: “只读”档位两个工具返回 `read_only`；修订号过期返回冲突；译文写向不是它创建的轨道返回 `track_not_writable`；拆分文字不存在 / 一半为空返回 `invalid_split`，时间不合规返回 `invalid_time`；拒绝时文档不变。
- AC-SPLIT-05-4: 已放行“写入译文”的连接调用 `split_studio_cue` 仍需确认；用户拒绝时返回 `declined_by_user`，文档不变。

#### 边界与异常

- 翻译进行中返回资源忙，与其他写入工具相同。
- 确认等待超时与其他写入工具相同（返回待确认，可用 `get_confirmation_result` 继续等待）。
