# 拆分与插入字幕 需求

## 目标与范围

校对时常遇到一条字幕说了两句话（转写把两句合成一条、或一句太长读不完），或者漏了一句（转写漏听、导入的字幕缺行）。本次在字幕预览中支持**把一条字幕拆成两条**（在文字中点选拆分位置，转写文档按字词时间定出拆分时刻）和**在某条前后插入一条新字幕**，两者都可试听、可撤销。

对应 `docs/TODO.md`「字幕工作台：编辑与校对 → 拆分字幕、插入字幕」；`docs/features/studio-cue-structure/brd.md` 将其列为后续批次。

来源：2026-10-11 用户：“你上面说的这些建议都挺好的，可以记录到一个TODO文档，然后再逐一处理”；随后“跑完后提交并推送，然后继续下一项”。

## 范围外

- 调整字幕顺序（拖动排序）。
- Agent 工具中的拆分与插入（Agent 仍可合并、删除、改时间）。
- 拆分时自动重新翻译两半（译文可一并拆分，或留在第一条并标为原文已变更）。

### R-SPLIT-01 拆分一条字幕

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「拆分可利用转写的字词时间定出拆开后的时间」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 编辑操作“拆分”：一条字幕在给定时刻拆为两条——原字幕保留前半文字、结束于拆分时刻；新字幕紧随其后，文字为后半、从拆分时刻开始到原结束。两半文字都不能为空；拆分时刻必须在开始与结束之间（结束未知时只需晚于开始）。
- 译文：可同时给出两半的译文（作为人工译文写入）；不给出时，原译文留在第一条（因原文已改变而标为“原文已变更”），第二条没有译文。
- 建议拆分时刻：按文字中的拆分位置估算。转写文档中这条字幕未改过文字与时间、且转写带有字词时间时，取拆分位置处字词的时间边界；否则按拆分位置前的字数占比在开始与结束之间估算（结束未知时用下一条的开始或开始后 5 秒）。
- 撤销恢复拆分前的文字、时间与译文并移除新字幕；重做得到同样的两条（新字幕的 id 不变）。

#### 验收标准

- AC-SPLIT-01-1: SRT 文档中 1.000–4.000 的“甲。乙。”在“乙”前、2.500 拆分后，变为“甲。”1.000–2.500 与“乙。”2.500–4.000 两条，导出两条；撤销后恢复为一条，重做后两条（第二条 id 与第一次相同）。
- AC-SPLIT-01-2: VTT（保留格式）文档拆分后导出成功，两条都在；拆分后的文档按新时间重新生成（与改时间相同）。
- AC-SPLIT-01-3: 转写文档中带字词时间的字幕，在第二个字词前拆分时建议时刻为该字词的开始时间；改过文字的字幕按字数估算。拆分后文档校验通过（同一转写片段可对应两条字幕），撤销、导出正常。
- AC-SPLIT-01-4: 拆分时刻不在开始与结束之间、或一半为空时拒绝且文档不变；同时给出两半译文时两条都有人工译文，不给出时第一条译文标为原文已变更、第二条无译文。

#### 边界与异常

- 翻译进行中拒绝（与其他编辑相同）。
- 双语导入后成对的字幕可以拆分；新字幕不再与原文件中的译文行成对。

### R-SPLIT-02 插入一条字幕

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「插入字幕」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 编辑操作“插入”：在某条字幕之前或之后插入一条新字幕，给定开始、结束与文字（可选译文，作为人工译文）。
- 约束：新字幕的开始不早于前一条的开始、不晚于后一条的开始（与改时间的顺序规则一致）；结束不早于开始；结束未知只在允许的格式中可以；转写文档的结束须在媒体时长内。
- 撤销移除新字幕；重做插回同一条。

#### 验收标准

- AC-SPLIT-02-1: 在第 2 条之后插入 6.000–7.500“补上的一句”后，它成为第 3 条，导出包含它；撤销后消失，重做后回到第 3 条。
- AC-SPLIT-02-2: 开始早于前一条的开始或晚于后一条的开始、结束早于开始、文字为空时拒绝且文档不变；转写文档中可以插入（结束在媒体内）。

#### 边界与异常

- 翻译进行中拒绝。

### R-SPLIT-03 拆分与插入的界面

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「拆分字幕、插入字幕」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 入口：右键 / 行“⋯”菜单“拆分字幕…”（只选中一条时）、“在上方插入字幕…”“在下方插入字幕…”。
- 拆分对话框：显示原文，点击或用方向键在文字中放置拆分位置（默认在最靠近中间的标点或空格后）；下方预览两条（文字与时间），拆分时刻按建议自动填入、可修改，并注明“按字词时间”或“按字数估算”；每一条可试听；有译文时可选择“同时拆分译文”并在译文中放置拆分位置。
- 插入对话框：开始、结束（默认取前后两条之间的空隙，最长 2 秒）、文字（必填）、译文（有译文轨时可填）；可试听所填时间段。
- 应用后撤销标签“拆分字幕”“插入字幕”；新字幕成为选中行。

#### 验收标准

- AC-SPLIT-03-1: 右键一条字幕“拆分字幕…”，在文字中点击拆分位置，预览两条与建议时刻，应用后列表出现两条且第二条被选中；Ctrl+Z 恢复。
- AC-SPLIT-03-2: “在下方插入字幕…”默认时间在两条之间，填写文字后应用，新字幕出现在其后并被选中；时间不合规时说明原因且不能应用。
- AC-SPLIT-03-3: 1280×860 浅色与 786×660 深色下两个对话框不溢出，长句换行，按钮对齐。

#### 边界与异常

- 选中多条时“拆分字幕…”禁用；翻译进行中两个入口都禁用并说明。
