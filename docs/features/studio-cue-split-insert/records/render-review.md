## 发现与修复（状态/位置 → 现象 → 原因 → 改动 → 复验）

1. 键盘放置拆分位置 → 方向键不移动光标，拆分位置不变 → Chromium 的只读文本框不响应方向键 → 改为拒绝 `beforeinput` 的普通文本框 → 测试用 End + 方向键放置位置，并验证输入与退格不改变文字。
2. 撤销插入后 → 列表上方出现“已删除 1 条字幕”及撤销按钮 → 删除提示按操作种类判断 → 只对“删除”标签的编辑提示 → 截图 02 之前的步骤断言无此提示。
3. 撤销拆分后再次拆分 → 依据变为“按字数估算”（截图 03 初版）→ 字词时间以修订号为 1 为条件 → 改为比较文字与时间 → 截图 03 显示“按字词时间”，测试断言。
