## 发现与修复（状态/位置 → 现象 → 原因 → 改动 → 复验）

1. 无选择时 → 范围显示“从第 101 条到结尾” → 起点取了文档末尾的默认值 → 仅当打开时有选中字幕才提供该项 → 复拍 04。
2. 试听 → 只能试听第 N 条 → 规格写的是“起点条” → 改为按伸缩后时间试听整篇最后一条（规格纠正、批准摘要已刷新，预检增加伸缩后结束时间）→ 界面测试读取主进程收到的试听区间。
3. 帧率选择 → 使用等宽字体，与对话框其他控件不一致 → 去掉 mono 类 → 复拍 04、05。
