# 整篇时间偏移 需求

## 目标与范围

字幕整体比原声早或晚（换了片源、片头长度不同、转写时截掉了开头）时，能**一次平移整篇字幕**或**从某一条起到结尾的所有字幕**，并在确认前**按平移后的时间试听**，听准了再应用（可撤销）。

对应 `docs/TODO.md`「字幕工作台：听原声校对的后续 → 整篇时间偏移」：现在 Ctrl+A 只选当前页 100 条，“平移时间…”无法覆盖整篇。

来源：2026-10-11 用户：“你上面说的这些建议都挺好的，可以记录到一个TODO文档，然后再逐一处理”；随后“跑完后提交并推送，然后继续下一项”。

覆盖：

- 主进程：新的编辑操作“平移”，作用于整篇或从某条到结尾，不受每页 100 条与单次编辑 1000 条的限制；平移前可预检（影响条数、不能平移的原因）。
- 渲染端：“平移时间”对话框增加范围选择（所选 / 从第 N 条到结尾 / 整篇）、微调按钮与按平移后时间试听；列表上方在未选择时也能打开。

## I2：按比例伸缩时间（2026-10-14）

字幕按 25 fps（PAL）片源制作、视频却是 23.976 fps 时，时间轴越往后差得越多，整体平移无法对齐。I2 在“平移时间”对话框中加入**按比例伸缩**：选择帧率换算（字幕原本对应的帧率 → 视频帧率）或输入自定义比例，整篇或从某条到结尾的时间按比例换算，确认前可试听换算后的时间，可撤销。

来源：2026-10-14 用户在 v0.5.0 回顾后选定“整篇按比例伸缩时间：用于帧率换算（比如 23.976 和 25 互转）”，要求先写文档再开发（`docs/TODO.md`「v0.5.0 后续」）。

I2 范围外：两点对齐（指定两条字幕的正确时间自动求比例与偏移）；伸缩与平移在一次操作中同时进行（先伸缩再平移即可，各自可撤销）；按选中的若干条伸缩；Agent 工具中的伸缩。

## 范围外

- 按比例伸缩时间（帧率换算，如 23.976 ↔ 25）与两点对齐（I1 范围外；按比例伸缩在 I2 加入，见 R-SHIFT-03、R-SHIFT-04；两点对齐仍不做）。
- 自动对齐（根据音频自动求偏移量）。
- Agent 工具中的整篇平移（Agent 的改时间仍按条）。

### R-SHIFT-01 主进程平移整篇或从某条到结尾

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「一次平移整篇字幕（现在 Ctrl+A 只选当前页 100 条）」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 编辑操作 `{ kind: 'shift', deltaMs, fromCueId? }`：所有字幕（或从 `fromCueId` 起按文档顺序到结尾的字幕）的开始与结束同时移动 `deltaMs`（整数毫秒，非 0，绝对值不超过 24 小时）；结束未知的仍为未知。与其他编辑一样在文档事务中进行、翻译进行中拒绝、返回撤销操作（即反向平移），可与其他操作一起放入批量编辑。
- 不能平移（整个操作不生效）：任何一条开始时间会小于 0；转写文档的任何一条结束时间会超出媒体时长；从某条起平移时，第一条会早于前一条的开始（原本不早于时）。
- 预检 `previewCueShift { documentId, revision, deltaMs, fromCueId? }`：返回将移动的条数，以及不能平移时的原因（`negative` / `beyond_media` / `before_previous`），不修改文档。

#### 验收标准

- AC-SHIFT-01-1: 250 条的文档整篇推后 1500 毫秒，所有字幕（包括不在第一页的）开始与结束都加 1500 毫秒、结束未知的仍未知、每条的时间修订号加 1；撤销后与平移前完全一致。
- AC-SHIFT-01-2: 从第 120 条起提前 800 毫秒，只有第 120 条及以后移动；若第 120 条会早于第 119 条的开始则拒绝且文档不变。
- AC-SHIFT-01-3: 提前使第一条开始小于 0、或转写文档推后使最后一条结束超出媒体时长时拒绝，文档不变；预检对同样的输入返回对应原因与条数，且不修改文档。
- AC-SHIFT-01-4: 翻译进行中拒绝平移；平移后 VTT / ASS / SSA 按新时间重新生成导出（沿用改时间的现有规则）。

#### 边界与异常

- 文档最多 100000 条；平移逐条修改时间，不受单次编辑 1000 条的限制。
- 文档已被其他编辑更新（修订号不符）时，预检与平移都按现有规则返回冲突。

### R-SHIFT-02 “平移时间”对话框：范围、微调与试听

| 字段 | 值 |
| --- | --- |
| 来源 | TODO「并能边试听边确认偏移量」 |
| 状态 | active |
| 批次 | I1 |

#### 说明

- 入口：右键 / 行“⋯”菜单“平移时间…”（有选择时）；列表上方工具栏在**未选择时**显示“平移整篇时间…”按钮。
- 范围（单选）：“所选 N 条”（有选择时）、“从第 X 条到结尾”（X 为所选的第一条，有选择时）、“整篇（共 M 条）”。从菜单打开时默认“所选”；但当所选恰为当前页的全部字幕而文档不止一页时默认“整篇”（Ctrl+A 的情形）；从工具栏打开时为“整篇”。
- 偏移量：毫秒输入框（负数提前）＋ 微调按钮 −1 秒、−0.1 秒、+0.1 秒、+1 秒。
- 预览：“第 X 条从 a 移到 b，共 N 条。”；不能平移时显示原因并禁用“平移”。
- 试听：按平移后的时间试听参照字幕（所选的第一条，未选择时为当前页第一条），可反复调整偏移量再试听；没有可用原始媒体时不显示试听。
- 应用：“所选”沿用现有的逐条改时间；“从第 X 条”与“整篇”使用平移操作；撤销标签“平移 N 条字幕的时间”。

#### 验收标准

- AC-SHIFT-02-1: 在 250 条文档的第 1 页按 Ctrl+A 后打开“平移时间…”，默认范围为“整篇（共 250 条）”；输入 1500 应用后，第 3 页字幕的时间也已推后；Ctrl+Z 一次恢复。
- AC-SHIFT-02-2: 未选择时工具栏的“平移整篇时间…”打开对话框，范围为整篇；微调按钮按步长改变偏移量与预览。
- AC-SHIFT-02-3: 选中第 120 条选择“从第 120 条到结尾”，预览显示“共 131 条”；提前到早于第 119 条时显示原因且不能应用。
- AC-SHIFT-02-4: 点试听按平移后的时间段播放参照字幕（主进程收到的范围 = 原时间 + 偏移量）；修改偏移量后再次试听使用新的偏移量；关闭对话框停止试听。
- AC-SHIFT-02-5: 1280×860 浅色与 786×660 深色下对话框不溢出，范围选项、微调按钮与试听按钮对齐。

#### 边界与异常

- 翻译进行中“平移”禁用并显示原因（与其他编辑相同）。
- 偏移量为 0 或无法解析时不能应用。

### R-SHIFT-03 主进程按比例伸缩整篇或从某条到结尾

| 字段 | 值 |
| --- | --- |
| 来源 | 2026-10-14 用户：“整篇按比例伸缩时间：用于帧率换算（比如 23.976 和 25 互转）” |
| 状态 | active |
| 批次 | I2 |

#### 说明

- 编辑操作“伸缩”：比例以整数分子 / 分母表示（帧率换算精确，如 23.976 = 24000/1001，25 → 23.976 的比例为 25 ÷ (24000/1001) = 1001/960）；比例限制在 0.5–2 之间（不含 1）。
- 换算：每条字幕的开始与结束 `t' = 锚点 + round((t − 锚点) × 分子 / 分母)`，四舍五入到毫秒；整篇时锚点为 0，从第 N 条起时锚点为第 N 条的开始（第 N 条的开始不动，它的结束与之后的时间按比例拉开或压缩，因此不会越过前一条）。未知结束保持未知。
- 校验与平移相同：转写文档的结束不能超出媒体时长（`beyond_media`）；任何问题都整体拒绝、不写入。四舍五入后时间仍按原顺序（不会交叉），可能出现开始相同的相邻字幕，允许。
- 预检（只读）：返回影响条数、最后一条换算前后的开始时间与不能伸缩的原因。
- 撤销精确恢复伸缩前每一条的开始与结束（不用反比例换算，避免取整误差）；重做得到同样的结果。
- 不受每页 100 条与单次编辑 1000 条的限制（与平移相同，整篇 10 万条以内）。

#### 验收标准

- AC-SHIFT-03-1: 250 条的 SRT 文档按 25 → 23.976（比例 1001/960）整篇伸缩，第 1 条 00:00:10.000 变为 00:00:10.427，第 250 条 01:00:00.000 变为 01:02:33.750；所有页都改变，未知结束仍未知；撤销后每一条的时间与伸缩前完全相同。
- AC-SHIFT-03-2: 从第 120 条起按 0.96 伸缩，第 120 条的开始与之前的字幕不变，第 120 条的结束与之后的字幕按与第 120 条开始的距离压缩。
- AC-SHIFT-03-3: 转写文档伸缩后有结束超出媒体时长时拒绝（`beyond_media`），文档不变；预检返回同样原因且不写入；比例为 1、小于 0.5 或大于 2 时拒绝。
- AC-SHIFT-03-4: 翻译进行中拒绝；VTT / ASS / SSA 伸缩后导出按新时间重新生成（与平移相同）。

#### 边界与异常

- 文档修订号不符时按现有规则返回冲突。

### R-SHIFT-04 伸缩的对话框

| 字段 | 值 |
| --- | --- |
| 来源 | 2026-10-14 用户：“整篇按比例伸缩时间：用于帧率换算” |
| 状态 | active |
| 批次 | I2 |

#### 说明

- “平移时间”对话框顶部增加方式切换：**平移** / **按比例伸缩**（标题随之为“调整时间”）；从列表上方按钮打开时默认平移，可切换。
- 伸缩方式：
  - 范围：从第 N 条到结尾（打开时选中了字幕且不是第 1 条时）/ 整篇。
  - 帧率换算：“字幕原本对应” 与 “视频” 两个帧率选择（23.976、24、25、29.97、30），显示得到的比例（如 ×1.0427）；或“自定义比例”输入（如 1.0427，最多 6 位小数，0.5–2）。
  - 预览：“共 250 条 · 最后一条 01:00:00.000 → 01:02:33.750”，不能伸缩时说明原因并禁用“应用”。
  - 试听：按伸缩后的时间试听整篇的最后一条（伸缩造成的偏差最大处），关闭对话框时停止。
- 应用后撤销标签“伸缩时间”。

#### 验收标准

- AC-SHIFT-04-1: 未选择时点列表上方“调整时间…”，切换到“按比例伸缩”，选择 25 → 23.976，显示 ×1.0427 与“共 250 条 · 最后一条 …”，应用后整篇改变，Ctrl+Z 恢复。
- AC-SHIFT-04-2: 自定义比例输入 0.4 时说明范围（0.5–2）并禁用应用；转写文档超出媒体时说明原因并禁用应用。
- AC-SHIFT-04-3: 试听播放的是伸缩后时间段（经播放请求的范围核对），关闭对话框停止。
- AC-SHIFT-04-4: 1280×860 浅色与 786×660 深色下对话框不溢出，两种方式切换时高度变化平滑、按钮对齐。

#### 边界与异常

- 翻译进行中两个方式的“应用”都禁用并说明。
