## 发现与修复（状态/位置 → 现象 → 原因 → 改动 → 复验）

1. 侧栏外框 → 四角为直角 → 项目 token `--radius-2xl: var(--radius-2xl)` 自引用，`rounded-2xl` 计算为 0（既有问题）→ 侧栏改用 `SmoothCorners` 组件，行用 `smooth-corners` 类 → 01/07 中圆角正常。
2. 长标题行 → 文字溢出面板，没有省略号 → Radix ScrollArea 内容层是 `display: table`，随内容变宽 → 视口加 `[&>div]:!block`（与悬浮面板一致），切换器同改 → 01/14 中单行省略。
3. 786×540 浮层 → 浮层盖住底部导航左端 → 浮层固定 `bottom-4` → 窗口宽度小于 900 px 时止于 `bottom-[60px]` → 10 中与导航分开；最小窗口完整显示 7 行（设计由 8 行改为 7 行，并说明原因）。
4. 深色浮层 → 阴影在深色下不可见，边框太淡，与页面分不开 → 浮层深色下使用实色边框 → 09 中边界清楚。
5. 空列表 → 「还没有会话记录」比标题与搜索图标靠左 10 px → 外部传入的 `px-2` 覆盖了自身的 `px-2.5` → 外层容器加内层段落各自留白 → 17 中左对齐一致。
6. 设置导航 → Agent 项提示仍为「联网查询资料」→ 新增会话记录后没有更新文案 → 四种语言改为「联网查询、会话记录」等。

未发现其他可处理的问题：标题、分组名、搜索图标与行文字共享左缘；右上角两个按钮到面板上、右内边界等距；当前行、相邻悬停行之间留有 2 px 间隔，不会连成一块。

## 2026-10-12 用户反馈后的第二轮

用户反馈：点击「收起会话列表」后，展开按钮会自己弹出 Tooltip；展开/收起像原地淡入淡出，不够连贯，头部两个按钮应与外部两个按钮有共享元素过渡。

7. 收起后 → 展开按钮自动显示 Tooltip → 收起时卸载头部按钮，并以程序方式把焦点移到另一个新按钮上，Radix 在获得焦点时打开 Tooltip → 两个按钮改为同一组元素（不再卸载），点击后与程序移回焦点时在指针离开前不显示 Tooltip → `motion-closed.png` 与采样测试断言收起、展开、Esc 关闭后 1 秒内都没有 Tooltip。
8. 展开/收起 → 侧栏在原地淡入淡出，与左上角按钮之间没有空间联系 → 收起态与展开态是两个独立图层 → 改为单个容器从按钮处长成列表、缩回按钮（motion-recipes Case 7 策略 A），按钮随容器右上角移动 → `motion-close-docked.json`：收起 0→≈400 ms 内宽度 248→76、高度 834→44 连续变化，按钮横坐标 228→56 全程与容器右上角相差不超过 1 px；内容约 130 ms 内淡出，背景层 205–355 ms 淡出；展开反向，内容约 125 ms 起淡入。窄屏浮层同样（`motion-open-overlay.json`）。
9. 常驻侧栏展开时 → 主页对话内容仍按整个窗口居中，看起来偏左，像被侧栏遮住了一块空间（用户反馈）→ 内容只按窗口居中 → 侧栏用与容器相同的 spring 驱动共享的 `homeContentShift`，欢迎视图、消息栏、底部输入区与「回到底部」按钮随之右移 132 px → `01-sidebar-1440-light.png` 中输入区到侧栏右缘与到窗口右缘的距离相等（端到端断言误差 ≤ 2 px）；`motion-close-docked.json` 的 `cx`（对话栏中心）随容器收起从 858 连续变到 726（窗口中心），展开反向；窄屏浮层时 `cx` 全程不变。底部导航与标题栏是全局外壳，保持按窗口居中。
10. 常驻阈值 → 用户确认由 1216px 降到 1000px → 内容改为居中于侧栏右侧后，1000px 时对话栏两侧仍各留 32px → `SIDEBAR_DOCK_MIN_WIDTH = 1000` → `07b-docked-1000-dark.png`：页面宽 1000px 时侧栏常驻，对话栏到侧栏与到窗口右缘的距离相等，与底部导航、主题按钮不相交。
