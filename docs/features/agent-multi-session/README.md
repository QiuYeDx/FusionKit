# Agent 多会话与会话管理

2026-10-12，基线 `5cf4dba`（分支 v0.4.0）。

用户原话：「目前的FusionKit Agent不支持多会话 需要支持一下多会话与会话管理和相关逻辑 可以先好好想一下设计清楚 然后写文档再开发」。

改动前，Agent 只有一个会话，「新对话」会把它清掉，除执行模式外什么都不保存，重启就丢。

## 做到了什么

- **多会话**：新建、切换互不影响；每个会话有自己的消息、计划、用量、日志、待确认卡片和输入草稿。
- **后台运行**：切走的会话继续回复，多个会话可以同时运行。列表里会标出运行中的会话，后台回复完成后显示未读。
- **授权归属**：工具读取的用户原话、写入的计划和确认、准备好的操作、转写完成回报，都只属于发起它的会话。删除会话即作废它的授权。
- **本地保存**：会话保存在 `userData/agent-sessions/`，每个会话一个文件，格式与导出文件相同，另有一个索引。重启后可以继续对话；待确认卡片不跨重启。
- **会话管理**：可以重命名、置顶、删除（需二次确认）、搜索、按天分组。可以从行菜单导出任一会话，导入的文件作为新会话打开。在设置 → Agent 里可以清空全部会话。
- **标题**：发出第一条消息时先截取它作标题，首轮回复后由 Agent 模型生成一个短标题（这次请求不带工具，用量计入该会话）。手动重命名过的标题永远不会被覆盖。
- **入口**：主页左侧是会话侧栏。窗口宽度 ≥ 1000 px 时常驻，可手动收起；更窄时它收成左上角的按钮，点开后以浮层显示。悬浮面板的标题处可以切换会话。
