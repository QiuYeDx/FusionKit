# 字幕工作台 · 日语 / ASMR 双阶段转写开发方案

## 现状与约束

工作台标准转写使用一套模型产出文本和时轴。实验性 `anime-whisper-q8_0` 已纳入共享资源目录，工作台支持安装后用于短句重识别。现有短句协议及时间戳限制见[基线考察](discovery.md)。新模式需要独立的工作台执行策略及一个新增任务配置维度，沿用项目的媒体、设备和文档边界。

## 方案与取舍

### 设计原理

字幕质量包含三项独立结果。录音中的日语对白要先被找到，区间起止要贴合原声，文字要与区间里的声音一致。第二阶段能纠正字词，前提是第一阶段已经找到这段话且保留了足够的音频。过窄会吃字，过宽会把邻句带进来。第一阶段应以**语音覆盖率和边界可听性**为优化目标，第二阶段以**给定片段上的识别准确率**为目标。

| 阶段 | 首版方案 | 产物 |
| --- | --- | --- |
| 准备 | 用现有 FFmpeg 媒体层归一化所选音轨，生成同一份受管的 16 kHz 单声道 PCM | 可按原时间轴定位的音频和时间映射 |
| 打轴 | `TransWithAI/Whisper-Vad-EncDec-ASMR-onnx` 在 CPU 上输出逐帧语音概率。由 FusionKit 根据停顿及区间规则生成字幕行 | 原媒体时间轴上的有序区间、异常区间和诊断统计 |
| 逐句识别 | `anime-whisper-q8_0` 固定 `ja`，按区间切片，设置 `noTimestamps: true`，省略提示词，关闭逐句 VAD | 每个已定区间的日语文字或空识别状态 |
| 保存 | 按区间 ID 合并为字幕文档，由现有文档提交和后处理流程接收 | 可听校、可编辑的日语字幕文档 |

首版组合已确定。打轴模型约 119 MB，Anime Whisper 约 818 MB。两项模型全新下载合计约 0.94 GB，运行时和按设备所需的加速资源另计。已安装的 Anime Whisper 直接复用。评测使用 `large-v3-turbo-q8_0` 提供对照区间。分段阈值、时间精度和质量收益由首轮实验确定。[开发计划](tasks.md) · [模型与现有能力考察](discovery.md)

### 时间轴与逐句识别

#### 第一阶段的区间规划

1. 复用工作台 `native/media-normalizer.ts` 的选轨、探测、WAV 产物与媒体授权。所有区间以归一化 PCM 的整数帧半开区间 `[startFrame, endFrame)` 保存。保存一份明确的 PCM 帧 → 原媒体时间转换，按现有工作台播放和音轨语义校验非零 PTS、选轨及裁切偏移，最终生成字幕时转换一次。FFmpeg 输出是否已补齐偏移先用测试脉冲验证，避免偏移叠加或漏加。
2. 以固定版上游模型和参考前处理为依据，在同一份 16 kHz PCM 上分窗执行 ONNX 推理。冒烟实验核对输入特征、张量形状、概率语义、约 20 ms 的输出跨度、边缘帧偏移和补零掩码。在全局 PCM 帧坐标内拼接概率，重叠窗口优先采用远离窗边的预测，最后限制到有效音频长度。用跨窗耳语、首尾脉冲、长静默和末窗补零验证映射。
3. 按起止阈值和最短停顿把概率变成语音候选区间。根据相邻区间之间的短停顿合并碎片，在有可信停顿的长段内切分。首轮试验优先产出 2–8 秒区间，保留有证据的短感叹词。单次识别片段含上下文不超过 20 秒。缺少可信停顿的连续语音保持原区间，超过识别上限的区间进入待听校。冻结阈值前，分别统计耳语漏检、纯音效误触发和连续对白合行。若合行影响验收，将具体区间和误差留在实验报告中，供后续决定是否为长段引入分句模型。

#### 第二阶段的片段与文字

- 每个区间含不可变 ID、字幕起止帧、独立解码裁切帧。默认先用精确区间做基线，另在调参集比较两端最多 120 ms 上下文。额外音频仅取相邻字幕之间的空隙和媒体有效范围，短静默时缩小。解码长度合计仍遵守 20 秒上限。上下文永远只影响输入裁切，导出的起止时间仍取字幕区间。
- 从同一 PCM 按帧读取并校验 WAV 头、长度、媒体身份及片段上限。借鉴 `runtime.ts` 单句重识别的 `verifyRuntime → acquire → beginInference → release` 和无时间戳解析。把运行在已验证租约下的短句请求做成可共用函数。逐句循环持有同一模型租约并串行请求，验证连续请求之间的语音和文字隔离。
- 一条区间对应一项 `text | empty` 结果。只做既有纯文本清理和普通换行，保留日语标点、语气词和重复语句。若同一短句返回多个文本片段，按服务顺序汇总为一个 cue。输出阶段以区间 ID 合并，忽略无时间戳协议合成的时间字段。检测邻句重复时保留带标记的听审证据，基于文本去重的规则须用真实重复对白验收。
- `empty` 计数并记录原区间。候选全空或打轴无有效语音时进入已有 `no_content` 交互，增加本模式原因和对应听审信息。部分有效时生成非空字幕并附待复核范围，任务上展示「有 N 段待听校」，暂停该次自动翻译与自动导出，用户听校后可手动执行。待复核摘要在任务保留期间可查看，完整区间清单留在同一任务的按需查询中，避免放大轮询消息。正常成功的文档沿用已有自动任务行为。推理超时、进程退出、协议错误进入现有错误路径，文件级重试复用配置及选轨，并在已验证的原生取消和租约回收后重新开始。有效空结果保留语义且可听检。

### 资源与事务

阶段进度由任务服务统一映射为单调递增的总进度。第一阶段按已处理音频时长更新，第二阶段按已完成片段数更新，提交确认后到 100%。现有 `status` 延续兼容语义，增加可选 `phase` 和片段计数便于 UI 呈现。任务状态中的可见信息有界，空片段和长段待复核清单按 owner 与任务令牌分页读取。

沿用现有工作台文件队列，逐文件完成两阶段。只有处理中的文件保留一份归一化媒体和一个重用的片段槽位，WAV 按需读写，每次请求完成或终止后释放。16 kHz 单声道 s16 的裸 PCM 约 115.2 MB/小时。准入按 probed duration 和现有文件上限估算空间，处理时持续检查实际写入和剩余空间，沿用项目已有任务/文档大小上限及明确的空间不足提示。长音频分窗读取并消费概率，内存只保留有限窗口、拼接边缘以及受限的区间结果。ONNX 超时或取消后等待原生调用实际停止，必要时终止并回收隔离宿主，然后释放文件和模型使用权。目标包需要分别验证 ONNX CPU 能力及 Whisper 内容识别的 CPU / 适用加速能力。Windows 原生模块按项目规约用实际 Electron 隔离宿主冒烟。见 [Electron 原生模块避坑记录](../../../.agents/skills/fusionkit-pitfall-guard/references/probe-windows-native-addons-in-electron-not-node.md)。

取消信号贯穿规范化、打轴、待换载、短句串行请求、文档提交前。提交前清理掉运行产物，提交临界区沿用工作台 durable/uncertain 处理，避免出现重复文档和重复自动任务。负载、临时文件和日志通过现有 owner 生命周期管理。诊断默认记录阶段、区间和计数，记录真实听校样本时需要使用获准素材并在测试目录留证。

## 验证与风险

在 Electron 的 `/tools/subtitle/studio?view=transcription` 检查 1280×800 和 1024×700 浅/深色窗口。设计基准采用 [FusionKit UI Design](../../../.agents/skills/fusionkit-ui-design/SKILL.md) 和工作台 `StudioTranscription.tsx` 的设置及任务区域。用长文件名、模型缺项和待听校内容检查按钮位置、键盘焦点和消息换行。实施时先渲染并执行真实交互，再修正并复验。

### 真实素材和开放门槛

实验先冻结素材、音轨、参考稿、归一化口径和报告字段。按来源独立拆调参与留出集，至少覆盖耳语、气声/双耳偏侧、普通日语、音乐/音效、多句紧邻、纯呼吸/擦碰、长静默、多轨与长素材。每个关键语音类别至少来自两段独立素材，负样本单独统计每分钟错误字幕。已有 A/B/C/B-noise 可做可复现回归，另准备实际留出样本。标注可听词首/尾与合理字幕范围，边界不确定的片段单独报告。

| 实验组 | 提问 |
| --- | --- |
| 工作台当前默认设置，固定同轨并指定日语 | 现有产品基线 |
| 人工时间轴 + Anime Whisper | 区间正确时可达到的文本效果 |
| ASMR VAD 时间轴 + Anime Whisper | 首版组合的耳语覆盖、端点、合行、误出字和实际延迟 |
| Turbo 时间轴 + 同一 Anime Whisper | 固定内容模型及裁切规则，与首版打轴做同音轨对照 |

统计时间重叠和匹配边界误差，使用 IoU ≥ 0.5 的一对一匹配报告 cue F1，同时用语音帧覆盖率量化漏打，不让多切/少切掩盖漏语音。日语字符错误率按文件和完整时间顺序统计删除、插入、替换，拼接漏句计入删除。主要 CER 对空白/标点和 Unicode 归一化规则使用固定口径，并另报标点完整性。记录非语音误出字数/分钟、超长未切/空结果数、总时长比、模型换载、首句耗时、峰值内存/显存/磁盘，再随机顺序盲听差异片段并标注丢词首尾、串句和幻觉。

**建议在首轮运行前冻结以下实验开放门槛。数字是规划目标，当前没有双阶段实测值。** ASMR 留出集整段 CER 相对现有模式下降至少 10%，耳语语音帧召回率最多下降 2 个百分点。匹配首尾边界的 P90 误差不超过 500 ms。负样本误出字率不超过对照，清晰日语 CER 回退不超过 2 个百分点。两小时实例无资源泄漏或任务失败，目标设备上的中位耗时不超过标准模式的 2 倍。报告列出样本量、分组值和盲听中的严重截字或串句，确认严重问题消除后再展示实验入口。若某组改善不足，先按人工轴与自动轴的结果定位阶段，再根据失败样本调整区间或阈值，记录是否需要增加长段分句。留出集首次评估后保留其结果，下一轮调整继续用调参集和新的验证样本。
