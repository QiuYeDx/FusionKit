# 字幕工作台 · 日语 / ASMR 双阶段转写需求

基线为 `v0.6.0` / `dc8cdc35`，规划日期为 2026-11-20。本次用户要求在字幕工作台增加可选模式，先用一个模型确定字幕起止时间，再让约 0.8 GB 的日语模型按字幕时间逐句识别。首期交付是一个可选择、可评测的本地转写模式，生成工作台可编辑的日语原文字幕。2026-11-20 用户确认采用 `TransWithAI/Whisper-Vad-EncDec-ASMR-onnx` 打轴。

## 目标与范围

首期以日语耳语、气声、带背景音的近讲和普通日语对白为目标。字幕单位是一段可独立听校的语音。允许长停顿分隔字幕，保留原始媒体时间轴，以便播放、听校、修订和导出。非日语、多角色重叠语音和长段连续无停顿属于必须验证的边界素材。功能入口限定在字幕工作台的转写页，现有转写设置、字幕文档和自动翻译/导出继续按原契约使用。

## 需求

### R-JASMR-01 选择模式与准备资源

| 字段 | 值 |
| --- | --- |
| 来源 | 2026-11-20 用户请求，可独立选择日语 / ASMR 模式 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

作者从转写页选择模式，提交前确认音轨、模型就绪状态及输出语言。

#### 验收标准

- AC-JASMR-01-1: 工作台提供「标准转写」「日语 / ASMR」选择，首次及旧设置默认标准。切换后展示本次执行使用的两个模型、资源状态与锁定的日语原文输出。返回标准时恢复原设置。
- AC-JASMR-01-2: 当资源未就绪时，可从设置进入共享资源管理并看到缺项，点击安装后通过共享资源管理下载并校验两种格式的模型。启动时由主进程重新验证资源、设备和能力，旧调用方省略模式时继续按标准处理。

#### 边界与异常

模型缺失、安装中或运行时不可用时展示原因与恢复入口。

### R-JASMR-02 打轴先行与逐句识别

| 字段 | 值 |
| --- | --- |
| 来源 | 2026-11-20 用户请求，打轴独立于字幕内容 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

打轴和识别使用同一选定音轨，字幕时间可追溯到音频，正文可追溯到短句识别。

#### 验收标准

- AC-JASMR-02-1: 指定原媒体音轨后，第一阶段由 ASMR 专用 ONNX VAD 检测语音，再按可用停顿整理为原时间轴上有序、有界的字幕区间。第二阶段按区间读取同一音轨的 PCM，有清晰的区间与识别结果映射。用带非零偏移、相邻语音和长静默的样本验证区间映射。
- AC-JASMR-02-2: 逐句请求使用 `anime-whisper-q8_0`，固定日语、无提示词和模型时间戳。测试注入任意第二阶段时间戳，落盘字幕保留首轮区间及第二阶段文字。
- AC-JASMR-02-3: 识别空结果须与推理/协议错误区分。有效空结果在任务中可见，复核音频所需时间范围可查。取消或技术失败在文档提交前发生时不出现部分文档或后续任务，重试保留模式和选轨。提交后走已有持久化确认流程。

#### 边界与异常

连续语音缺少可信切点、存在重叠或识别无文字时给出待听校范围。

### R-JASMR-03 正常使用任务与结果

| 字段 | 值 |
| --- | --- |
| 来源 | 字幕工作台现有转写、文档和后续任务契约 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

用户可以像标准转写一样批量提交媒体、查看阶段并打开字幕文档。

#### 验收标准

- AC-JASMR-03-1: 单个或一批文件进入现有任务队列。进度可辨认准备音频、打轴、逐句识别和保存。两阶段及队列等待期间均可取消，退出后释放本任务的临时文件、模型使用权和推理租约。
- AC-JASMR-03-2: 完整结果进入可播放、可编辑、可导出的工作台文档。自动翻译/导出遵守已有设置，同时满足本模式的完整性判定。长媒体的临时磁盘和模型驻留符合设计中的资源上限。
- AC-JASMR-03-3: 标准转写、旧文档读取、现有单句重新识别和独立「本地字幕转写」工具通过各自的兼容性回归。

#### 边界与异常

资源冲突和提交不确定沿用已有任务处理方式，双阶段资源随所属任务结算。

### R-JASMR-04 通过真实素材验证收益

| 字段 | 值 |
| --- | --- |
| 来源 | 用户的质量目标与既有 ASR 实验记录 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

端到端评测同时衡量正文准确率、时间轴、负样本误出字及处理成本。

#### 验收标准

- AC-JASMR-04-1: 分别用人工标注、ASMR VAD 和 Turbo 产生的区间驱动同一个逐句识别模型。与标准工作台流程在同音轨上对比，分别给出时间轴覆盖、连续对白合行、漏字错字、负样本误出字、处理时间及峰值资源数据。
- AC-JASMR-04-2: 用冻结的留出样本执行量化门槛和盲听验收。达标后开放实验选项，未达标时保留内部验证入口和具体失败样本，依照开发方案定位打轴或文本阶段。

#### 边界与异常

对不可听清的参考区间保留标注不确定性，单列相关统计。

## 产品约束

处理在本机执行，音频沿用现有路径授权。模型安装沿用共享资源及现有许可提示。选项展示额外耗时和必需资源，实验性模式由用户主动选择。此处「字幕行」指一条带起止时间的字幕 cue，同一 cue 的视觉换行沿用文档/导出规范。
