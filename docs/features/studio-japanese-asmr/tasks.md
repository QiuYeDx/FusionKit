#### 实现要点

固定上游模型版本并记录文件身份、前处理契约和输出语义。在隔离 Electron 宿主运行 ASMR VAD CPU 冒烟，让合成帧和真实样本分别验证时间映射与参考实现一致性。扩展 ASR 试验入口，用同音轨跑标准流程、人工轴、ASMR VAD 轴和 Turbo 对照轴。输出逐样本指标与回听片段，冻结概率阈值、窗口拼接、停顿及解码边距。评测数据缺失时先完成隔离测试链路，真实质量保留待测。
