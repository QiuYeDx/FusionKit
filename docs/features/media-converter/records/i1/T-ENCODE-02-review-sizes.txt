## 4. 旋转标记（跨模块问题，不在本任务写集）
$ ffmpeg -f lavfi -i testsrc2=s=64x32:r=10:d=0.3 -c:v ffv1 -metadata:s:v:0 rotate=90 -f matroska tag.mkv
$ ffprobe -show_entries stream=width,height:stream_tags:stream_side_data tag.mkv
  width 64, height 32, tags { "ROTATE": "90" }，没有 Display Matrix
$ ffmpeg -i tag.mkv -c:v ffv1 -f matroska out.mkv && ffprobe out.mkv
