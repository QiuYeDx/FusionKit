# 音视频转换与压缩（v0.6.0）

在 FusionKit 本机完成常见音视频的格式转换、视频压缩和音频提取。视频压缩是重点：在保留画质的前提下，把文件尽量压小。

- 简单模式只有三档：画质优先、均衡、体积优先，上手即用。
- 高阶用户可以自己控制码率模式、编码器和滤镜。
- 文件全程留在本机，不上传，不需要 API Key，没有广告。

## 压缩技术要点

| 技术 | 做法 | 增量 |
| --- | --- | --- |
| SVT-AV1 10-bit | preset 6，CRF 按档位和分辨率取值；本机实测 10-bit 比 8-bit 小约 12% | I1 |
| 硬件编码器 | 用生产参数实测后才启用。NVENC 已在本机实测调优（p7、UHQ/HQ、CQ）；QSV/AMF 先用初值，待在对应设备上校准，参数被拒绝时自动跳过 | I1 |
| 智能流规划 | 能只换封装就不重新编码；音频能直通就直通；字幕、章节、元数据按容器规则保留；容器选「自动」时，按字幕类型决定用 MP4 还是 MKV；会丢失的内容在开始前提示 | I1 |
| 正确性 | 旋转、色彩标记（setparams）、全范围转有限范围、HDR 保留或色调映射、杜比视界识别、VFR、去隔行 | I1 |
| 安全 | 不变大保护（98%）、输出字节上限、按卷检查磁盘、覆盖前把旧文件移到回收站、错误日志脱敏、拒绝播放列表 | I1 |
| 感知画质目标 | 参照 ab-av1：分段采样，插值二分搜索 CRF，用 VMAF 评分并加低分位保护；目标分数 96/94/91 | I2 |
| 目标大小 | 按真实时长计算码率，真 2-pass；每像素比特过低时自动降分辨率；超标时修正重编；超过目标的文件不发布 | I2 |
| 预览对比 | 同一时刻的帧滑动对比，显示 VMAF，并可播放样片 | I2 |
| 高级控制 | CRF/CQ、VBR 1/2-pass、带上限的 CRF、CBR、preset、tune、GOP、胶片颗粒、滤镜、响度 | I3 |

## 决策（2026-10-26 用户确认）

| 编号 | 问题 | 结论 |
| --- | --- | --- |
| Q-01 | 「压缩视频」的默认输出编码 | 选项 B：有 HEVC 硬件编码器时默认 HEVC，否则默认 H.264；AV1 作为「最小体积」，由用户主动选择 |
| Q-02 | macOS 方案 | 自建 LGPL 视频版 ffmpeg，作为独立运行时，由用户在 Mac 上构建，在 I4 交付 |

| Q-04 | 许可与编解码专利（QA-005、openh264/kvazaar） | 发布前补齐许可声明与源码提供；保留 CPU 兜底，并如实说明 |
