## 使用方式

首页“可用工具”可查看六项正式能力。配置 Agent 模型与任务执行模型后，可要求“查看字幕工作台文档，整理一个翻译计划，准备日语到中文翻译，先让我确认”。需要文件时通过原生选择器授权，计划会显示步骤、依赖进度及阻塞原因。

工作台翻译/转写在准备卡片中显示准确范围；询问执行或仅排队模式保留待确认，自动执行模式按已选模式提交。经典字幕队列只启动本次实际创建的任务。后台任务状态可继续询问 Agent，也可从结果进入对应工具页。

本地经典转写可查询环境和任务、准备参数；文件选择仍在转写工具页完成。重命名沿用已有能力，须在生成预览后确认当前计划。会话导入只恢复历史及计划展示，执行模式会降为仅排队。
