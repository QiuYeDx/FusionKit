# HomeAgent 业务范围与路线图

## 背景与目标
当前九个工具集中在旧字幕和名称翻译，缺少结构化规划、正式工具覆盖及可靠会话生命周期。本轮交付能发现能力、组织步骤、精确执行、查看结果的首页助手。

### BR-01 可靠执行与计划组织

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明
建立会话所有权、有界上下文、完整工具回执、依赖与步骤状态；停止后不继续新副作用，确认只启动本次任务，重命名在预览后明确确认。

#### 验收要点
迟到事件隔离；完整回执；按准确任务确认；计划与工具运行状态可解释。

### BR-02 正式工具覆盖

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明
经典与最新正式工具全部具有真实能力入口；新增本地转写、字幕工作台和翻译资料。支持现有授权接口允许的实际查询/导入/准备与执行，边界显式交接。

#### 验收要点
正式目录覆盖、固定选择器、真实接口及边界失败测试；不接新实验工具。

### BR-03 可见工作过程

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明
保留聊天主线，展示紧凑计划、能力目录、待执行动作和可信结果，四语言并完成 Electron 渲染审查。

#### 验收要点
四语言检查与隔离 Electron 渲染、操作、错误恢复证据。

### BR-04 真实任务的确认与结果闭环

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I2 |

#### 说明
依据 2026-10-03 用户再次复审并自主完善的请求，在 161b109 上修复已复现的停止、精确确认、长会话恢复及状态可读性缺口。保留原正式工具范围及执行权限，不将当前回执、历史事实与助手上次计划混为同一状态。

#### 验收要点
停止贯穿名称规划请求；转写准确范围无静默缩水；部分失败可见；导出的会话可重导入；首页可恢复会话、识别当前任务并进入正确工作区；隔离 Electron 交互和截图复审。

## 范围外
不新增实验区文本翻译、音频/实时工具，不新增通用 shell/任意文件写入/任意 IPC/外部服务。已有名称翻译保留兼容。不部署、不删除真实资料、不引入新的后台多 Agent 或无人值守调度。

## 模块与契约索引
runtime 负责运行/上下文；tools 负责能力目录和新工具；workspace 负责计划/旧队列/确认/会话/UI，见各模块 requirements/design/tasks。

## 后续批次
I1 完成正式工具与可靠运行主链路，I2 补足真实流程复审与状态反馈。多会话自动持久化或后台调度需另行定义业务需求。
