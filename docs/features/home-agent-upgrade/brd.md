# HomeAgent 业务范围与路线图

## 背景与目标
当前九个工具集中在旧字幕和名称翻译，缺少结构化规划、正式工具覆盖及可靠会话生命周期。本轮交付能发现能力、组织步骤、精确执行、查看结果的首页助手。

#### 验收要点
迟到事件隔离；完整回执；按准确任务确认；计划与工具运行状态可解释。

### BR-05 随处可用、感知页面的 Agent

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I3 |

#### 说明
依据 2026-10-09 用户提议：HomeAgent 不应只能在首页使用。应用各页面提供固定悬浮入口，展开后即为同一会话的对话面板；Agent 知道用户所在页面，并能通过页面声明的只读上下文与有限工具完成与当前页面相关的意图。首个落地页面为字幕工作台：用户可直接说“文中的‘法尔童’都应为‘法厄同’”，Agent 读取当前文档、找到相关字幕并准备修订，由用户在工作台修订预览中确认后写入。

#### 验收要点
非首页路由均可打开/关闭悬浮面板且与首页共享会话；面板标明当前页面；模型每轮获得当前页面路由与有界页面快照；页面工具只在该页面存续期间可用；工作台可读取、查找字幕并打开预填的 AI 修订预览，写入只发生在用户点击应用之后；隔离 Electron 渲染与交互审查。

### BR-06 跟随工具页设置、跨页面协作与连贯过渡

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I4 |

#### 说明
依据 2026-10-09 用户在 I3 交付后的追加要求，逐条完成：
1. 经典工具（字幕翻译、字幕转换、字幕语言提取、本地字幕转写、名称翻译）同样接入页面上下文，Agent 在这些页面能看到页面状态。
2. Agent 添加/准备任务时，用户没有指定的设置优先采用对应工具页当前的最新设置，而不是固定写死的默认值；用户明确指定的仍以用户为准。
3. Agent 能切换页面（例如往字幕翻译添加任务后打开字幕翻译页查看）。
4. 从首页切换到其他页面时，若有进行中的对话，首页对话以连贯、无闪烁的过渡变为悬浮面板；从面板回到首页反向过渡。

#### 验收要点
经典工具页快照与建议可用；工具结果标明所用设置来源（用户指定 / 工具页设置 / 内置默认）；导航只允许应用内已知页面并返回目标页状态；首页↔面板过渡在真实 Electron 中逐帧无跳变与重影，减少动态效果下退化为淡入淡出。

## 范围外
不新增实验区文本翻译、音频/实时工具，不新增通用 shell/任意文件写入/任意 IPC/外部服务。页面工具不得绕过页面已有的确认界面直接写入用户数据。已有名称翻译保留兼容。不部署、不删除真实资料、不引入新的后台多 Agent 或无人值守调度。
