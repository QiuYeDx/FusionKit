## 记录

### U1（完成）
- `AgentDock/index.tsx`：入口 tooltip 改为受控，`side="right"`。关闭面板时先标记“安静回焦”再聚焦入口，期间忽略打开请求；指针进入或失焦后恢复，悬停与 Tab 聚焦照常显示。
- 验证：`agent-dock.electron.test.ts` 断言 Esc 关闭后 600ms 内无 tooltip、悬停时 tooltip 位于入口右侧（截图 `00-launcher-tooltip.png`），外部点击收起后同样无 tooltip。

### U3（完成）
- 根因：`SubtitleTranslator/index.tsx` 的 `customLengthInput` 用 `useState(String(customSliceLength))` 在挂载时复制一次；I3/I4 后 store 也会被浮窗中的 `subtitle_translator_update_settings` 修改，页面不再挂载，本地副本不会更新。
- 修复：输入框显示 `草稿 ?? store 值`，草稿只在输入时存在、失焦清除（store 会把空值或越界值规范为默认值，因此输入中仍需草稿）。
- 同类排查：转换、提取、名称翻译、本地转写页的设置都直接读取 store，无同类副本。
- 防止再犯：新增 `.agents/skills/fusionkit-pitfall-guard` 的 FK-PIT-0187；`agent-handoff.electron.test.ts` 让 Agent 设置“自定义切片 1200”并断言打开中的页面显示 1200。还原修复后该断言以“期望 1200、实际 1000”失败，确认能复现原问题。

### U5（完成）
- `AgentDock/index.tsx`：面板打开且未固定时，在捕获阶段监听 `pointerdown`。目标在面板、入口、Radix 弹出层、对话框/警告框、遮罩或 toast 内时不处理，否则收起面板且不回焦（焦点留给用户点击处）。
- 新增标题栏“固定面板”按钮（`aria-pressed`，本机记住选择）；固定后不因外部点击收起，用于边选择页面内容边与 Agent 对话。
- 需求变更：AC-WORKSPACE-03-3 由“面板为非模态，可与页面同时操作”改为“点击外部收起，固定后可与页面同时操作”，同时写入入口提示的位置与回焦行为。I3 的 T-WORKSPACE-05/06 记录已按新措辞复核并刷新任务指纹。
- 验证：dock 用例断言外部点击收起且该点击选中了字幕；固定后点击字幕不收起。

### U2 / U4（完成）
- 新增 `components/AgentCard.tsx`：14px 平滑圆角（`SmoothCorners`）、边框、`bg-card`。工具卡、计划、待确认操作、历史回执，以及 `PendingExecutionWidget` 与文件名预览/结果卡统一使用；卡头统一为 3.5 号图标、`text-xs font-medium` 标题、`text-[11px]` 状态，正文以细线分隔。
- `AgentToolCall.tsx`：一次调用一张卡，卡头显示名称与状态（完成为绿色勾），正文显示结果，展开详情显示工具标识、参数与返回数据（新增文案 `home:tool_result_data`）。`AgentToolResult.tsx` 改为卡片正文，任务行改为浅底分隔列表，操作按钮为胶囊样式。
- `conversation.tsx`：去掉头像与 `pl-10` 缩进，内容占满整列。用户消息为右对齐的 `bg-secondary` 平滑圆角气泡，去掉尖角。新增 `useConversationIndex`，已在调用卡中显示的结果消息不再重复渲染；没有对应调用的结果仍单独成卡。经典工具结果由 Markdown 原始标识（如 `**queue_subtitle_translate** ✓`）改为结构化文字。文件名预览/结果仍以独立的交互组件显示。
- 历史回执中的操作改为同一卡片内的分隔行，不再卡中套卡。
- QA 脚本：合并后的卡片内含结果按钮，`success-call` 的名称断言改为取卡头按钮（`.first()`）。
- 验证：截图审阅首页（中英日繁、浅深色、1280/786）与浮窗。`node scripts/home-agent-qa.mjs` 通过（17 项检查、无横向溢出）。
