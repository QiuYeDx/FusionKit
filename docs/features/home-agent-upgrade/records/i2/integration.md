## 实际行为

- 停止名称翻译规划会取消模型请求并阻止后续批次、重试和 fallback。长对话压缩后，助手仍能读取当前有效待确认摘要；提示明确区分经典队列与现代准备动作。
- Responses 工具往返保留完整输出顺序、reasoning 与 phase；不完整流不执行工具。加密推理只在当前 turn 的有界内存内回传。
- 批量准备与提交都保留成功数量及具体失败项；传输结果未知时明确显示未知，不伪造全失败或重试。转写确认校验当时的准确草稿全集，避免静默缩小范围。三类翻译资料正确分页。
- 当前操作优先，历史回执折叠，最新结果按真实状态更新时间排序。准备、已提交与后台完成分别表达；导入历史可以查看回执，但不能恢复执行权限。
- 计划标注助手上次更新时间。“检查进度”保留草稿、避免重复追加，用户发送后才查询。转写显示实际阶段、进度、错误，跳转到对应工作台视图。
- 未配置模型也可导入历史；导出有类型化结果，并与导入共用 schema 和 8MiB UTF-8 限额。键盘焦点可见，阅读旧日志不被新日志拉走；输入区按实际高度预留空间，修复无模型提示遮挡计划底部。
