# HomeAgent 正式工具接入需求

## 目标与范围

以 `src/pages/Tools/index.tsx` 的最新/精选和经典栏目为范围，覆盖字幕工作台、翻译资料库、字幕翻译、字幕转换、字幕语言提取、本地字幕转写六项正式工具。已有名称翻译保留兼容。本模块负责真实能力发现、固定接口执行与会话内准备动作；编排、传统队列控制和界面由对应模块集成。

## 范围外

不新增长文本翻译、音频转写、语音合成、实时字幕、实时语音或音乐等实验性能力；不扩展已有实验性名称翻译。不接通用 IPC、shell、任意路径授权，不增加 main 权限。不提供删除文档、修改/采纳/删除资料或安装/删除模型资源。不将经典本地转写的真实 File 授权改成路径字符串。

## 需求

### R-TOOLS-01 在正式工具中完成有边界的查询、准备和执行

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

HomeAgent 能查询工作台文档/任务、本地转写环境/任务和翻译资料，通过原生选择器导入字幕，将工作台翻译、转写整理成可审阅的准备动作。经典本地转写通过参数预填和工具入口交接，用户在其页面选择真实文件。

#### 验收标准

- AC-TOOLS-01-1: 能力目录准确列出六项正式工具、路由和支持操作，不因 TOOL_META.status=stable 将实验工具加入；原名称翻译兼容接口不受影响。
- AC-TOOLS-01-2: 工作台和经典转写查询调用固定 API 返回有界文档/任务/环境摘要，区别不可用、失败、空数据、已排队、执行中和完成，不能把入队成功报告为任务完成。
- AC-TOOLS-01-3: 字幕导入及工作台转写准备仅使用固定原生选择器；取消选择不提交，工具参数不接受路径、能力 token、API key 或 endpoint，失败不绕过 preload 权限边界。
- AC-TOOLS-01-4: 工作台翻译/转写准备动作绑定创建会话及准确文档/草稿范围；auto_execute 自动提交，其余模式保留 ready 等待操作；确认在首次 await 前同步 claim，重复确认最多提交一次，跨会话或失败动作不可盲重提。
- AC-TOOLS-01-5: 经典转写交接只接受验证过的有限业务参数、返回真实工具入口，保留页面文件选择，不消费其他页面的未确认媒体能力，不跨用工作台 token。
- AC-TOOLS-01-6: 资料检索返回计数、标识、审核状态和有长度/数量上限的匹配摘要，不包含整库、原始证据全文、凭据或执行授权，不执行修改或采纳。
- AC-TOOLS-01-7: 当前会话动作跨路由保留；回调、文件能力与密钥不持久化；会话变化使旧 ready 动作失效并清理其能力，失败动作显示明确错误且不自动重提。

#### 边界与异常

revision、generation 和能力寿命由已有契约负责。工作台原有草稿不得静默混入 Agent 任务，无法精确隔离时要求先处理旧草稿。计划过期须重新准备。资料无匹配与 IPC 故障必须区分。
