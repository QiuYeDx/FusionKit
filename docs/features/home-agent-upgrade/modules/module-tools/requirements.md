# HomeAgent 正式工具接入需求

### R-TOOLS-02 批量结果完整与准确范围确认

| 字段 | 值 |
| --- | --- |
| 来源 | BR-04 |
| 状态 | active |
| 批次 | I2 |
| 优先级 | P1 |

#### 说明
保持现有正式能力范围，修复部分失败、准确转写范围及资料翻页缺口，依据 ../../records/review-i2-plan.md。

#### 验收标准
- AC-TOOLS-02-1: 翻译准备及提交均返回结构化 receipt，完整保留逐项文件、状态及失败原因；部分与全失败不被整体成功掩盖，失败动作的 data 仍可展示，不自动重试。
- AC-TOOLS-02-2: 转写确认在过期清理后的实际入队前校验 expectedDraftIds；任何缺失、失效或额外范围均零提交并报可恢复原因，默认工作台行为不变。
- AC-TOOLS-02-3: entries/collections/recipes 都应用 offset/limit，并分别返回 total/hasMore/nextOffset；翻页覆盖完整结果且不重复第一页。

#### 边界与异常
receipt 只传投影数据，不增加回调/路径授权。准备与提交阶段分别说明成功范围；过期资源要求重新选择，不暗中删掉失败项继续执行。

### R-TOOLS-03 字幕工作台页面上下文与修订工具

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明
字幕工作台在页面存续期间注册上下文：当前文档摘要、当前页、选区和编辑可用性；并提供读取、查找与准备修订的页面工具。修订复用字幕工作台的 AI 修订预览（docs/features/subtitle-studio/records/2026-10-09-ai-cue-revision.md），写入仍由用户在预览中确认。

#### 验收标准
- AC-TOOLS-03-1: 未打开文档时快照说明没有当前文档；打开文档时包含 documentId、名称、格式、revision、条数、译文状态与译文轨（语言/名称/是否当前显示）、当前页编号范围、选区数量与前 50 个编号、编辑受阻原因；不含字幕全文与任何密钥。
- AC-TOOLS-03-2: `studio_read_cues` 按 1 起编号读取当前文档最多 50 条，返回编号、时间、原文、当前显示译文轨的译文及是否过期，单条文本有长度上限；越界返回空列表与总数。
- AC-TOOLS-03-3: `studio_find_cues` 按写法（含近似误写）或编号在当前文档全文查找，不调用模型；返回命中总数与前 N 条（编号与文本）。主进程新增只读 `findCues`，与 AI 修订定位共用同一匹配规则，并校验文档授权与 revision。
- AC-TOOLS-03-4: `studio_prepare_revision` 接受修改要求、范围（所选/整个文档）、可修改字段及可选的写法或编号；打开预填的 AI 修订预览并自动开始生成。给出写法或编号时跳过修订流程的规划请求；生成完成后返回检查条数、提议条数、说明与“等待用户在预览中确认”；需大范围确认、失败或用户停止/关闭时返回对应状态。任何执行模式下工具都不应用修订。
- AC-TOOLS-03-5: 工作台无文档、编辑受阻（翻译进行中）、所选范围为空或已有修订预览打开时，工具返回明确原因且不打开第二个预览；文档在工具等待期间被切换时返回 `page_changed`。

#### 边界与异常
工具只操作当前打开的文档，不接受任意 documentId；Agent 中止本轮时工具返回已中止，修订预览保留给用户继续。修订模型沿用 AI 翻译配置，未配置时预览显示既有的模型设置提示，工具返回 `needs_configuration`。

### R-TOOLS-04 经典工具页面上下文

| 字段 | 值 |
| --- | --- |
| 来源 | BR-06 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P1 |

#### 说明
字幕翻译、字幕转换、字幕语言提取、本地字幕转写、名称翻译五个经典工具页注册页面上下文：当前设置、队列/任务概况、页面上的选择，以及页面建议；设置类页面提供只改该页设置的页面工具。

#### 验收标准
- AC-TOOLS-04-1: 五个页面打开时，面板显示页面名并给出页面建议；模型每轮收到该页快照：设置（不含密钥、授权令牌与完整路径以外的敏感数据）、各状态任务数与最多 10 个任务的名称/状态/进度；本地转写含环境就绪、可用模型、草稿文件数与名称；名称翻译含已添加根目录数、条目数、勾选/就绪/问题等统计。
- AC-TOOLS-04-2: 字幕翻译、转换、提取与名称翻译提供 `*_update_settings` 页面工具，只更新该页持久化设置中枚举允许的字段，返回更新前后值；页面即时反映。本地转写设置沿用固定工具 `configure_local_transcription`。
- AC-TOOLS-04-3: 上下文由路由驱动的单一注册组件提供，不修改经典页面源文件（本地转写页属来源追溯冻结文件）；单元测试覆盖快照投影与设置更新校验。

#### 边界与异常
页面工具不启动、取消或删除任务，不选择文件；快照中的文件名截断到 255 字符。

### R-TOOLS-05 未指定的设置跟随工具页当前设置

| 字段 | 值 |
| --- | --- |
| 来源 | BR-06 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P0 |

#### 说明
Agent 添加或准备任务时，用户没有指定的设置使用对应工具页当前（持久化或会话内最新）的设置；用户明确指定的值优先。工具结果列出实际采用的设置及来源，便于 Agent 如实告知。

#### 验收标准
- AC-TOOLS-05-1: `queue_subtitle_translate` 的源/目标语言、输出内容、分片方式与长度、冲突策略、并发分片、思考开关跟随字幕翻译页设置；`queue_recovered_subtitle_translate` 的冲突策略与并发分片同样跟随。输出位置例外：翻译页的自定义输出目录需重新授权，未指定时仍保存到原文件旁，结果中注明。
- AC-TOOLS-05-2: `queue_subtitle_convert` 的目标格式（不再必填）、冲突策略，`queue_subtitle_extract` 的保留语言（扩展到页面支持的全部语言）、冲突策略跟随对应页面；页面选择了自定义输出且已有目录时沿用该目录。
- AC-TOOLS-05-3: `create_name_translation_plan` 的源/目标语言、名称格式（含双语顺序、括号样式与自定义模板）、是否包含隐藏项与附加要求跟随名称翻译页。
- AC-TOOLS-05-4: `prepare_studio_translation` 的目标语言、要求、上下文、输出上限、每批条数与模型跟随工作台翻译对话框最近一次设置（会话内），没有时与对话框默认一致；`prepare_studio_transcription` 的任务模式与初始提示跟随工作台转写设置。
- AC-TOOLS-05-5: 页面设置为“覆盖”而本轮用户未指定时按页面设置执行；模型自行指定“覆盖”仍需用户本轮明确要求（原规则不变）。
- AC-TOOLS-05-6: 每个工具结果附 `appliedSettings`（值与来源 user / tool_page / default）；工具说明告诉模型未指定时省略参数；单元测试覆盖三种来源与覆盖策略。

#### 边界与异常
跟随只读设置，不修改工具页设置；工具页设置非法时回退内置默认并标注 default。

## 目标与范围

以 `src/pages/Tools/index.tsx` 的最新/精选和经典栏目为范围，覆盖字幕工作台、翻译资料库、字幕翻译、字幕转换、字幕语言提取、本地字幕转写六项正式工具。已有名称翻译保留兼容。本模块负责真实能力发现、固定接口执行与会话内准备动作；编排、传统队列控制和界面由对应模块集成。

## 范围外

不新增长文本翻译、音频转写、语音合成、实时字幕、实时语音或音乐等实验性能力；不扩展已有实验性名称翻译。不接通用 IPC、shell、任意路径授权，不增加 main 权限。不提供删除文档、修改/采纳/删除资料或安装/删除模型资源。不将经典本地转写的真实 File 授权改成路径字符串。

## 需求

### R-TOOLS-01 在正式工具中完成有边界的查询、准备和执行

| 字段 | 值 |
| --- | --- |
| 来源 | BR-02 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明

HomeAgent 能查询工作台文档/任务、本地转写环境/任务和翻译资料，通过原生选择器导入字幕，将工作台翻译、转写整理成可审阅的准备动作。经典本地转写通过参数预填和工具入口交接，用户在其页面选择真实文件。

#### 验收标准

- AC-TOOLS-01-1: 能力目录准确列出六项正式工具、路由和支持操作，不因 TOOL_META.status=stable 将实验工具加入；原名称翻译兼容接口不受影响。
- AC-TOOLS-01-2: 工作台和经典转写查询调用固定 API 返回有界文档/任务/环境摘要，区别不可用、失败、空数据、已排队、执行中和完成，不能把入队成功报告为任务完成。
- AC-TOOLS-01-3: 字幕导入及工作台转写准备仅使用固定原生选择器；取消选择不提交，工具参数不接受路径、能力 token、API key 或 endpoint，失败不绕过 preload 权限边界。
- AC-TOOLS-01-4: 工作台翻译/转写准备动作绑定创建会话及准确文档/草稿范围；auto_execute 自动提交，其余模式保留 ready 等待操作；确认在首次 await 前同步 claim，重复确认最多提交一次，跨会话或失败动作不可盲重提。
- AC-TOOLS-01-5: 经典转写交接只接受验证过的有限业务参数、返回真实工具入口，保留页面文件选择，不消费其他页面的未确认媒体能力，不跨用工作台 token。
- AC-TOOLS-01-6: 资料检索返回计数、标识、审核状态和有长度/数量上限的匹配摘要，不包含整库、原始证据全文、凭据或执行授权，不执行修改或采纳。
- AC-TOOLS-01-7: 当前会话动作跨路由保留；回调、文件能力与密钥不持久化；会话变化使旧 ready 动作失效并清理其能力，失败动作显示明确错误且不自动重提。

#### 边界与异常

revision、generation 和能力寿命由已有契约负责。工作台原有草稿不得静默混入 Agent 任务，无法精确隔离时要求先处理旧草稿。计划过期须重新准备。资料无匹配与 IPC 故障必须区分。
