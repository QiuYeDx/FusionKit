# 计划与工作台需求

## 目标与范围
让多步工作可追踪，精确确认与导入不产生额外执行资格，首页覆盖真实能力与结果。

### R-WORKSPACE-01 计划与工作台

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01, BR-03 |
| 状态 | active |
| 批次 | I1 |
| 优先级 | P0 |

#### 说明
计划与待确认动作有独立结构化状态，保留聊天交互。会话导入只恢复展示资料；旧队列精确确认与名称翻译二次确认由运行时执行。

#### 验收标准
- AC-WORKSPACE-01-1: 计划包含目标/依赖/步骤状态；非法依赖及多项进行中被拒绝，页面显示完成数及阻塞原因。
- AC-WORKSPACE-01-2: auto与确认只启动本次新任务；否定及同轮重命名确认无效，双击不重复应用；取消后不继续创建新任务。
- AC-WORKSPACE-01-3: 有效旧会话可以导入导出；非法/超大文件被拒绝，导入归idle且不恢复确认资格。
- AC-WORKSPACE-01-4: 能力目录/计划/待执行动作/可信结果在四语言可用，桌面窄窗口无遮挡，键盘与错误恢复通过Electron渲染审查。

#### 边界与异常
取消或会话重置后拒绝迟到副作用；导入不携带原生授权或回调。确认失败保留摘要；历史没有回执的调用显示未完成，不能视为成功。

- AC-WORKSPACE-02-1: 历史准备回执表达已发生事实；计划注明上次更新，检查进度只填入建议并聚焦、不覆盖已有草稿或调用模型；当前 ready/running 优先，20条终态加2条待办仍可先看到待办，历史保留失败/范围。

- AC-WORKSPACE-02-5: 四语言、1280×860/786×660、浅深色通过真实隔离 Electron 截图审查、交互检查及修复复验；记录合成请求与真实 API/文件验证的边界，清理服务。

#### 边界与异常
不根据聊天展示授予权限，不推断计划完成，不伪造任务深链，不自动发起付费调用或重试。
## I3 悬浮入口需求

### R-WORKSPACE-03 全局悬浮 Agent 面板

| 字段 | 值 |
| --- | --- |
| 来源 | BR-05 |
| 状态 | active |
| 批次 | I3 |
| 优先级 | P0 |

#### 说明
在首页以外的页面左下角提供与右下角主题切换对称的圆形入口，点击后以动效展开对话面板。面板与首页是同一会话，可随时回到首页完整视图。

#### 验收标准
- AC-WORKSPACE-03-1: 除 `/` 外的路由显示入口；进入首页时面板关闭、入口隐藏；面板消息、计划、准备动作、待确认经典任务与首页一致，在任一处发送后另一处可见同一历史。
- AC-WORKSPACE-03-2: 面板标题区显示当前页面（工作台打开文档时附文档名）；空会话显示页面提供的建议；提供“在首页打开”、新对话（二次确认）与关闭；输入支持 Enter 发送、Shift+Enter 换行、停止生成与执行模式；未配置 Agent 模型时给出设置入口。
- AC-WORKSPACE-03-3: 入口有可访问名称与 `aria-expanded`，其提示显示在入口右侧，关闭面板回焦时不弹出；面板为非模态：点击面板以外的页面区域时收起（面板自身弹出层、页面弹窗与入口除外，点击照常作用于页面），固定后不收起、可与页面同时操作；Esc 或关闭按钮收起并把焦点还给入口，打开时聚焦输入；收起时若正在生成，入口显示进行中状态，产生新的回复时显示未读标记。
- AC-WORKSPACE-03-4: 展开/收起动效从入口位置生长，减少动态效果设置下退化为淡入淡出；面板不遮挡底部导航，页面模态弹窗位于面板之上。
- AC-WORKSPACE-03-5: 隔离 Electron 中在 1280×860 与 786×660、浅深色下审查截图与交互（含工作台修订链路），四语言文案通过检查；首页原有行为与 QA 不回退。

#### 边界与异常
面板不保存独立会话、不恢复执行权限；草稿只在本次运行内保留。关闭面板不取消正在进行的回复。

## I4 过渡需求

### R-WORKSPACE-04 首页对话与悬浮面板的连贯过渡

| 字段 | 值 |
| --- | --- |
| 来源 | BR-06 |
| 状态 | active |
| 批次 | I4 |
| 优先级 | P1 |

#### 说明
首页对话占据页面内容；离开首页后同一会话位于左下角悬浮面板。两者之间的切换应看起来是同一个对话在移动和收缩，而不是消失后另起一个窗口。

#### 验收标准
- AC-WORKSPACE-04-1: 会话非空（或正在回复）时从首页离开（用户导航或 Agent 切换页面），面板自动打开，其外框从首页对话列的位置与尺寸连续移动、缩放到面板位置；首页内容随路由淡出，外框先以不透明底色盖住首页对话列，面板内容随后在移动的外框中淡入（淡出淡入衔接）；全程无闪白、无内容跳位、无两份对话以不同位置重叠可读。
- AC-WORKSPACE-04-2: 会话为空时离开首页不自动打开面板，入口保持收起。
- AC-WORKSPACE-04-3: 在面板点“在首页打开”时，外框反向移动到首页对话列位置，面板内容在外框溶解前淡出，外框随后淡出露出首页对话；回复进行中过渡不中断回复。
- AC-WORKSPACE-04-4: 过渡期间面板不可交互，落位后输入框获得焦点；减少动态效果时两向都退化为淡入淡出。
- AC-WORKSPACE-04-5: 真实 Electron 中对两向过渡逐帧取样（首帧、中段、末帧）并审阅，1280×860 与 786×660 浅深色各一组。

#### 边界与异常
过渡只是展示，不改变会话、执行模式与待确认动作；窗口在过渡中缩放时以落位后的布局为准。
