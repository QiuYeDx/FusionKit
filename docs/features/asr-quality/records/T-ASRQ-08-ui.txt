## 审查记录（状态/位置 → 问题 → 原因 → 改动 → 复验）
1. 浅色 1280，文件已改写的无内容行 → 提示写“不能直接重试”，但下方“重试”按钮仍可点，文字与可用状态矛盾 → 文案按“一定不能重试”写，而实现每次重试都会重新核对文件（恢复原文件后可以重试）→ 四种语言改为“这个文件在转写后被移动或修改了，请重新添加文件后再转写。”，按钮保留 → 第 2 轮 asrq08-light-1280-source-changed.png 复验，提示单行、琥珀色，位于无内容框下方。
2. 英文 1024 深色，无内容框 → 说明三行，按钮行被推到框底部，框高 144px → 说明句子过长 → 四种语言缩短（保留“可改用低音量·耳语重试 / 检查音轨、语言和模型后重新添加 / 相同设置结果通常不变”三点）→ 第 2 轮英文框高 126px，说明两行。
3. 无内容框按钮行 → 说明到按钮行只有 4px，而失败块是 6px，同类关系不一致 → 为“说明之下 4px”单独加的 margin 覆盖与 space-y-1 的 4px 外边距折叠后只剩 4px → 去掉单独覆盖，沿用 studio-task-failure-actions 的 6px（与 4px 折叠为 6px）→ 第 2 轮所有视口 help→actions = 6。
4. 未安装语音检测的低音量按钮（第 2 轮新增状态）→ 禁用按钮旁写“需要先在‘管理资源’里安装语音检测”，“重试”可用；asrq08-dark-1024-needs-vad.png 复验无问题。
无其他可处理问题：深色下琥珀/muted 文字对比与既有失败行一致；1024 两列布局下按钮行单行放下（英文 4 个按钮 385→849px，未换行）；底部导航遮挡只出现在截图滚动位置，不是本任务的布局。
