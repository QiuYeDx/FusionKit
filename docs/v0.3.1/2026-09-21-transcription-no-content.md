# 转写无内容结果

## 问题与判断

本地字幕转写和字幕工作台已有 `no_speech_detected` 内部错误码：在完整合法的识别窗口通过结构检查后，没有文本可形成字幕。当前它被投射为普通失败，工作台还会丢失具体说明，容易诱导用户反复重试。

空 ASR 文本并不证明源媒体没有人声（FK-PIT-0106）。静音、音乐、过轻的人声、选错音轨或模型未识别到内容都可能导致空结果。本次只改善结果语义与反馈，不声称提高识别准确率。

## 产品选择

采用独立终态 `no_content`，界面称“无可用字幕”。说明本次处理已结束、没有识别到可用语音内容、因此未生成字幕。显示中性说明及下一步建议：先试听并检查音轨、识别语言或模型，调整后重新添加文件；使用相同设置反复执行通常没有帮助。

不自动创建空字幕文件/空文档：空产物没有内容价值，容易被下游误认为成功字幕，还会占用用户输出路径或启动不必要的翻译。正常成功仍意味着真实字幕产物；无内容是另一种已完成的处理结果。

不展示普通“重试”或切换 CPU 重试；保留移除记录，工作台保留定位源文件。“清理已完成”包含有产物完成和无内容记录，不包含失败/取消；原有清理全部/已结束入口语义保留。

## 执行边界

- 只有完整合法推理结果导致的精确 `no_speech_detected` 可以转为 `no_content`，不能把任意空数组、损坏响应、解码错误、质量校验失败或部分识别当作无内容。
- 取消和清理失败优先；不能为了展示中性结果吞掉系统故障，也不能在取消竞争之后回报普通无内容。
- 无内容记录无 error、completion、字幕 artifact 或 documentId，不进入发布/文档 sink/自动翻译。
- 正常结束进度与轮询，释放媒体/目录授权、原生资源及自动翻译准备快照/资料引用；同批后续任务继续。
- 两套本地转写保持独立类型和主进程实现，复用中性的结果说明组件，不接入远程音频 ASR。

## 验证

覆盖状态/IPC严格校验、生产空响应、正常字幕、非法响应/质量错误、清理失败与取消竞争、队列继续、无 artifact/document/翻译、引用释放、终态清理和轮询。原生 UI 覆盖成功/无内容/失败混合队列、可见解释与动作、中文浅色宽窗和英文深色窄窗；UI fixture 与实际推理的证据范围分别说明。

实现后的验证：Classic 契约、IPC、执行器、队列与 session 共 373 项；Studio 契约、文档发布、任务服务和执行器共 215 项；renderer/controller 与自动翻译快照共 85 项，均通过。TypeScript、四语言完整性和源码翻译键检查通过。

Electron 使用隔离 profile 和生产 renderer/preload/IPC，覆盖中文浅色 1280×860、英文深色 820×700。Studio runtime/任务队列使用受控 fixture，文档仓库仍为生产实现；Classic 注入经生产 schema 与状态迁移校验的队列，移除使用生产 registry。实际生产执行器与租约生命周期由上述单测覆盖，本次没有运行真实模型，也不据此宣称识别准确率提高。

复查中发现 Classic 先发布终态再释放能力的顺序可能隐藏清理失败，已改为清理完成并重新检查取消后再发布无内容，并补充失败与批次 pin 回归。该边界沉淀为 FK-PIT-0166；识别结果与声学事实的区别遵循 FK-PIT-0106。
