# 翻译资料条目弹窗重写

## 阅读与操作

详情按「条目身份 → 核心内容 → 适用范围 → 来源与完整字段」组织。术语与参考译文采用原文、译文对照；背景与规则直接展示正文；表达补充释义和例句。正常阅读无需展开原始字段。来源长文、别名、长链接允许换行，正文内部滚动，操作栏保持可见。

条目详情、编辑、方案编辑及通用维护预览共用局部 `KnowledgeRecordDialog`：52px 紧凑 Header、12px 外围留白、16px 分组间距；通常 640px，较复杂的方案表单 760px。不改变导入导出弹窗和已有资料集删除、归档专用布局。

底部动作由任务和状态决定：

| 场景 | 左侧次要动作 | 右侧操作 |
| --- | --- | --- |
| 待确认条目 | 更多：复制、拒绝、归档预览 | 关闭、编辑、采纳 |
| 已启用条目 | 更多：复制、归档预览 | 关闭、编辑 |
| 已归档条目 | 更多：复制、永久清除预览 | 关闭、编辑、恢复预览 |
| 条目编辑 | 保存草稿 | 取消、保存并启用；已归档条目只保存编辑 |
| 资料集／方案编辑 | 更多：对已保存版本执行维护 | 取消、保存 |
| 通用维护预览 | 无 | 取消、执行当前操作 |

危险操作使用明确的危险样式，并先进入影响预览；不把清除、采纳、编辑等不同优先级动作平铺成一排。菜单位于已有模态弹窗中，使用非模态 DropdownMenu，避免动作关闭父弹窗后残留指针锁。菜单自身消费 Escape，父弹窗继续可用。

## 编辑与反馈

条目编辑先呈现基本信息和核心内容。根据后续实际使用反馈，匹配参数、语言、适用范围、标题与来源改为 Tab：共享等高内容区域，切换时导航和底栏位置稳定；每页独立保留输入与滚动位置。隐藏页保持挂载，同时从键盘和辅助技术访问中移除。上方直接由字段标签提供层级，去掉重复小标题和通栏分割线。方案表单仍按基本信息、语言、引用、翻译要求、可选项分组。

保存失败不关闭编辑器，保留草稿，将可读错误滚入视口并聚焦；可以直接重试。详情切换到编辑或维护时不把焦点抢回旧弹窗；维护取消后返回列表中的原入口。所有保存、版本、采纳、引用检查与历史清理约束沿用原业务实现。

维护预览使用紧凑影响清单，保留、受阻情况有独立说明；任务引用默认折叠，有未知引用或清除拦截时自动展开。任务追踪不可用必须显示未知提示，不能显示成零引用。涉及全量历史清理的通用确认仍保留明确确认选项。

## 验证

采用隔离 Electron profile 和真实 preload／IPC／资料仓库，导入五种条目及长标题、长别名、长来源内容。检查中文浅色宽窗、英文深色窄窗，逐项观察详情、编辑、来源滚动、维护预览和菜单。截图与几何记录位于 `test-results/knowledge-entry-dialogs/`。

验证覆盖编辑取消、保存草稿、保存并启用、复制、拒绝、归档、恢复、引用拦截与历史清理。保存错误通过一次性受控 IPC 回包触发，随后恢复生产处理器并真实重试，检查草稿和原始数据的边界。
