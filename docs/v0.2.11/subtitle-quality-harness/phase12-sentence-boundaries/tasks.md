## 任务范围

### T-SEG-01

产出：`cue-boundary-planner.ts` / `speech-timing-evidence.ts` 的最小内部合同和有效实现、对应单元测试，以及后处理新策略身份。没有真实消费者的未来接口不标为交付完成。

先用脱敏日文、英文和 Unicode fixture 验证源位置覆盖、禁止词内切点、时间来源缺失时的原段回退；同文重复保留每次出现。旧 `segment_only_v1` 和新整形策略是不同概念，不偷改原生时间能力。

验收：文本文字与原有标点不增删；伪造时间域/倒序/失配文本被拒；显示偏好不能授权新时间切点。涉及新 helper、`subtitle-post-processor.ts` 及相关测试，预计不超过 6 文件；超出则先拆分台账。

### T-SEG-02

产出：默认执行器使用安全原段回退和显式连接决策；废弃默认 `assignProportionalTimings` 和以 CJK 为理由的裸合并。相邻英文续词、日文续词与独立短句不能统一按短时长合并。

时长/字数从硬限制改软目标必须同时更新新任务的设置语义。将本任务拆为连续的小提交：后处理/导出测试；随后配置说明与对应四语言文案。每次提交包含有效默认行为，不合入只有 UI 标签变化的半成品。

验收：已保存原始响应经生产执行器导出，三个错误切法为零，新增模型请求数为零；明确记录仍保留的无标点长段。运行后处理、执行器、格式器、类型和设置相关测试。不能在此处关闭 R-SEG-02/03 全部需求。

### T-SEG-03

产出：Q-01/Q-02 的真实对照结果和明确采用决定。A 路线与 B 路线按设计第 6 节运行；各处理三个固定输入一次，故障只允许该次重试一次；不扩大成跨语言排行榜或恢复整个旧 GUI 环境。

先确认候选所需资源已有或通过受管渠道可用。原音和用户字幕不上传，不覆盖原文件。没有词时间、发生文字差异、边界吸收停顿、音效出现词都原样记账；不对输出手工补成正确答案。

验收：本次开头需提供可用于核心内容分组的真实锚点，B 保留已改善主体，B-noise 不添词；限定试听核对新锚点。保存模型/版本、字段、耗时/显存、原始响应、默认候选输出。选型失败也必须做决定：保留 T-SEG-02 成果、登记失败原因，不能无限试下一套参数。

选 B 时，T-SEG-04 必须先展开为受管资源、adapter、调度与 UI 能力四类可独立验证任务，写明资源身份及平台边界后实施；不把 Python/CUDA 打包藏在一次 helper 修改中。Q-01 是实现阶段的技术验证，不是要求用户重新解释需求。

### T-SEG-04

产出：选型通过的时间 producer 接入主进程，原音身份、窗口来源、词到原文映射及取消/回退完整。落点为 `speech-timing-evidence.ts`、原生合同/supervisor 与执行器及对应测试；选 B 时按 T-SEG-03 展开的专门任务执行。

验收：真实请求与反例请求均通过；原 VAD 压缩词轴仍拒绝；同一时间不得两个 GPU 模型请求争用；超时/取消/模型退役和资源清理走现有生命周期。每窗额外请求和全任务预算统一计数，不能绕过既有质量恢复限制。

### T-SEG-05

产出：有时间证据的句界候选进入统一规划器，处理原段内部和相邻段接缝；基于候选关系恢复中性分隔，独立视觉换行。仅在时间来源通过的片段启用内部切分，其余走已经接好的原段回退。

验收：无标点的多短句、带标点的长度不均句、原始词中接缝、句内长停顿、真重复、开闭引号、跨窗句各有正反例。改变显示目标不能改变原文覆盖或引入比例时间。对实际开头重新导出并检查，不止验证 synthetic fixture。

### T-SEG-06

产出：现有任务详情的降级计数/说明与设置迁移一致；SRT/LRC 来自同一计划，后续翻译使用稳定源条目。落点为本地类型/IPC、设置、详情组件、四语言及格式/交接测试，按纯接口与 UI 分成小提交。

验收：有效原文+增强失败仍完成并显示段数；空转写保持既有错误；取消不写产物；LRC 同时间条目不误删；纯翻译不能改时间或原文结构。用户看得到改为“建议值”的解释，重启后保存值不被覆盖。

### T-SEG-07

产出：以基线 `9a4c2ea`、T-SEG-02 中间版本和完整新版本组成可听对照；实际打包应用生成字幕后交用户验收。源文件只读，所有输出指定工作区自定义目录、自动编号，不默认写入 NAS。

完整跑本次 `trk01`、阶段 11 序章，回归 B/B-noise/C。逐项报告词中截断、缺分隔、明显提前/滞后、新漏词/复读、回退数和新增耗时。生成的人工包只聚焦可用结果，不要求用户理解 VAD/词轴参数。

机器验证：相关测试、`tsc --noEmit`、四语言检查、Vite 三段构建及 preload 检查；存在真实 native 字段/资源变化时执行相应 packaged runtime 验证。实际 Electron 点击默认转写并检查输出，不把组件离线回放写成完整桌面验收。关闭本轮启动的服务和模型进程。

人工验收：核心内容分组可读、三个已知断词消失、短句有区分、台词与音频对应；不以复制参考五个时间戳替代听校。任一关键项失败则记录下一修复任务，不标本阶段完成。
