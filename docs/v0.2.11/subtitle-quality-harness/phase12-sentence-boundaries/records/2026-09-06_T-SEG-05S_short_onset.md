## 实现与结果

`cue-short-onset-evidence.ts` 将原字幕短尾句及完整后文对应、全 token 覆盖、多个观察的首末点、原始 PCM 的活动与停顿分开核验。只允许拆开原有文字，不以另一个观察的前部词形删改源字幕；人工 7380 ms 和样本词句未进入运行时。

原定阈值直接重放五份已保存观察。固定 0～30 / 0～18 秒目标首点为 7400 / 7560 ms，尾点为 8060 / 8040 ms，均在同一活动 7390～8180 ms；其前检测间隔 1250 ms。另有两段 5420～5550 / 5850～6140 ms 活动，与用户说明的清嗓声相符，但活动检测本身不判定声音语义，也不提供人工精确边界。

旧 4～18 秒首点 6360 ms 位于活动间隙，尾点却在目标活动，按预定合同拒绝 `target_points_not_in_one_activity`。补静音两份首点 7480 / 7440 ms 也在同一活动。五份原始观察及异文均保留；若把全部五份交给共识函数，整体明确拒绝，未悄悄剔除不利观察再声称全票一致。生产选用固定完整前部窗口对，依据是独立活动合同，不是按人工误差筛窗。

候选首句拆为 2500～7400 ms「ああもしもし」、7400～9660 ms「私だ」，共13条；后11条逐字段不变，全部源文字保留。7400 ms 为第一份原生 DTW 点，未取平均或采用活动阈值起点。比人工主观7380 ms晚20 ms，只记录差值，不声称20 ms精度或人工已验收此不同数值。
