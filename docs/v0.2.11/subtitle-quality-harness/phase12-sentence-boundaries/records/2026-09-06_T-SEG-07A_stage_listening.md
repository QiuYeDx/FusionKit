# T-SEG-07A：综合听校包与验收映射

## 授权与基线

用户要求先提交推送 06C，再整理综合听校包，集中验收分句、去重和时间轴。06C 已提交 `8950e15` 并推送 `origin/v0.3.1`。本项沿用 spec-driven-ai-coding 存量 Markdown 台账及项目听校避坑规则：局部标签不扩展成整轨结论，播放与定位操作不等同实际听到的范围。

使用 05T 默认生产路径实际生成的全套字幕与已有无增益音频副本；06C 实跑的 opening/independent 与 05T 逐字节保持。本项零新增识别，不改默认转写参数、文字或时间，不修改 NAS、既有字幕和用户附件。原始三文件 SHA256、大小和 mtime 与初始记录相同。

每段四项独立判断：词句截断、短句可读性、时间同步、漏词/额外词/复读。所有项初始“还没判断”，允许可以接受/有问题/不确定。可以自由拖动、0.8/0.65 倍速、点字幕或导航后连续听；可在大致播放位置记问题。全段备注与局部备注保留，不自动把定性听感解释成精确字词边界。

导出 `asmr-stage-listening-annotations.json`，绑定 reviewId、每段音频/SRT 指纹、时长与片段内时间域；导入必须完全匹配才覆盖页面状态。允许部分填写，不将未填算通过。浏览器本地保存失败时提示及时导出；历史操作仅标记 interaction_only，不能作为完整听完的证明。测试使用独立无持久化 Chrome 会话，合成填写从未写入页面初值或人工验收记录。
