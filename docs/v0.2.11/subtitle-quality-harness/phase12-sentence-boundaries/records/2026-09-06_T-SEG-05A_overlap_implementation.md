# T-SEG-05A：有界跨窗异文仲裁实现

日期：2026-09-06。关联 R-SEG-02/03/04/05/07。规模 M，单模块串行。前次记录完成用户反馈与来源核对，本轮推进限定复核、正式代码和实际应用验证。

## 实测与采用决定

固定复核只有一次 20～40 秒原音及一次既有 B-noise，沿用正式 large-v3/CUDA/非 VAD DTW 字段。接缝返回一个完整事件段，24.920～31.300 秒；“何だ”写作“なんだ”，不满足初定的全文同文门。没有调参数或换裁剪；依据已接受两份观察，形成设计 6.11 的双侧精确覆盖合同：前缀 7 字、后缀 11 字，重叠 3 字。负例产生错误重复文字，不能因返回时间点就判为有语音。

该证据只用于识别两份窗口观察的事件关系；选择后窗已接受的完整文字一次呈现，沿用旧外边界 24.960～31.230 秒。不会把第三次输出其他台词拿来替换主文，也不把 29 秒写成内部切点。

## 代码与生命周期

`cue-overlap-resolver.ts` 负责限定结构资格、唯一双侧覆盖和时间证据，返回替换及三份来源决策。`production-executor.ts` 在主识别后执行，每文件最多两处，每处只消费右根窗共享额外请求一次；同根窗不再叠加分隔请求。完整保留之前四处 DTW 分句使用的其他根窗预算。原音无增益、30 秒超时、非 VAD lease 串行、取消与清理错误处理沿用现有合同。

开发中发现辅助跨接缝窗口不能借用“零重试深度但 rootWindowKey 与 windowKey 不同”的主窗口身份。已明确独立观察键与预算归属，保留主重试图校验严格性；没有伪造 split lineage 或将辅助响应加入主图。

回归涵盖两组不同句式的正例、同窗/不同时间/真实重复、不完整词锚、非相关内容、多个第三观察、额外插词、时间错位、缺失/倒序/坍缩/越界 token 点；执行器正例/失败回退/取消/清理/共享预算。

## 真实应用发现的状态副作用

首批 `overlap-production/` 把接缝放在原有分句前面：重复消失，但已有分句变化；验收失败。第二批 `overlap-production-final/` 把接缝后置：原有分句恢复，但复核不再通过匹配门而保留重复；同样不作为完成结果。没有为了通过样本放宽锚点或换裁剪。

依据同模式状态影响的实测，在 `server-supervisor.ts` 给 pinned separator lease 增加已有机制对应的 freshInferenceState 选项；已请求实例重建，未请求实例复用，资源 pin/忙碌拒绝/清理合同不变。最终是原有分隔序列先执行，接缝在独立推理状态中最后执行。有合格接缝的文件最多额外加载模型两次，新增解码仍最多两次。精确原生状态原因未定位，不能说已修好上游引擎。

最终回归目录为 `overlap-production-isolated/`。前两批保存用于追溯，不能以 synthetic 单测成功覆盖真实应用中的失败。

## 最终实际应用结果

最终构建通过实际 Electron 默认任务队列运行六素材（large-v3、CUDA、日语、Silero VAD）。`overlap-production-isolated/verification.json` 对最终 SRT/LRC 严格回读：开头 12→11 条、完整 216 秒音轨 67→66 条，唯一变化都是将已报告的两份冲突观察变为一次完整句，24.960～31.230 秒。除此之外所有字幕的文字与时间逐条相等，原有 12.060/14.840/19.300/22.020 秒四处分句保持。

独立约 176 秒素材 31 条、低声 B 1 条、已保存 C 控制 3 条，SRT 与上一轮字节一致；LRC 与本轮 SRT 的文字/起点投影逐条一致。音效仍 no_speech_detected，无 SRT/LRC。三份 NAS 原件的大小、修改时间和 SHA256 保持。最终批次从首快照至终态约 99.6 秒，含排队/加载/解码，不作为单项推理性能基准。

本轮去重计数共 346 项相关测试通过：接缝消费者 17、执行器 87、原有分隔消费者 37、supervisor 56、主后处理 75、格式 25、导出 49。最终状态隔离业务改动后重新跑 supervisor/执行器/新消费者；其余无代码变更的回归已在本轮通过。最终 TypeScript、Vite 三段构建、preload 和 Spec 检查通过。构建保留既有 chunk/dynamic import 警告，业务 UI/i18n 没有修改。

该版本覆盖限定的“前窗末尾残缺异文 + 后窗内完整观察”，不宣称解决所有跨窗冲突，也不做全局模糊去重。T-SEG-05A 实现和机器验收完成，保留进行中等待本例人工听校；T-SEG-05 其他连写、跨父段规划及 T-SEG-06 说明/阶段完整验收仍未完成。代码未提交或推送。
