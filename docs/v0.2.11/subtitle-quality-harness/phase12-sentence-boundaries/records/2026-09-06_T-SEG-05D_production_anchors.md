## 实现

cue-local-anchor-evidence.ts 是生产和离线核对共用的单观察核心，使用已经映射到毫秒的 dtwTokens，避免在生产里重新解释原生 t_dtw 单位。完整上下文用于左右锚点唯一性检查，原文位置仍以当前父段计算。原始字素不能跨 token 错配；非法/缺失/倒序点、词内位置、重复上下文和资源超限均拒绝。

cue-separator-restorer.ts 只在旧规则已经选出完整同文组、且该组从父段内部开始时，检查其唯一组首。通过后补一个切点，再按原始位置排序；不改变已有内部切点、原文及分隔。相邻切点至少 600 ms，最大 8 个；失败返回旧消费者结果。执行器、请求参数、VAD、资源 pin、候选请求顺序均未改动。纯文本分隔路径不启用此分支。

离线脚本在加载时用项目已有 TypeScript 依赖转换同一核心，避免直接导入 TS 强制要求 Node 24；没有提交生成代码副本，也没有新增依赖。实际测试运行于 Node 24.19，未声称做过 Node 18 实机测试。
