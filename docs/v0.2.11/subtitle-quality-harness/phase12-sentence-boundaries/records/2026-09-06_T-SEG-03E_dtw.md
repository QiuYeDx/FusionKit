# T-SEG-03E：现有运行时 DTW 能力的限定审计

## 固定计划（推理前）

关联 R-SEG-03/04/07。03D 已证明普通 token 时间即使文字完全一致也会漂移。固定 commit 的 [server](https://raw.githubusercontent.com/ggml-org/whisper.cpp/f049fff95a089aa9969deb009cdd4892b3e74916/examples/server/server.cpp) 接受 `--dtw large.v3`，在 verbose_json 返回独立 `t_dtw`；[实现](https://raw.githubusercontent.com/ggml-org/whisper.cpp/f049fff95a089aa9969deb009cdd4892b3e74916/src/whisper.cpp) 在开启 flash attention 时关闭 DTW，因此必须单独加载 `--no-flash-attn`。这不是原 `start/end` 自动变准的开关。[头文件](https://raw.githubusercontent.com/ggml-org/whisper.cpp/f049fff95a089aa9969deb009cdd4892b3e74916/include/whisper.h) 将该值定义为实验性的 token 输出时刻近似，不是完整发音起止。

不新增模型或适配另一引擎。使用现有固定 server 和 GGML large-v3，各输入独立进程，CUDA、非 VAD、beam=5、temperature=0、token_timestamps=true，启动加 DTW 及关闭 flash attention。固定五次：0～30 秒、03D 的 8～17 秒和 6～20 秒裁窗、已保存低声 B、无词 B-noise。任何不支持/内存失败停止本轮，不换 CPU 或调精度再搜。响应完整落盘后才比较。

审计区分 ordinary start/end 与 DTW 点；按照固定源码单位（10 ms）加真实窗口偏移，并逐 token 检查未计算的 -1、非单调、越界、重复退化及文字覆盖。完整局部候选段组唯一匹配主原文，错词段不得抽取相似子串。对焦点边界两侧 token 的 DTW 点分别比较全部三个窗口；稳定点不能冒充 onset 或音频听校。B/noise 只验证候选约束和风险，不允许候选替换主文。

本轮三项：五请求能力验证、单独 DTW 审计及反例、采用/否定决定。若只有词内点更稳，则下一步必须明确如何取得句首范围及人工听校，不直接启用生产拆时；若不稳定，则停止本引擎这两种 token 时间路线的扩展。私人数据写忽略目录 `test-results/subtitle-quality-review/phase12/dtw/`，任务结束清理进程。

## 结果

五次计划内请求全部完成，无重试。每次独立进程，进程 ID 为 82924、86632、68052、58028、54668，全部已退出；输入哈希不变。模型和 server 哈希与 03D 相同。响应和每次诊断均保存于私有目录，未改生产加载参数。

| 输入 | 推理耗时 | 加载耗时 | 结果 |
| --- | --- | --- | --- |
| 开头 0～30 秒 | 2732 ms | 2634 ms | 有有效 DTW 点，10 个原生段 |

DTW 与普通 start/end 分开审计：DTW 不使用普通词区间去制造发音起止，单位转换、未计算值、越界、倒序和相邻点退化均有反例。此次支持无原生段界但有有效 DTW 点的观察；`automaticAcceptance` 仍恒为 false。
