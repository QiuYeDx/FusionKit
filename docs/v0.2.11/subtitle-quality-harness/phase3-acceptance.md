# 第三批：实际模型验收与 ASMR 听校准备

规模 M，角色为验证与问题修复；承接用户确认的下一步。继续沿用前两批设计，不在没有听校依据时接入自动改字或全局 VAD 调参。

## 范围

- P3-01：使用 FusionKit 已分配给字幕任务的实际模型配置，对自造、非私有的日文 SRT/LRC 做小规模真实服务验证。覆盖双语/仅译文、跨片上下文和并发，最多 12 次模型请求，每次最大输出 2,048 tokens。严格协议失败使用既有重试，计入总请求额度。真实音频及 NAS 文本不发往云模型。
- P3-02：检查真实返回的格式遵循率、时间轴保留、基本译文含义与专名一致性。结构失败后先查根因，只有实际问题需要时修复本批相关路径。真实模型服务的故障与本地协议错误分开记录。
- P3-03：基于工作区三个既有切片制作本地听校包，突出 B 的长间隔与 C 的未覆盖候选，提供循环试听、原始候选区间、人工“语音/非语音/不确定”标注与导出。不以 VAD 或另一轮 ASR 代替人工真值；未完成听校的条目保持未标注。

### 发现的质量边界

独立 SRT 和 LRC 任务中，“ミナ”分别出现“米娜”和“美奈”两种译名；同一任务顺序两片的重复人名测试则保持“米娜”。这个结果说明上一片译文参考在该例中得到沿用，但目前没有跨文件共享的确认术语。不能将某一转写自动判为唯一正确名称，也不能把独立任务中的变体误报为时间轴/JSON 协议缺陷。

下一项可独立推进的翻译工作应是有作用域、可人工确认的术语表：项目/系列共享已确认译名，模型发现的新名称先进入候选，不直接写成永久事实；与当前有界上下文和 checkpoint 配合。

## ASMR 本地听校包

交付文件：`test-results/subtitle-quality-review/asmr-listening-review.html`（约 3.9 MB，包含 3 个 30 秒工作区 WAV 切片，不含 NAS 路径）。支持切片选择、波形、区间循环播放、各 0/1/2 秒前后文、0.65/0.8/1 倍速、本地标注保存和 JSON 导出。所有条目默认未标注。

8 个条目包括：A 的对照片段；B 的两个 VAD 候选和中间 20.20 秒区间；C 的四个重点候选范围。C 的重叠来源已合并为听校范围，说明中保留当前/宽松检测来源的区别。

音频指纹与区间共同确定数据集身份；导出 JSON 包含片段指纹、区间、判断和备注，不携带音频。判断分为“未标注 / 真实语音 / 呼吸或音效或无词句 / 不确定”。页面限制网络连接，音频内嵌，因此本地打开即可使用。

生成器：`scripts/local-subtitle/benchmark/build-listening-review.mjs`，模板：同目录 `listening-review.html`。私有输入清单在忽略目录 `listening-manifest.json`。

### 已验证与未验证

- 生成器与候选诊断共 8 项 Node 测试通过：PCM 读取、截断/非法音频拒绝、区间约束、音频指纹、来源文件不被覆盖、HTML 嵌入转义、脚本语法检查。
- 自动浏览器拒绝 `file://` 本地听校页面，给出本地 URL 访问策略限制。本轮没有改用其他浏览器表面或间接服务绕过；因此播放器、标注保存和导出的实际浏览器交互尚未验证。
- 用户需在本机浏览器打开交付 HTML，优先试听 B-gap 与 C-late-1 / C-late-2，记录可辨认词句或“不确定”，然后导出标注。试听标注完成前，不将候选检测结果用于自动补字，也不宣称 ASMR 漏识别率已改善。
