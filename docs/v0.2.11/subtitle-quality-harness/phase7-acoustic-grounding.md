# 第七批：文字候选的声音依赖与首字定位对照

## 范围

承接用户继续推进的指令，P7-01～P7-03 已完成实验与工具校验。沿用已有隔离 small / faster-whisper / CTranslate2 环境，不下载新模型，不改生产默认值，不访问 NAS。

P7-01：对固定文字比较原音频与等长静音的逐 token 条件概率。保持输入文字、token 序列、模型及长度一致。该差异只表示模型对输入声音的依赖，不是语音存在概率。

P7-02：在 B/C 的局部工作区音频中，逐个遮挡 500 ms 区间；遮挡边缘用 10 ms 淡入淡出减小突变。观察哪些声音区间影响固定文字及首 token 的得分。范围用已知宽上下文选择，不把用户的自由试听备注当精确句界；总编码最多 32 次、对齐评分最多 48 次。

P7-03：同时评价旧 ASR 候选、无词句音效和自造无关文字。保留负例、完整 token 分数和输入指纹，不根据单一平均概率或遮挡峰值自动修改字幕。不将 500 ms 分辨率宣称为逐帧对齐。

代码落点：`scripts/local-subtitle/benchmark/acoustic-grounding.py` 及对应 Python 单元测试；私有清单与结果仅写入 `test-results/subtitle-quality-review/phase7/`。本批是定位方法的实测，不增加新的主程序内部空接口。

## 实测结果

2026-09-05，本地 CPU/int8 多语言 small，沿用第六批已校验的模型修订及依赖。共执行 22 次音频编码、42 次固定文字评分，无生成解码、无云端请求。3 个工作区 WAV 的处理前后 SHA-256 一致。

下表为每个文字候选自身的“原音频平均 log 概率 − 等长静音平均 log 概率”，不是百分比、准确率或不同文字间的排名。时间均相对对应的原始 30 秒 B/C 样本，不是 NAS 原文件的绝对时间。

| 样本及固定文字来源 | 原音频减静音 | 首 token 得分下降最大的遮挡区间 | 解读 |
| --- | ---: | --- | --- |
| B 语音窗口：此前无 VAD 替代候选 | +4.9426 | 23.5–24.0 秒 | 文字对部分声音有明显依赖，尚未确认为正确文字 |
| B 语音窗口：旧转写候选 | −0.1442 | 不作定位结论 | 本次未显示相对静音的正向支持，不能据此自动删除 |
| C 核心句候选 | +3.4476 | 17.5–18.0 秒 | 可缩小下一轮声音复核范围 |
| C 同一音频：自造无关句子 | −0.6002 | 17.5–18.0 秒 | 错句的首 token 也会出现明显遮挡峰值 |
| B 音效窗口：此前误词 | +1.4737 | 未做局部遮挡 | 负例也得到正向对照分数，禁止把正数当成有词证明 |

B 替代候选的整体文字分数主要对 23.5–25.5 秒遮挡敏感；C 核心句主要对 17.5–19.5 秒敏感。这里描述的是模型得分敏感区域，不能直接写回为字幕起止时间。尤其 C 无关句子的首 token 在遮挡 17.5–18.0 秒后也下降约 2.5885 log 单位，单看首 token 峰值仍会误收错误文字。

用户此前的备注继续作为自由试听的定性反馈，不从备注反推精确句界，也不要求用户重新填写原标注。本次数据不恢复“C 尾音必定在 20.15 秒之后”等已经撤回的结论。

## 工具与验证

- 清单限制候选数、遮挡数、音频长度及总计算量；固定文字 token 往返一致，保留逐 token 原始分数。
- 遮挡仅作用于内存副本，保持音频长度及时间原点，校验输入和模型指纹；输出不得覆盖输入文件或模型目录。
- 报告保留原音频、静音、各遮挡条件的分数及摘要；`acousticTruth` 始终为 `unverified`，`automaticReplacementAllowed` 始终为 `false`。
- 6 项 Python 单元测试通过，覆盖遮挡范围和样本不变性、分数合法性、计算预算、时间原点映射、禁止把正向声音依赖当成文字验证及输出保护。
- 实测完成后新增的汇总函数已用原始分数生成摘要并由单元测试覆盖，没有重复运行模型。本批没有生产 TypeScript/UI 改动，没有重复宣称前几批测试为本批执行结果。

复现命令（仓库根目录，使用第六批隔离环境）：

私有清单、文字及音频未纳入版本控制。通用工具和测试不依赖私有样本；运行实验需要本地清单、模型和模型校验收据。

## 下一步与应用边界

本批提供了可复用的候选诊断手段，尚未改善主程序的自动转写结果。下一步应围绕上述粗范围，用现有生产 large-v3 做有限次数的独立窗口重解码，并保留音效负例，比较候选文字在上下文变化下是否稳定。只有同时获得更可靠的文字证据和声音边界证据，才考虑接入用户可复核的候选结果；当前不设自动接受阈值、不自动替换字幕、不宣称逐帧准确或整体质量已提升。
