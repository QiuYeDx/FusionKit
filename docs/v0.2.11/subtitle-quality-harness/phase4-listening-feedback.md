# 第四批：听校反馈与上下文窗口对照

## 范围与验收

承接用户提交的 `asmr-listening-annotations.json`，本批处理 P3-03 的真实听校反馈。状态：已完成本批反馈核对和限定范围实验；自动补救与准确句界验收未开始。先验证数据集与音频指纹，保留原始标签和备注；只在工作区既有 WAV 上做局部对照，不访问 NAS、不向云服务发送素材、不改变生产 ASR 参数。

- P4-01：核对全部 3 个音频指纹、8 个区间和 datasetId。标签不是完整句子真值；备注中的尾音、混合声音、估计发音独立保留。
- P4-02：使用完整 large-v3、固定日语、独立服务进程，对 4 个上下文窗口各执行当前 VAD 与无 VAD，共最多 8 次本地请求。复用既有请求参数，记录有效 VAD 日志、窗口原点、原始与映射后的时间戳。短窗口结果只作为候选，不自动替换。
- P4-03：对比既有 30 秒结果，记录哪些文字已经存在、哪些只是时间边界问题、哪些尚无逐字真值。导出可试听的工作区窗口与诊断，不要求用户重复填写原来的 8 个小片段。

实验脚本和私有输出位于忽略目录 `test-results/subtitle-quality-review/annotation-followup/`；生产源码与听校页面本轮不变。验收要求：指纹匹配；输入文件内容不变；每次推理独立进程且最终关闭；所有 ASR 文本均标为模型候选；不以字数、VAD 覆盖率或字幕时长计算准确率。

## 已收到的反馈

| 区间 | 用户选择 | 备注对结论的限制 |
| --- | --- | --- |
| A-control | 真实语音 | 间歇说话，不是整个 30 秒连续发声；尚无逐句边界 |
| B-first | 非语音 | 用户确认普通 ASMR 音效、无词句；是检测误报对照 |
| B-gap | 不确定 | 前段无词句，最后两三秒有一句话；整个区间是混合内容 |
| B-last | 真实语音 | 句子一部分，前部在区间外；不能以候选起点当句首 |
| C-early-1 | 真实语音 | 只有句子局部，前部在区间外 |
| C-early-2 | 不确定 | 词尾和下一声的一部分；缺少完整句子不等于没有语音 |
| C-late-1 | 不确定 | 用户听到一句话的后半部；估计发音不作为逐字真值 |
| C-late-2 | 非语音 | 备注指出先有上一句尾音、再有口腔音；不能作为纯非语音区间自动删除 |

原始选项仍为 3 个 speech、2 个 non_speech、3 个 uncertain，不擅自重写用户选择，也不将此计数当准确率。

## 对现有结论的修正

上一版听校包以候选区间为关注点，虽有前后文扩展，但 0.2–0.7 秒候选不能承担“完整句子是否遗漏”的判断。用户指出的切片截断首先证明听校区间不覆盖整句话，不直接证明送入模型的音频也在同一位置被裁断。

既有 C 当前组文字中已经有用户所描述的后段句子，字幕在切片内 19.41 秒结束。**第六批纠正：用户在试听时还会手动前后寻找完整句子，旧导出没有播放范围记录，因此不能由其尾音备注证明语音延续到 20.15 秒之后，也不能据此断言该句结束过早。** “完整句子被小关注区间截开”的反馈保留，但精确句界未知。B 的字幕从 3.84 秒延续到 25.34 秒，用户描述词句在后段、前段为音效，仍是过早起字幕/跨越长段非词句声音的复核线索。准确句首、句尾未得到人工时间标注。

B-noise 当前组在用户明确确认的无词句区间仍返回约 `0.0000193` 的 `no_speech_prob`；本次服务返回值不能作为“必然是语音”的证明。关闭组的重复拟声内容也不应一律等同同句循环幻觉：它可能是反复声音的文字化，但对用户需要的词句字幕仍构成无效内容风险。

上述结果是实验调用的 raw 输出，不等于完整 FusionKit 生产链最终导出文件；未在本批验证后处理能否消除其中某项问题。也未以模型间一致、字符数增加或边界缩短宣称准确率提高。

## 下一步实现依据

1. **先分开文字与时间轴问题。** C 的核心句已存在，优先评估保留文本的声学时间对齐，核查词尾覆盖、跨停顿显示和相邻句归属；不能用等比例分配时间代替对齐。
2. **局部补救需要成句上下文。** 以疑似问题区间为中心扩展，并合并同一句的相邻候选；记录音频窗口原点、关注范围和候选原始边界。实验窗口是探索参数，不直接成为全局默认值。
3. **候选先校验，再替换。** 无 VAD 只作为有界局部候选来源；需要保留旧结果、检测与邻句重复、识别非词句风险、检查文字与时轴是否真的改善。冲突或证据不足时保留待复核状态。
4. **建立负例和尾音混合例。** B-first 是用户明确确认的无词句片段；C-late-2 同时含尾音和口腔音，不能因 non_speech 标签整段过滤；不把这两类混为同一种负样本。

下一项生产实现应先落在可追溯的诊断与局部候选路径，时间对齐方案需另行比较。当前证据不足以发布“默认关 VAD”“统一降低阈值”或自动补字策略。
