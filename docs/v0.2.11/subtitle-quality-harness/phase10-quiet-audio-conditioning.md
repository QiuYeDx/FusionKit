# 第十批：低音量音频进入 VAD 前的保护

P10-01～P10-03 已完成代码接入及有界验收（2026-09-05）。默认点击转写时，低音量窗口自动处理，结果可疑则自动回退。本批 B 的最终字幕有实测改善，不能据此宣称全素材准确率提高。

已排除 A/B/C 的明显双声道相位抵消。B 整体音量低；单独增益 12 dB 时 VAD 只保留 B 后半句，配合前后各 1000 ms 上下文后得到完整主体候选，B 音效对照为空。全局处理 A/C 有退步，因此只考虑有界低音量输入。

## 实现与验收约束

- P10-01：默认 VAD 转写路径的私有 PCM 窗口计算 RMS，保持帧数、顺序及时间原点。RMS <−30 dBFS 且 ≥−60 dBFS 时，以 −20 dBFS RMS 为目标，最大增益 12 dB。极少数尖峰使用平滑软限幅，输出峰值约不高于 −1 dBFS；软限幅触发门为该峰值的 90%，触发样本超过 0.1% 时整窗不处理。静音及正常音量窗口保持字节不变。
- P10-02：只有实际应用增益的 VAD 窗口使用 1000 ms 语音上下文；普通窗口沿用旧请求。参数从已验证的私有窗口属性进入主进程快照，不接受 renderer 伪造。不开启压缩时间域 word timestamps。
- P10-03：用同一个生产 PCM 写入函数、请求构造器及后处理导出 A/B/C 和负例的最终 SRT/LRC。实际自适应结果不冒用固定增益实验。检查无削波、文件身份、取消清理、源文件不变，并扩展独立窗口检查退步。
- 自动回退：增强输入的原始输出通过接口契约检查后，若质量检查不通过、单段超过 7000 ms 或连续重复达到 3 条，丢弃增强候选，用原始音量及原 VAD 参数再请求一次。回退本身不再递归增强；既有质量分窗/重试上限保持有效。短正常结果及空结果不会触发这次回退。空结果仍沿用既有 `no_speech_detected` 错误状态，不导出伪空字幕。

阈值是有限增益与上下文的输入策略，不是语音分类阈值。现有模型/资源不替换；正常接受的窗口请求数不变，触发保护的窗口增加一次原音量请求。不改 NAS 音频。代码落点：quiet-audio helper、pcm-window、media-normalizer、production-executor、server-contract、server-supervisor 及对应测试。

## 实测结果

使用现有 full large-v3、Silero v6.2.0、CUDA 运行。下面时间均相对于各自截取片段。最终导出使用当前生产后处理和格式编码器，共生成并回读 30 个 SRT/LRC 文件。

| 输入 | 实际处理 | 旧结果 → 新结果 |
| --- | --- | --- |
| B，30 秒 | +12 dB / 1000 ms 上下文 | 错误文本「うわぁ…それでしょう」跨 3.84–25.34 秒并被拆成 4 个碎片 → 「太ももスベスベでしょ」23.45–26.31 秒，1 条字幕 |
| B 音效对照，18 秒 | +12 dB / 1000 ms 上下文 | 「お前…」→ 无文本；不导出字幕 |
| A、C，各 30 秒 | 不增益，PCM 数据及请求参数保持不变 | 文本和最终时间轴与原基线一致；C 原有错词和长时间段尚未修复 |
| 新窗口，原文件 575 秒处 | +12 dB 后出现约 12 秒可疑长句，触发回退 | 回退保留原结果「大丈夫?」11.68–12.41 秒 |
| 新窗口，原文件 625、650、675 秒处 | 不增益，PCM 数据和参数不变 | 保留原结果；只运行基线请求，不重复运行相同输入 |

新窗口未经过人工逐字标注，且来自同一素材，因此只能用于发现退步，不能算独立准确率评估。回退阈值是在发现 575 秒窗口问题后加入的，仍需在未用于设计的其他作品上验收。

实际生产限幅波形与直接固定增益不同：固定 12 dB 实验会削去 B 的少量尖峰；只按峰值预留余量又将增益降至约 7.72 dB，B 和音效对照退步。最终实现仅对极少数尖峰软限幅，重新实测得到上表结果。不能借用固定增益结果为其他算法背书。

## 验证与证据边界

- 316 项相关 Vitest 测试通过（8 文件；首次新增空结果测试误写顶层状态，改为既有 `failed / no_speech_detected` 后该文件 60 项重跑通过）。覆盖增益边界、字节/帧数保持、源文件身份、私有窗口证明、取消/清理、参数快照、默认执行器的实际 SRT 导出及单次回退。
- `tsc --noEmit`、`vite build --mode=test`、`check-preload-bundle.mjs` 通过。构建仍有既有 chunk 体积及混合静态/动态导入提示。
- 生产 PCM 写入器与请求构造器生成输入，真实 native server 得到响应；生产质量判定、回退条件与编码器回放这些响应，生成最终字幕。执行器调用/选择路径另有集成测试，未将离线回放冒充完整桌面操作验收。
- 同一 native server 连续执行增强输入和原输入，两次真实请求验证回退文本与时间恢复。无语音概率与独立进程基线略有差异，原始日志保留，质量判定仍通过；未要求浮点诊断概率逐值相等。
- 私有证据目录：`test-results/subtitle-quality-review/phase10/`。`production-limited/` 是最终生产波形实测；`heldout/` 是扩展窗口；`fallback-live/` 是真实连续回退；`export-report.json`、`exports/` 是最终字幕。`production/` 是已放弃的峰值限增益版本，不作为最终成功证据。私有音频不入库。
- NAS 原件只读取，提取过程核对大小及修改时间不变。验收响应/输入也校验哈希不变；原生验收进程均停止。本批未启动前端或 Electron 服务。

已构建工作区代码，但未替换用户已安装应用，也未生成安装包。当前没有足够证据承诺耳语普遍不漏词、空输出必定无语音、全长文件质量提高或帧级边界准确。下一批应优先验证未参与调参的完整素材，并处理 C 这类整体音量正常但局部低声/停顿的情况。
