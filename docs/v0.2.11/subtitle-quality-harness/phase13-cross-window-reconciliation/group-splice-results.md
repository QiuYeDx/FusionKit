# 整组拼接实现与离线候选

## 2026-09-07 本批结果

按 [本批合同](group-splice-contract.md) 新增 `overlap-group-splice.ts`，将显式来源选择、字幕拼接、严格自动证据判断分开。草稿消费者保留一侧的完整原文及其内部原始分句，将整体起止恢复至待替换字幕的整体显示范围；它不会沿接缝切文字、拼造新的识别文字或宣称恢复了精确声学起止。变化后的 cue 标记 `estimatedTiming`，不继承旧词级时间戳。

来源观察与当前字幕的文字/核心区投影必须仍然相等；组索引连续，整个当前时间轴及外部邻居不得冲突。未选择一侧的完整文字不能在保留侧中唯一找到时，草稿显式标记 `unaccounted_source_content`。这是对来源选择风险的展示，不是强制让两份转写具有相同分句。

自动证据判断另要求两次固定、不同身份、同一音频来源的协议有效观察，完整文本各出现一次、没有区域内额外内容、全部字的 token 内部点有覆盖与源时段支持，跨观察差异不超过既有 300ms 门槛。不会通过忽略长音、替换否定词或数字来允许删除。这一严格入口目前只有合成反例和离线重放，未接入执行器，不能把 `supported` 返回值当作通用自动化已获产品验收。
