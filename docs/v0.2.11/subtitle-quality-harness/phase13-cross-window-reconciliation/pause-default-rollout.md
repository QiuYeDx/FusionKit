# 停顿分块默认推广与 VAD 联动

## 决策与授权

2026-09-07 用户明确要求将已有明显改善的停顿分块设为默认，接受一定不足，不再为收益有限的疑难样本无限试验。本记录替代先前“全部已知接缝退步解决后才默认启用”的推广条件；这属于用户接受质量取舍后的需求变更，不是将失败样本改报通过。

采用当前已完成完整应用对照的 acoustic_quiet_v1，去掉四语言中的“实验”标识，显示为推荐选项。已有旧音轨的两处接缝重复仍记录为已知局限；不扩大近似匹配删除范围、不新增模型重载或逐句词汇特例。没有安全停顿时保留有界重叠，短音频 / 超过 24 小时仍保留既有路径。此轮不宣称新的转写精度提升或重复问题根治。

## 配置合同

- 新安装默认 acoustic_quiet_v1 + VAD 开启。
- 偏好版本 3→4 一次性推广：既有安装改为上述默认，保留模型、语言、输出格式等其余偏好及草稿。之后用户显式选择 fixed_v1 可以跨重启保存。
- 选择停顿分块自动开启 VAD；该策略下 VAD 开关锁定，显示依赖说明。用户先选固定窗口，才可关闭 VAD。持久化清洗也修正矛盾组合。
- 新任务 IPC 拒绝显式 acoustic_quiet_v1 + vadEnabled=false。旧请求省略策略及旧任务快照仍按 fixed_v1 解释，既有任务、普通重试与 CPU 重试不被页面偏好迁移。
- 主进程继续检查受管理 VAD 资源，没有安装时使用现有资源缺失提示，不让选择新策略绕过资源校验。
