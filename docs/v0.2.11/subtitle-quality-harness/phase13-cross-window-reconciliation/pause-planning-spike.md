# 停顿优先切块：有界可行性实验

## 来源、问题与范围

用户要求重新考虑固定时间窗口，优先从自然停顿切块。此前诊断完整复现两轨重复；本批将切块源头的实验放在继续扩展事后去重之前。沿用连续推进授权，按 spec-driven-ai-coding 的 bounded spike 执行，不改默认生产策略，不要求用户再确认内部实验。

本批回答：固定、保守的原始 PCM 低能量候选能否显著减少强制重叠接缝，同时不明显破坏已有语句？低能量不是可靠语音不存在证明，也不等同于独立 VAD。候选通过不表示人工听校完成或可直接上线。

## 固定实验合同

- 16kHz mono PCM16 上按 10ms 检查原始波形；连续至少 600ms 同时满足 RMS ≤ -55dBFS、peak ≤ -45dBFS 才形成候选区。
- 每个切点距离候选区两端各至少 300ms。搜索当前输入起点后 18～29 秒，优先离 25 秒最近的候选点；若没有候选，沿用 30 秒输入/5 秒重叠及中点核心区归属。短尾块直接覆盖至文件终点。
- 停顿切块不加跨句的 5 秒重叠；切点位于低能量区内部，前后各保留该区音频。完整样本范围连续覆盖，不删除静音、不压缩原始时间轴、不生成任何按字数猜测的边界。
- 原始音频只读；实验产物放忽略目录。先在两轨保存 PCM 上离线规划；若可减少重叠，再分别进行一次固定顺序识别，同模型/参数/增益回退机制，每轨新进程。不得为了满意结果遍历阈值或改变裁窗重复识别。
- 解码质量门需要递归恢复时暂停该轨实验并保存全部结果，不无限扩展。实验请求不得超过每轨 2×候选窗口数。

## 验证与停止条件

1. 合成输入验证样本全覆盖、核心区无重叠无遗漏、窗口≤30秒、停顿两侧缓冲、连续音频退回旧几何结构、确定性和非法输入拒绝。
2. 保存两轨全部切点、候选区和 fallback，统计重叠接缝数；不得把减少接缝等同于质量改善。
3. 识别后保留完整原生响应、原始绝对时间和核心区投影。由于生产校验当前只接受固定几何，本实验不绕过该校验并伪称生产通过；只生成明确标注的实验字幕，生产接线仍待设计。
4. 对照原两轨问题点，记录重复变化、字词新增/缺失和时轴变化；需要听校的新内容、轻声及尾音单列。不能以字幕数量降低作验收。
5. 如果候选过少或输出出现明显回归，停止调参并记录限制；下一步考虑独立 VAD＋波形约束及更明确的切点证据。即使实验有收益，仍需旧 ASMR/非语音对照和生产整合回归后才能启用。
