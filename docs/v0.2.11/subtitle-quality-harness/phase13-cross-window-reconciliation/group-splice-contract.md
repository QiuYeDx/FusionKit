# 整组拼接：保留来源与自动资格分离

本批沿用用户继续开发授权。复用已冻结的四份观察，不增加推理；不改变已失败观察的有效性，不将模糊相似改成删除依据。

## 本批实现

1. 可重放的整组拼接草稿：只选择已有左组或右组的完整文字，恢复组首尾的原始时间并限于当前待替换字幕整体范围。组内沿用被保留来源的原始分句，禁止按字符均摊时间、生成新字、自动补标点。必须检查冻结的来源/当前字幕快照、索引连续、外部相邻字幕不冲突；修改后的字幕不能套用旧提名。
2. 同时列出两侧差异与独有内容；草稿始终为 `review_required`，不是生产字幕，不触碰导出或 NAS。保留哪一侧是显式参数，不能让相似度自动决定。左右有差异时必须可见，不能因合并后更短就称其更好。
3. 单独实现严格的自动证据判断：保留侧须完整包含另一侧一次，两个有效、身份不同的固定原音观察须分别完整支持保留组一次；所有词的内部时间点须有覆盖、顺序与跨观察稳定性支持，区域中不得出现其他未解释内容。字符串和 DTW 条件分开验证。词形/长音、否定词、数词等分歧不归一化为相同字；当前两处依然可被拒绝。
4. 用同一个拼接实现生成本次两处离线对比候选，显示原始结果、候选、来源差异及证据拒绝原因，供阶段质量检查。候选不是自动修复已通过的证据；不要求用户重新确认重复是否存在。

## 验证与退出条件

测试覆盖一对一、一对多、多对一；前导清嗓的保留；真实连续重说；否定/数词/长音差异；陈旧提名与相邻字幕冲突；独立观察身份、额外文字、缺失/漂移时间点。离线重放四份原音响应，保留第一份协议拒绝。执行类型检查和相关回归，输出可恢复记录。

本批不启用新生产入口或停顿默认策略。两处缺少自动证据时，不再增加特例或模型试跑；保留可审查的草稿和明确的拒绝结果，将自动去重的剩余限制作为阶段边界。
