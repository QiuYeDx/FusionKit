# 保守来源自动选择与实验执行链

沿用用户继续开发授权。已认可的两段是固定对照，不再重听或追加模型试跑。本批不解决任意异体字/词义差异，不把人工接受写成生产短语规则。

本批将完整包含关系下的来源选择接入已有停顿实验链（仅 v2 根计划；默认固定链不变）。先对左右两侧分别生成受来源校验的草稿；没有一侧完整覆盖另一侧则直接跳过，不申请新观察。对可选侧分别调用已有严格证据判断；仅一侧通过则保留它，两侧都通过时文本规范化序列必然相同，稳定保留左侧分句。来源完整性优先于段数、长度或置信度，不按这些分数删去独有字词。

执行顺序位于既有五种重叠修复之后。不得覆盖已被其它修复修改的原始索引；每任务最多新增一组/两个固定观察，复用现有共享根请求预算。两次观察分别使用全新模型状态、无增益原音、no-VAD DTW，使用现有协议、保留预算和取消/失败清理。加载/证据失败保留原输出，取消和清理错误不得吞掉。默认策略以及 VAD-off/短素材/>24h 回退行为不改变。

验证：纯选择器覆盖左右完整包含、等价来源、前导声、真实重复、字词分歧和无效观察；执行器覆盖成功、默认禁用、无可选来源不发请求、有限预算、观察缺失/错误、加载失败、取消和清理失败。复用真实八素材的完整应用存档检查新增入口是否会提名及消耗预算；已认可的两处应保持跳过而非误报自动通过。不启动新的真实模型/应用试跑；模拟执行验证与真实模型验证分别记录，默认启用质量门保持未通过。

当前状态：选择器和实验执行链完成，324 项相关回归及类型检查通过；真实最终存档扫描没有新增可自动修复组，缺少原生正例/新完整应用验证。默认启用未通过，本路线本阶段收敛，不追加两个已知样本的专用规则，详见 [结果记录](group-selection-results.md)。
