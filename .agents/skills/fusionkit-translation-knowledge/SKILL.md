# FusionKit 翻译资料准备

交付 UTF-8 `.fktk.json` 与简短使用说明。只支持 FK-TK/2（`schemaVersion: 2`）。离线校验器已打包依赖，只需 Node.js 18+，无需 FusionKit、联网或安装 npm 包。

## 一句话模型

**一个资料集 = 一个作品 / 主播 / 系列的词典和备忘，有一个翻译方向；翻译时用户勾选要用哪几本。** 资料集里只有三种内容：

- **术语**（`term`）：原词 → 译法，可设「必须 / 优先 / 保留原文」。
- **背景**（`context`）：AI 需要知道的事实。
- **要求**（`rule`）：译文需要遵守的写法。

每条可以启用或停用。预设（`presets`）是可选的「资料集组合 + 翻译要求」，供字幕工作台一键套用。

## 从需求到可用资料

1. 确定语言方向和作品／主播／领域。按「一个作品一个资料集」组织；多个作品共用的说法放进单独的通用资料集。仅在关键歧义妨碍整理时询问用户。
2. 读 [文件协议](references/protocol-v2.md) 与 [应用中的使用方式](references/application-usage.md)。第一次制作参照 [日中入门包](examples/ja-starter.fktk.json)；需要多个资料集与预设时参照 [多资料集示例](examples/multi-collection.fktk.json)。示例为虚构演示，制作新包时生成新 UUID。
3. 依据 [组织与匹配](references/organization-and-matching.md) 设计最少够用的资料集，再搜集内容。事实核查与本地材料抽样遵循 [来源整理](references/research-and-evidence.md)。整理用户旧版资料时读 [从归档重建](references/rebuild-from-archive.md)。
4. 优先提供真正影响译文的术语、背景、要求。没有明确需求不设置「必须」术语或「重要」说明；拿不准的 AI 建议设为 `enabled: false`，交给用户启用。
5. 按下面的验证与交付要求完成文件和说明，不只输出提示词或无法导入的表格。

## 保持可执行、可审核

- `ja → zh-Hans` 等语言标签精确匹配；`zh` 不够明确。方向写在资料集上，条目不单独带方向；同一作品要两个方向就建两个资料集。
- 日文连写优先评估 `literal_phrase`，不要机械使用 `whole_term`；多义短词、活用和大小写差异见组织参考。`note` 只是说明，不是语义识别器。
- 不得补写原文不存在的口头禅、剧情或动作；只适用于某个说话人或场景的约定，写进说明正文（例如「主播 A 说话时……」），让 AI 自行判断。
- 预设不能携带模型、密钥、温度、时间轴或任务绑定；预设引用的资料集必须同方向并在包内。
- 用 `origin` 标注来源：用户约定 `manual`，AI 推断 `agent`，网页 `web`（附实际读过的 URL、标题、UTC 时间）。不要把 AI 建议标成用户约定。
- 来源只用必要显示名和摘要，不输出私人绝对路径、凭据、任务 ID 或未经要求共享的全文。网页需实际打开读取，不能把搜索摘要冒充原文。

## 更新与身份

实体 ID 使用小写 UUID v4（可用 `crypto.randomUUID()`）。已有实体实际改动才增加 revision；改名或改内容保留 ID，重新打包或排序不提升未改实体的版本。省略旧条目不等于删除。保留未知的非执行性 extensions。

多套包共享通用资料集时，复用完全相同的实体 ID、revision 和内容；每个包仍须带齐自己引用的资料集。不要在不同包内暗改同 ID 同版本内容。

## 验证与交付

以技能目录为当前目录，或使用脚本绝对路径：

```sh
node scripts/validate.mjs /path/to/output.fktk.json --json
```

退出码 0 表示结构及已知语义合法（可以有警告），1 为无效文件，2 为工具／IO 错误。修正全部错误后重跑。`DUPLICATE_TERM`、`TERM_DISAGREEMENT` 警告需向用户说明（例如官方译名与个人偏好分在两个资料集，不要同时勾选）。无可用 Node 时明确写「未运行校验」。

另做使用检查：常用词在真实或自写句中能否按字面命中；可选资料是否单独成集。校验器不证明来源、译法质量或模型遵循情况。不要为此默认启动应用或调用付费模型。

随包简短报告：

- 范围、语言方向、每个文件的用途。
- 每个资料集的术语、背景、要求数量，其中「必须」「重要」和停用的条数；实际访问的来源、未核实项。
- 实际校验结果和警告。
- 使用路径：「翻译资料 → 导入资料 → 预览后导入 → 字幕工作台勾选资料集（或套用预设） → 试译或翻译」。导入后条目按文件中的启用状态立即生效。

交付可点击的 `.fktk.json` 链接；ZIP 仅便于分发技能，不能当成翻译资料导入。
