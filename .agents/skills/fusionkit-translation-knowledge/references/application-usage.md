# 应用中的使用方式

配套 FusionKit 字幕工作台，文件协议为 FK-TK/2。资料准备可以离线进行；不要直接访问应用的 userData。

## 翻译时用到什么

| 内容 | 何时参与翻译 |
| --- | --- |
| 术语 | 所在资料集被勾选、条目启用、原文中按匹配方式命中时 |
| 背景、要求 | 所在资料集被勾选、条目启用时（每批都会带上） |
| `required` / 「必须」 | 预算不足时也不会被省略；两条「必须」术语对同一处原文给出不同译法时，翻译会被阻止 |
| `preferred` | 预算不足时可能被省略；与「必须」术语冲突时让位 |
| 停用的条目 | 不参与，保留在资料集中 |
| 归档的资料集 | 不出现在工作台选择列表中 |
| 预设 | 工作台中套用后，填入资料集、翻译要求与内容说明 |

资料只用于字幕工作台，经典字幕 AI 翻译器没有资料入口。模型、推理参数不属于资料包，不要写伪字段。

## 导入

1. 「翻译资料 → 导入资料」，选择或拖入 `.fktk.json`。
2. 预览按资料集列出：新资料集，或与本地同 ID 的资料集（新增、不同、相同的条目数）。每个资料集可选择新增 / 合并 / 另存为副本 / 跳过；内容不同的条目统一选「保留本地」或「使用导入」。
3. 导入后条目按文件中的 `enabled` 立即生效，没有审核步骤。拿不准的建议请在包里设为 `enabled: false`。
4. 字幕工作台确认源语言和目标语言，勾选资料集或套用预设，试译后开始翻译。

## 给用户的最短说明

写清：推荐勾选哪几个资料集（或直接用哪个预设）；哪些资料集不要同时勾选（例如官方译名与个人偏好）；哪些条目默认停用、为什么。术语没有在原文出现时「未命中」是正常的。

## 获取与安装技能

在应用的「翻译资料」页可以保存技能 ZIP。解压后把 `fusionkit-translation-knowledge` 整个文件夹（含 references、examples、scripts）交给 AI 工具；只复制 SKILL.md 会丢失协议说明和校验器。

本项目的权威源在 `.agents/skills/fusionkit-translation-knowledge/`。技能 ZIP 不是翻译资料包，不能导入；AI 生成的 `.fktk.json` 才能导入。
