# 当前应用能力与用户交付

配套当前字幕工作台，文件协议为 FK-TK/1。资料准备可离线进行；不直接访问 userData 或伪造本地采纳摘要。

| 能力 | 当前状态 | 制包方式 |
| --- | --- | --- |
| term / context / rule | 已采纳、已选用且范围匹配时可参与请求 | 主要交付内容 |
| expression / memory | 可保存、查看和导出，暂不执行 | 用户确需且有证据时创建，并说明限制 |
| styles | 全部引用规则需已采纳且依赖可用 | 带齐规则、资料集、来源；候选会产生 STYLE_NOT_READY |
| recipes | 保存资料集、风格、要求与内容说明 | 引用完整、语言一致，对象需本次确认 |
| inheritGlobalPreferences | 尚未应用通用偏好继承 | 通常关闭，重要要求放进本包 |
| learningSuggestion | 自动积累尚未执行 | 通常 off，不承诺自动学习 |
| 模型、推理参数 | 不属于知识包协议 | 工作台配置，不写伪字段 |

资料仅用于字幕工作台，经典字幕 AI 翻译器没有资料入口。资料直接在翻译配置内选用，不指示用户寻找额外总开关。普通集不因关联对象就要求绑定；条目实际 scope 限制才需确认。

## 导入与批量采纳

1. 导入 `.fktk.json`，检查版本／冲突预览。共享包自包含，不依赖接收者已有某 ID。
2. 「待确认」中筛选资料集和类型，选择当前页或当前筛选结果，批量预览中查看、排除不想采用的项，再确认采纳。
3. 强制术语／要求、核心背景和不可用依赖受到批量审核规则限制，界面解释跳过项；确需这些约束时说明应单独核对，不标 ready 或改来源绕过。
4. 库在预览时改变，需刷新并重新确认。“已导入”不等于“已启用”；候选也不会被导入时“采纳标为可用资料”的选项自动采纳。
5. 字幕工作台确认源／目标语言、选资料或方案、检查／试译，再开始翻译。未选就不读整库；新文档不自动继承说话者和片段条件授权。

导入合法、证据可信、本机采纳、纳入请求、模型遵循是不同结果。报告写清验证范围，不声称离线 CLI 验证最终译文。

## 给用户最短说明

推荐先用哪套／哪个方案，哪些可选集不同时启用；只有相应作品才加作品集，人物要求再绑定实际说话者。没出现术语时“不命中”正常；风格引用要求未采纳需先处理。不能承诺只采纳术语就启用引用候选规则的风格。简单词表可用空 styles/recipes。

## 获取与安装技能

工具页可保存技能 ZIP。解压后把 `fusionkit-translation-knowledge` 整个文件夹（含 references、examples、scripts）交给 AI 工具；只复制 SKILL.md 会失去协议和校验器。

本项目权威源在 `.agents/skills/fusionkit-translation-knowledge/`。其他支持项目级 skills 的工作区可放在该项目 `.agents/skills/`，或按所用工具的安装方式处理。技能 ZIP 不是翻译资料包，不能导入资料库；AI 生成的 `.fktk.json` 才能导入。
