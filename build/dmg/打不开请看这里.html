FusionKit 打不开？请看这里

FusionKit 没有购买苹果的签名证书，第一次打开时 macOS 可能会拦一下。这不代表文件有问题，按下面的方法放行一次就好。

English below ↓

先安装

  1. 把左边的 FusionKit 图标拖到右边的“应用程序”文件夹。
  2. 打开“应用程序”文件夹，双击 FusionKit。

提示“无法验证开发者”或“无法打开”

  1. 先点“好”或“完成”关掉提示。
  2. 打开“系统设置 → 隐私与安全性”，在页面下方找到关于 FusionKit 的提示，点“仍要打开”。
  3. 按要求输入电脑密码，再点“打开”。

macOS 12 请打开“系统偏好设置 → 安全性与隐私 → 通用”。

提示“已损坏，无法打开”

文件并没有坏，是 macOS 给从网上下载的应用加了“下载标记”。先确认 FusionKit 已经在“应用程序”文件夹里，然后打开“终端”（可以用聚焦搜索“终端”），粘贴下面这行命令并按回车，再重新打开 FusionKit。

xattr -dr com.apple.quarantine /Applications/FusionKit.app 已复制

这条命令只去掉 FusionKit 的下载标记，不会改动应用本身，也不需要输入密码。复制按钮不起作用时，点一下命令即可全选，再按 ⌘C 复制。

换成新版 FusionKit 后又打不开

换成新版本后，第一次打开时可能还要再放行一次，方法和上面相同。

系统要求

macOS 12 或更新版本，仅支持 Apple 芯片（M1 及更新）。推荐的转写模型另需约 1 GB 磁盘空间。

打开 FusionKit 后，底部导航的“帮助”里有同样的说明和更多常见问题。

If FusionKit won't open

FusionKit is not signed with a paid Apple certificate, so macOS may stop it the first time you open it. Nothing is wrong with the file; allow it once as described below.

Install first

  1. Drag the FusionKit icon on the left onto the Applications folder on the right.
  2. Open the Applications folder and double-click FusionKit.

"The developer cannot be verified" or "cannot be opened"

  1. Close the message with "OK" or "Done".
  2. Open System Settings → Privacy & Security, find the note about FusionKit near the bottom and click "Open Anyway".
  3. Enter your password if asked, then click "Open".

On macOS 12, open System Preferences → Security & Privacy → General.

"FusionKit is damaged and can't be opened"

The file is not broken: macOS marks apps downloaded from the internet. Make sure FusionKit is in the Applications folder, open Terminal (search for "Terminal" with Spotlight), paste the command below, press Return and open FusionKit again.

xattr -dr com.apple.quarantine /Applications/FusionKit.app Copied

The command only removes FusionKit's download mark. It does not change the app and does not ask for a password. If the copy button does nothing, click the command to select it all and press ⌘C.

It won't open after you update FusionKit

After replacing it with a new version, you may have to allow it once more the first time you open it, in the same way.

System requirements

macOS 12 or later, Apple silicon only (M1 or newer). The recommended transcription model needs about 1 GB of extra disk space.

Once FusionKit is open, Help in the bottom navigation has the same steps and more common questions.
